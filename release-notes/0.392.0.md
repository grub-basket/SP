# 0.392.0

## Scroll fixes
- **List no longer jumps back to the bottom.** After the list had been pinned to the bottom (e.g. sending a note), a scroll up that arrived without a wheel/touch/mouse/key event — momentum, a status-bar tap, the scrollbar, find-in-page — left the "stick to bottom" latch set, so the next re-render snapped you back down. The latch is now cleared from the scroll itself when you scroll up and are clearly off the bottom (Stashpad's own pin writes are excluded, so sending a note still pins as before).
- **Find-in-list keeps your place.** Opening the in-list search no longer pins the filtered results to the bottom, and closing or clearing the search returns you to where you were instead of jumping to the top.
- **Row jumps land correctly.** A note scrolled into view (e.g. after a jump) now aligns just below the sticky heading instead of parking underneath it.
