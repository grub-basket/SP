# 0.511.0

Split-modal upgrades (mark multiple sections, smarter nesting) and a new
"insert at multiple points" tool. Covers everything since 0.508.0.

## 0.509.0 — multi-marker split + per-segment nesting

- The **Line** split mode now takes **any number of split points at once** instead
  of a single divider. Click a line to add or remove a marker after it; the
  arrow keys nudge the most-recently-touched marker; clicking a divider clears
  just that one. The markers carve the note into N segments and the Split button
  reads "Split into N".
- The marker set round-trips through "Open in a tab", so split points survive a
  pop-out.
- **"Nest" redefined to decompose each part.** With nesting on and two or more
  splits, each part's first line becomes a note and its remaining lines become
  that note's children (fence-aware; blank lines dropped). Part boundaries are
  respected — a part's children never pull in the next part's lines. Part 1
  reuses the original note, so splitting into N parts leaves N top-level notes.
- A single split engine (`performMultiSplit`) now serves every split mode — Line,
  Cursor, Each-line, Blank-line(s), Headings, and Custom-delimiter — so the
  nesting behavior is consistent across all of them. With nesting off, each part
  stays one whole note, as siblings (unchanged).

## 0.510.0 — insert text at multiple points

- New **"Insert text at multiple points"** button in the formatting toolbar, on
  both the composer and the edit/split editor.
- Click it to start marking: click spots in the editor to drop or remove a pin at
  each caret position, type the text once in the panel beneath the editor, and
  press Enter (or Insert) to drop that text at **every** marked spot at once.
  Insertions are applied right-to-left so earlier positions stay valid.
- Cancel, or Esc from either the text field or the editor, exits with no change.
  Editing the editor's own text clears the marks, since their positions would
  otherwise drift.
- The button is a normal toolbar button, so it can be reordered or hidden from the
  toolbar settings; it appears only when the formatting toolbar is enabled.

## 0.511.0 — single-split nesting fallback

- Restores the pre-0.509.0 behavior for the simple case: with nesting on and
  **exactly one split** (two parts), part 1 stays whole as the original and part 2
  becomes a single child of it — neither part is decomposed. Two or more splits
  still use the per-segment decomposition from 0.509.0. Nesting off is unchanged.
