# 0.187.0

## Editing

- **Edit in Stashpad is now the default edit action.** The pencil button on a note
  now opens Stashpad's own editor (previously it opened a new Obsidian tab). Menus
  and commands are relabeled to match: Stashpad's editor is **"Edit in Stashpad"**,
  Obsidian's is **"Open in Obsidian editor"**. The Obsidian editor is still one step
  away — the right-click menu and **Mod+Shift+E**.

## Autocomplete

- **Space completes a tag.** With the `#` tag popup open, pressing Space accepts the
  highlighted tag and keeps typing — since tags can't contain spaces anyway. (It only
  completes a genuine prefix match, so a brand-new tag you're typing isn't hijacked;
  and it doesn't apply to `[[` links or `@`, which legitimately contain spaces.)
- **`@` dates work with Natural Language Dates Redux too.** The `@` date suggestions
  now resolve via either the original `nldates-obsidian` plugin or the modern
  `nldates-redux` fork — whichever you have installed.

## Moving notes

- **Clearer nest/move confirmation toast.** Dragging a note into another now says
  **"Nested X → Y"** (or "Moved X → Y" for a cross-parent move) instead of the old
  jargon "Reparented".
