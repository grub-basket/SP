# 0.320.4

Note actions get a full customization layer, plus a dedicated settings tab, an alphabetical view launcher, and an upgraded pinned-notes tab view. Grouped by version.

## 0.320.0 — Note-action catalog, custom item buttons, reorderable star menu

- **One catalog of note actions.** Every per-note action (edit, copy, move, react, reply, …) is enumerated once with a default icon, so the star menu, the row buttons, the context menu and the icon registry all draw from the same source.
- **Command icons registry.** A settings section lists every action with its icon; change any icon (with a live Lucide preview) or reset it to the built-in default. The four fixed row buttons keep their icons.
- **Custom item buttons on every note.** Add your own command buttons to each note's action row. The first few (four on desktop, two on mobile) sit inline after the built-in buttons, which keep their positions; any extras drop to a bar at the bottom of the note.
- **Star menu is now freely built.** The star button's quick menu is a reorderable list that can include any Obsidian command, not just the presets. Empty it to hide the star button.
- **Context menu — Edit leads, Copy grows.** "Edit in Stashpad" moves to the top (most reachable) and the Obsidian-editor handoff drops below it. A new Copy submenu offers copy text, copy tree, copy tree with level markers, and copy focused subtree, each honouring the timestamp modifier.

## 0.320.1 — Context-menu builder

- A settings builder reorders, adds, and removes the plain actions at the top of a note's right-click / ⋮ menu (Set due, Reveal in large text and Move to archive are addable). The state-dependent items — obscure, pin, tasks, share & export, encrypt, delete — always keep their fixed places.

## 0.320.2 — Pinned notes: folder tabs

- A third pinned-panel layout (panel ⋮ → "Folder tabs"): a strip of per-folder tabs plus "All", each showing a count, filtering the panel to the active tab. The active tab is remembered per device.

## 0.320.3–0.320.4 — Dedicated settings tab, launcher order, pinned upgrades, polish

- **New "Note Actions & Menus" settings tab** gathers the star menu, item buttons, context menu and command icons in one place, each with a clear heading and a one-line explanation of what it does.
- **View launcher** lists its destinations alphabetically.
- **Pinned folder tabs gain actions**: an action bar to open the folder, expand or collapse its pinned-note sublists, and unpin everything in it (with a confirmation); a right-click menu on each tab (open, open in a new tab, unpin all); a full-path tooltip so same-named folders are distinguishable; the tab strip scrolls instead of pushing the list off-screen.
- **Polish from a UX review**: item buttons only offer actions that read clearly as an icon-only button (nothing that opens a surprise dialog); the context menu always shows a divider between the part you can reorder and the fixed part; the Copy submenu drops redundant timestamp entries when a timestamp modifier is set; the overflow button bar gets a divider and a "⋯" marker; the command-icon list is grouped with a "Reset all icons" button.
