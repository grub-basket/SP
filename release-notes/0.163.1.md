# 0.163.1

Fixes the home-note header's menu button, which rendered as a horizontal
"meatball" (⋯) on iOS/macOS instead of the intended vertical kebab (⋮). The
button now uses the same `ellipsis-vertical` icon as the note rows, so it reads as
a true vertical kebab and matches them.

(Background: the previous icon, `more-vertical`, is rotated 90° by Obsidian on
iOS/macOS to the platform's horizontal-dots convention, so it looked horizontal
regardless.)
