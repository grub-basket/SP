# 0.296.0

Performance follow-ups (0.295.2 and 0.296.0): cheaper rows, background
housekeeping that no longer walks the vault, and a fix for encryption keys that
arrive via sync.

## Encryption keys that arrive via sync (0.295.2)

- A folder's `.stashkey` is a dotfile, so Obsidian raises no vault event when
  it appears through Sync, iCloud or another device — after the startup scan the
  plugin never noticed it until a reload. Now, whenever the plugin is about to
  conclude "this folder has no key" (unlocking, the encryption commands, the
  archive-on-move-in check), it first re-checks the disk for that folder and its
  ancestors, and it re-scans the vault every ten minutes and about a minute
  after a sync burst settles. A key removed elsewhere stays trusted for up to
  ten minutes; the read then simply fails on the missing file.

## Rows are cheaper to build (0.296.0)

- Windowed rendering rebuilds rows as you scroll, so per-row cost now recurs.
  Row click, double-click and drag-arming handlers are attached once to the
  list instead of once per row; behaviour is unchanged (selection, shift-click
  ranges, buttons inside a row, whole-row drag grab).
- Row icons come from one hidden SVG sprite per window instead of a parsed
  inline SVG per icon per row — about half the DOM nodes per row and no SVG
  parsing while scrolling. The sprite is built from Obsidian's own icon set, so
  theme icon packs are honoured, and it is rebuilt when the theme changes. A
  theme that styles the *paths inside* `.svg-icon` will not reach these icons.

## Background work (0.295.2, 0.296.0)

- Due reminders are checked against a small index of notes that actually carry
  a `due` (kept current from metadata events, rebuilt hourly) instead of walking
  every markdown file every five minutes. The manual "resend reminders" command
  uses the same index.
- The master-index tab collects its rows once and only repaints on facet, sort,
  chip and select-mode changes; it reads note bodies only for notes without a
  heading, and works out the "has web links" facet the first time you turn that
  chip on.
- Lazy body rendering drains a few notes per frame, nearest to the viewport
  first, and the clamp measurement is done in one layout pass per batch.
- The "pin to bottom" watchdog started after sending a note is cancelled when
  the view closes.

## Stylesheet (0.296.0)

- The rule that makes text selectable in Stashpad inputs used four global
  `[class*=…]` selectors evaluated against every element in the document; it is
  now scoped to the plugin's own containers and popovers.
