# 0.206.1

- **A folder claimed by another plugin now excludes everything beneath it, not
  just the folder itself.** This matters for conversion backups: a backed-up
  Stashpad folder still looks like a Stashpad folder, and can contain
  note-bearing subfolders of its own. Those subfolders were only being skipped
  by the underscore-prefix rule, which is a user setting — so a user who
  cleared it could see backup copies appear alongside their live folders.

---

This release also includes **0.206.0**: a per-folder recovery snapshot
(`.stashpad-structure.json`) recording each note's id, parent, created date and
path, plus a **"Repair lost note frontmatter from the folder's structure
snapshot"** command. If a note ever loses its frontmatter — a bad merge, an
over-eager find-and-replace, a sync conflict — it becomes an anonymous orphan;
the snapshot is what puts it back, matching by file path since that's all that
survives. It's a photocopy, never the source of truth, and an entry is only
dropped once the note's file is actually gone, so the damage can't erase its own
recovery record.
