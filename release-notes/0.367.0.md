# 0.367.0

## Hide built-in menu items instead of deleting them

Built-in right-click / ⋮ menu items and submenus can't really be deleted — they come back on restart (they're seeded defaults). That made "delete" confusing. Now you **hide** them instead, which sticks.

- In **Settings → the right-click / ⋮ menu**, each built-in item or submenu shows an **eye** button to hide it (and eye-off to show it again). Hidden rows read muted and struck through. A hidden submenu drops from the menu entirely.
- Commands you added and submenus you created yourself keep the **✕** to remove them outright.
- The submenu editor offers **Hide** instead of **Delete** for a built-in submenu.
