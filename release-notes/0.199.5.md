# 0.199.5

- **Importing a markdown file no longer loses its filename.** The original
  filename now lands on the note's first line as a `# Heading 1` (followed by
  a blank line), and the usual filename processing runs from there — so the
  note is *named* by the file and its content follows. Skipped when the note
  already opens with an equivalent line ("My Note" matches `my-note`), and for
  re-imported Stashpad notes (their filename is just slug + id, not
  information). Applies to single-file and folder imports; attachments were
  already safe (their filename becomes the note title).
