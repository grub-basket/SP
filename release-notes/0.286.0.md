# 0.286.0

Multiple highlight colors, a smarter drag model, and reply/duplicate-panel polish.

## Highlight colors (0.284.0)

Copies Obsidian Insider's colored-highlight feature and makes the picker smarter.

- On disk a highlight's color is a colored-circle emoji right after the opening
  `==` — `==🔴red text==` — the exact syntax Obsidian Insider uses, so notes
  round-trip with its native feature.
- **Composer picker:** typing `==` in the composer (or the edit modal) opens a
  color menu — Default, Red, Orange, Yellow, Green, Blue, Purple — with arrow-key
  and mouse selection. This is the real addition, since Obsidian's own `==` menu
  only works in its editor, not Stashpad's plain-textarea composer.
- **Smart filtering:** typing after `==` filters the menu by color name
  (`gr`→Green); a token that matches no color dismisses the menu so a plain
  highlight just continues. Accepting inserts the emoji right after the `==` with
  the caret ready to type.
- **Rendering:** on Obsidian 1.13+ the color renders natively; on older Obsidian
  a fallback strips the emoji and tints the highlight. Six translucent, theme-aware
  tints; plain `==highlight==` keeps the default yellow.

## Whole-row grab area (0.285.0)

Replaces the enlarged-grip approach. With "Select text in notes" on (desktop,
nested mode), the **whole row is a drag handle except its interactive/text
zones**: a press on dead space (meta-column whitespace, the timestamp, the grip,
padding) drags the row to reorder, while a press on the body text, a link, a
button, the checkbox, a reaction, or the author link selects/clicks as normal.
The reserved-zone list is a single documented source of truth so the behavior
stays predictable as rows gain new controls.

## Reply + duplicate-panel polish (0.286.0)

- **Per-item Reply button:** each desktop note row gains a dedicated reply
  (left-curving arrow) button beside edit/open/more, starting a quoted reply to
  that note — previously reply was only in the context menu and command palette.
- **Full-width composer panels:** the reply quote and the "Similar notes"
  duplicate-hints panel now stack full-width **above** the composer input instead
  of sitting beside it and halving its width.
- **Keyboard-navigable duplicates:** the "Similar notes" results are focusable —
  Shift+Tab from the composer reaches the panel, Arrow Up/Down move between
  results (Up past the first returns to the composer), Enter/Space opens the note,
  and Escape returns focus.

## Fix

- **0.283.3:** reverted the 0.283.1 tab-title centering rule — a `flex:1` tab
  title fills its width, so centering had no visible effect; tab titles render as
  the app defaults again.
