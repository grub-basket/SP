# 0.176.0

A batch of features and fixes since 0.170.5 — task shortcuts, attachment
navigation, folder-open behavior, a mobile editor pass, and reminder/header fixes.

## Tasks

- **Type a checkbox to make a task.** Start a note with `[]` or `[ ]` and it's
  created as an open task; start it with `[x]` (or `[X]`) and it's created already
  completed. The prefix is stripped from the note body, so the title stays clean.
- **Open all tasks with a shortcut.** New bindable **"Open all tasks"** command
  (default **Shift+T**) jumps straight to the aggregate "All tasks" view that
  collects tasks across every Stashpad folder.

## Attachments

- **"Open in Stashpad" now works on attachments.** Right-click any non-markdown
  file (image, PDF, …) in the file explorer and pick **Open in Stashpad** to jump
  to the note that embeds it. If several notes embed the same file, you get a
  picker listing the parent notes to choose from. The "Open this note in Stashpad"
  command also works when an attachment is the active file.

## Folders

- **New setting: "Folders always open in a new tab."** (Behavior → Windows &
  Tabs, off by default.) When on, opening a folder — from the folders panel, the
  folder switcher, or the file-explorer "Open folder in Stashpad" — always opens a
  fresh tab at the home note instead of reusing an already-open tab, and the folder
  switcher drops its "Reveal <folder> tab" entry in favor of a plain "Open in new
  tab."

## Editing on mobile

- **The in-app Edit / Split modal is usable on a phone now.** It becomes a
  full-height sheet with a scrollable body and a **pinned action bar**, so Save /
  Cancel / Open-in-a-tab stay reachable above the keyboard instead of being pushed
  off-screen, and the modal no longer overflows the screen.

## Reminders & the focused-note header

- **Due-reminder notifications are now tappable.** Tap anywhere on a task-due
  reminder to open the task; a small **Snooze** button in the corner opens the
  scheduler instead (to reschedule / reassign) without opening the task.
- **The focused-note header regained its expand/collapse toggle** on desktop —
  and expanding it now actually shows the full note (it was still capped to a few
  lines before).

## Other

- The **Open Stashpad link** dialog shows a green "Link automatically pasted from
  your clipboard" confirmation when it auto-fills a link it found on your
  clipboard, so the pre-filled field isn't a surprise.
