# 0.415.0

Covers 0.407.0–0.415.0.

## Replies
- **Nest Replies** — a command + chooser to tidy a reply thread: nest replies under the selected note(s), nest the selection into what they reply to, or nest every reply in the current list under the note it replies to. Moves are undoable.
- The **"Reply to" quote block** gains an **expand button** that opens the replied-to note in the file-preview modal (read it without scrolling to it).
- Clicking a reply link (the "N replies" chip or a quote) now **reveals and cursor-selects** the target note in the list.

## File preview
- **Quick capture** — a "+" button (and a command) captures a note that nests under the previewed note; toggle it off to pick any destination with the note picker.
- **Open in a new window** — opens the current file in a new Obsidian window.
- **Mouse back/forward** page the preview (prev/next slide).
- The text-note thumbnail in the rail is now a clearer accent-coloured badge.

## Other
- Moving a Stashpad tab between windows (popout ↔ main) no longer kills that tab's list hotkeys.
- The **detail panel** now honors the obscure **schedule** (clear off-hours, like the list) and the chosen conceal **method** (solid/shape, not always blur).
- **Find-in-list** rendering is debounced (no re-render on every keystroke); a **desktop search-scope ribbon** icon runs the current scope on click and cycles it on right-click.
