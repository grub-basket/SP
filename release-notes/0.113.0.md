# 0.113.0 — Settings now sync across devices

## Fixed: settings didn't sync (Obsidian Sync)
Stashpad stored its settings in a non-standard `.stashpad/data.json` subfolder, which
Obsidian Sync's "Community plugin settings" does not sync — so settings silently failed
to propagate between devices (e.g. desktop ↔ mobile). Now fixed:

- **`data.json` is back at the standard `<plugin>/data.json` path** that Obsidian Sync
  syncs. The `loadData`/`saveData` overrides that relocated it have been removed (the
  inherited standard-path versions are used).
- **One-time, safe migration:** on first launch of this version, an existing
  `.stashpad/data.json` is copied to the standard path (it's the active store, so it
  wins over any stale leftover), a `.stashpad/data.json.bak` backup is written, and the
  old file is retired so it never re-migrates.
- As a result, these now sync across devices: **folder-panel pins, hidden folders, and
  downranked folders**, all **settings toggles**, and **Stashpad's own keybindings**.

Note: make sure Obsidian Sync's "Community plugin settings" option is enabled. After
updating on all devices, settings converge on the standard `data.json` and sync normally.
(Other plugin-private files — the action log, render cache, author registry, and
encryption keyfile — intentionally remain in `.stashpad/`.)

_Internals: settings-storage relocation merged via the `sync-settings` branch._
