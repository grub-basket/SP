# 0.276.4

A batch of task, filtering, mobile, and heatmap improvements.

## Tags in the due-date / assign picker

The due-date / assign dialog gains a **Tags** section: your current tags as
removable chips, one-tap **quick chips** you define in settings, and a
type-to-add box that suggests from your configured list (and accepts any tag you
type). Chosen tags are written to the note. Set them up under
**Settings → Task tag chips / Task tag suggestions**.

It also **prefills the note's author** as an assignee when an author profile
exists and matches — so scheduling your own note doesn't need a manual assign.

## Keep a pinned note's children through a filter

A new option, **"Keep a pinned note's children too"** (off by default): when a
pin keeps a note visible past a filter, its whole subtree stays visible too, so
the pinned note isn't shown with its contents filtered away.

## Task timeline: filter by tag

The timeline gains a tag filter, so you can check on a class of work — "events",
"sagas", product outages, or any tag you group tasks under.

## All notes: Broken links & Stale

Two new filters in the All-notes index: **Broken links** (notes pointing at a
`[[wikilink]]` that doesn't exist — the companion to Orphans) and **Stale**
(notes untouched for more than ~6 months).

## Activity heatmap

- Opens on **today**, so the detail panel shows the day's activity right away.
- New **opt-in "Log note opens"** setting (off by default) adds a **Viewed**
  bucket, so the heatmap can show what you looked at. Local only.

## Mobile

- **Folders panel**: each folder now has a **gear button** that opens its menu,
  and the long-press menu is turned off on mobile so it no longer fights
  drag-to-reorder. (Desktop right-click is unchanged.)
- The **focused heading-note header** no longer crams its title next to the
  timestamp and buttons — the title drops to its own row below, like body notes.

## Quick menu

The star quick-menu's **"More commands…"** now opens the command palette (search)
instead of a longer context menu.
