# 0.451.0

Spans development versions 0.448–0.451.

## Export to image (PNG) — new

- A third export format, **Image (PNG)**, alongside HTML and PDF in the export dialog
  (**Share & export ▸ Export**). Desktop-only (rendered via a hidden window); on mobile
  the dialog offers HTML.
- Exports the selected notes / subtree / thread to a PNG. **Combined** produces one tall
  image; **split each top-level item** produces one image per top-level note and its
  subtree.
- Multi-note image export is supported even when the result is a long image.
- Images embed inline; non-image attachments are still copied to the sibling assets
  folder and linked.
- The default export filename now derives from the collapsed roots — a parent-plus-
  descendants selection names after the parent, sibling selections name as
  `<folder>-<n>notes`.

## Replies — merge & re-point

- Merging a note now **re-points inbound replies** so a conversation stays connected
  after a merge.
- New **"Merge into parent"** command.

## Attachments

- **Folder-wide attachments grid** — a modal showing every attachment in the folder.
- **Attach button in the edit modal.**
