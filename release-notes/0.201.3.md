# 0.201.3

- **Bracket healing is simpler and stricter:** ANY run of three or more `[` or
  `]` collapses to a proper pair at note creation (nothing beyond `[[ ]]` is
  ever intentional in Stashpad).
- **Autopairing covers Markdown now, and its bracket bugs are fixed.**
  - A third `[` no longer re-fires the pair (which used to leave three opens
    and four closes) — it inserts plainly.
  - Backspacing an opener whose closer sits right after the caret deletes
    BOTH: `[[|]]` → Backspace → `[|]` → Backspace → gone.
  - New pairs: `(` `)`, inline `` ` `` code, and the doubled markers —
    `**bold**`, `~~strikethrough~~`, `==highlight==` — pair on the second
    keystroke with the caret between; typing the closer steps over an
    existing one. Single `*`/`~` never pair, so lists and italics type
    normally. The setting is now "Auto-pair Markdown syntax".
- **Mobile paperclip goes straight to the native attachment sheet** — no
  dropzone modal detour on a phone (dropzones need drag-and-drop). Desktop
  keeps the big dropzone.
- **The cross-vault "delete the cut originals?" offer is dismiss-proof.**
  It tended to arrive exactly as you clicked the source window to focus it —
  and that click (or a stray Escape) dismissed it. It now closes only via its
  two buttons.
