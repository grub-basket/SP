# 0.455.0

Pinned notes get a **"Go to parent"** item in their right-click menu (folder panel / pinned sidebar). A vague pin — a bare title with no obvious context — can now be traced to the note it lives under in one click. The parent is resolved via the note's `parentLink` recovery wikilink (with a same-folder id fallback); the item is omitted for pins that sit at the folder root.
