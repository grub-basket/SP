# 0.458.0

New **"Alt-drag selects text"** setting (desktop, on by default). When a note row is whole-row draggable (i.e. the "Select text in notes" grip mode is off), holding **Alt / Option** while you drag over a note now selects its text instead of reordering it. It only affects Alt-held drags, so ordinary drag-to-reorder is unchanged — it's a lightweight escape hatch for grabbing text without switching modes. Complements the existing grip-based text-selection mode.
