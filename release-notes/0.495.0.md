# 0.495.0

**Pasting a range of cells from Excel now drops a Markdown table into your note — not a picture of the cells.**

## 0.495.0 — paste from Excel drops the table, not a picture

- **The bug.** Copying cells in Excel (and Google Sheets, Numbers, LibreOffice
  Calc) puts the data on the clipboard twice: once as an HTML table plus
  tab-separated text, and — on macOS especially — once as a rendered PNG *image*
  of the cells. Stashpad's paste handlers read the file/image first, so the image
  won and the actual table was thrown away.
- **The fix.** A new converter (`src/excel-paste.ts`) recognises a spreadsheet
  paste — the reliable signal is an HTML `<table>` on the clipboard, which every
  spreadsheet app emits and a screenshot does not — and turns it into a
  GitHub-flavored Markdown table *before* the image is considered. Both paste
  surfaces use it: the composer and the note-body editor.
- **What still works unchanged.** A screenshot, a file copied from Finder/Explorer,
  and a plain-text (Shift+Cmd+V) paste are untouched — the converter steps aside
  when there is no table on the clipboard, so those fall through to the normal
  image/file handling.
- **Conversion details.**
  - Cells with embedded line breaks become `<br>` inside the Markdown cell; `|`
    characters are escaped so they don't split columns.
  - Columns are padded to the widest cell for a tidy, readable table.
  - An optional `^l` / `^c` / `^r` prefix on a header cell sets that column's
    alignment (left / center / right) and is removed from the heading text.
  - Quoted multi-line and quoted values with embedded quotes are parsed correctly.
  - A table copied straight from a web page is converted too; a single cell or a
    single column pastes as its text (still the data, never an image).
- **Credit.** The conversion is adapted from the
  [Excel to Markdown Table](https://github.com/ganesshkumar/obsidian-excel-to-markdown-table)
  plugin by Ganessh Kumar R P (MIT), with the robust quoted / multi-line cell
  parsing borrowed from the sibling plugin GridSense. Both are acknowledged in the
  README.
