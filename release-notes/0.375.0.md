# 0.375.0

## 0.374.0 — Note preview modal

- The file-preview viewer can now show the **note itself** as its first slide — the note's markdown rendered and scrollable (embeds, callouts, tags and links render just as they do in a note), with the note's attachments in the rail after it. A new per-row **Preview** button opens it.
- Attachment chips still open their own attachment; the note only ever appears as slide 0, so there's no recursion. Zoom/rotate controls hide on the note slide (it's text, not an image).
- Two independent toggles under **List & Display**: **Note preview button** and **Show more / less toggle** — keep either, both, or read long notes through the modal with inline expansion turned off. Both on by default. Hiding the preview button doesn't remove the note slide from the modal; you still reach it by opening any attachment.

## 0.375.0 — Markdown table assists

- Editing a Markdown table in the composer or the edit/split editor now helps you keep it tidy:
  - **Tab / Shift+Tab** move to the next / previous cell (selecting its text), and **Tab past the last cell** appends a new row.
  - The table **re-aligns** its columns automatically as you move, so the raw markdown stays readable.
  - **Enter** adds a new row (and **Enter on an empty row exits** the table) wherever Enter inserts a newline — the edit editor, or the composer in shift-enter-submits mode. In the composer's default Enter-submits mode, Enter still sends the note and you build the table by Tabbing.
- Only a real table (one with a `|---|` delimiter row) is touched — a stray pipe in prose is left alone. New setting **Markdown table assists** (Composer & Copying, on by default).
