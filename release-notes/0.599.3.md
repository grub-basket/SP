# 0.599.3

This release covers every change since 0.589.0:
- **Move a folder** into another folder, and **merge** one folder into another, from the main view.
- **A gear next to the folder button** opens the folder's menu without the sidebar.
- **Edit times update for everyone**, not only people who set an author name.
- **Less clutter:** one date per note, and a composer hint that teaches the Space shortcut.
- **Fixes for two tabs on one folder, synced devices, and Obsidian 1.14's New tab screen.**

## Highlights

- **Folder gear.** A gear sits flush against the right of the folder button at the top of a Stashpad. It opens the folder's menu: open in a new tab, reveal, pin or hide, Rename, Move, Edit folder, Merge, encryption and Delete. It is the same menu as the Folders sidebar, so the sidebar is no longer needed to manage a folder. On a phone, the folder switcher has **Manage this folder…** instead, and a narrow toolbar's folded Folder section has it too.
- **Move folder…** puts a Stashpad folder inside another folder, or back at the top of the vault. The list only offers places where it can still be a Stashpad (not inside another Stashpad, not in an archive). The open tab, pins, icon, pinned notes and other per-folder settings follow it. A notice offers Undo. Also in the command palette: "Move this folder into another folder…".
- **Merge** is the new name for Fold. "Merge into another folder…" moves all of a folder's notes under a new note in another Stashpad, and Undo puts it back. Unfold is now Unmerge.
- **Move from the breadcrumb.** Right-click (long-press on a phone) a note in the breadcrumb for **Move…**, which moves that note and its children. The Home crumb offers Move folder… and Merge into another folder….
- **Edit times that work.** A note's edit time now updates on every edit, even without an author name set, including the first edit after Obsidian starts and the first edit made in Obsidian's own editor. The details panel shows **Edited** under Created once a note has been edited.
- **One date per note.** A row only says "edited …" when the note was really edited after it was made. The "edited" label now starts switched off for new installs; existing settings are kept.
- **Composer hint.** The empty composer says "Hit Space and start typing…" (Space jumps into it), and "Type a note…" once you're in it. The keys stay in the line underneath. Phones are unchanged.
- **Two tabs on one folder** no longer save every edit time twice, and the second tab no longer records your edits as "edited outside Stashpad". Note history keeps one version per edit (it was keeping two).
- **Synced devices:** an edit that arrives from another device keeps the edit time it was given there, instead of the receiving device writing its own.
- **Renaming or moving a folder** now also carries locked (encrypted) note records, re-lock reminders, pinned notes, recent folders and merge redirects to the new path.
- **New tab screen:** "Open Stashpad" has an icon and the same pill style as the other buttons on Obsidian 1.14, and works with Enter.
- **Conflict copies:** the duplicate-note window spots Dropbox-style copies like "Note (Name's conflicted copy 2026-10-29)" and Syncthing's ".sync-conflict-…" files.
- **Multi-insert marks** in the composer stay inside the text box and follow it when it moves.

## All changes

### 0.590.0
- Multi-insert marks in the composer are clipped to the text box (they could hang over the folder button or the panel above), and follow the composer when it moves (mobile keyboard lift, docked panel, list re-layout). First built as 0.566.0 and renumbered for the merge.
- Review fixes: a session whose composer was closed or hidden ends within a frame instead of at the next key press; mark positions are cached per text and width so a long note with many marks doesn't re-measure every frame.

### 0.591.0
- A note's `modified` time is stamped on every real edit, whether or not an author name is set (it used to be skipped without a name, so the edit time never moved for most solo users).
- The first in-app edit after Obsidian starts counts: the edit-modal save seeds the authorship tracker with the text it is replacing.

### 0.592.0
- The row footer's "edited …" shows only when a note was edited after it was made (it used to fall back to the creation time, repeating the row's own date).
- "Show last edit time in note footer" is off for new installs; existing settings are kept.
- Briefly switched the inline timestamp to a 12-hour clock (later reverted in 0.597.3).

### 0.593.0
- The details panel shows "Edited" (was "Modified") under Created, and only after a real edit.

### 0.594.0
- The empty composer says "Hit Space and start typing…" while unfocused and "Type a note…" while focused; the send/new-line keys stay in the helper line only. Phones unchanged.

### 0.595.0
- New folder gear joined to the right of the folder switcher, opening the folder menu (also in the switcher as "Manage this folder…" and in the folded toolbar's Folder section).
- The folder menu moved out of the Folders sidebar into `src/folder-menu.ts`, shared by the sidebar and the main view.

### 0.596.0 / 0.598.0
- The duplicate-note window recognises conflict copies by a "(… conflicted copy …)" group at the end of the file name (Dropbox style, including device names with their own parentheses) and Syncthing's `.sync-conflict-…` names; a "(conflicted copy)" in the middle of a title no longer counts. Built as 0.596.0, shipped as 0.598.0 (renumbered for the merge).

### 0.597.0
- "Open Stashpad" on Obsidian 1.14's New tab screen uses the same icon + label pill as the other actions, and responds to Enter / Space. Older Obsidian keeps the plain row.

### 0.597.1
- Stashpad's own edit-time stamp is treated as its own write: it is no longer logged as an outside edit, and the row's "edited" label updates without a full redraw.

### 0.597.2
- One edit-time stamp per edit when two tabs show the same folder (it was two).
- An edit that arrives from another device with its edit time already set keeps that time.
- The stamp's "own write" marker is cleared if the write fails.
- Note history no longer stores each in-app edit twice.
- Ticking a checkbox counts as the first edit after a restart too.

### 0.597.3
- The "show last edit" default really is off for new installs (a hard-coded fallback overrode it).
- The inline timestamp keeps its 24-hour format with AM/PM, which sorts correctly in pasted logs.

### 0.599.0
- Renaming or moving a folder also carries locked (encrypted) note records, re-lock reminders, pinned notes and recent / last-used folders to the new path. (It also rewrote merge redirects; taken out again in 0.599.3.)

### 0.599.1
- **Move folder…** in the folder menu (gear, Folders sidebar, phone switcher) and the command palette ("Move this folder into another folder…"). Destinations leave out the folder itself and its insides, its current parent, hidden and reserved folders, and anywhere inside another Stashpad; the move is re-checked when it happens, name clashes are refused, and a notice offers Undo.
- Fold is now called **Merge** (and Unfold **Unmerge**) in menus, commands, pickers, confirmations and notices. Command ids are unchanged.
- The breadcrumb's right-click / long-press menu has **Move…** for note crumbs; the Home crumb has Move folder… and Merge into another folder….

### 0.599.2
- With two tabs on one folder, the second tab no longer logs your edits as "edited outside Stashpad".
- The first edit made in Obsidian's own editor after a restart updates the note's edit time.

### 0.599.3
- Merge redirects are kept on their original paths, so Unmerge and old links keep working after a parent folder is renamed or moved.
- Renames and moves also carry watched / muted folders, the drafts reminder list and the Folders panel's pin times and group order; recent folders no longer repeat; incomplete old entries are left as they are.
- Breadcrumb Move… with a new destination creates it beside the moved note (it used to land inside it, so the move was refused).
- Opening a note in the editor also records its current edit time, so a synced edit arriving while it is open keeps its time.
- A failed write no longer leaves "own write" markers in other tabs.
- Archived notes moving along with their whole folder are not treated as newly archived (no surprise encryption).
- Placeholder name in the conflict-copy examples and tests.
