# 0.202.1

- **Fixed: pressing ↑ in the edit modal jumped the cursor to the end of the
  note.** The arrow keys were still reaching the split view's "move the split
  divider" handler while editing. It moved an invisible divider, rebuilt the
  editor, and the rebuild re-seeded the cursor at the end (the edit surface's
  normal starting position) — while also swallowing the keypress, so the caret
  never moved up. Arrow keys now only touch the divider on the split surface;
  in the editor they move the cursor normally.
