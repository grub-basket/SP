# 0.470.0

This release rolls up every change since 0.458.0.

## 0.470.0 — Behavior settings reorganized
The **Behavior** settings tab is renamed **Behavior & Display** and re-sorted into nine focused sub-sections. The overloaded "List & Display" group (which held over thirty unrelated settings) is split into **List & Display**, **Time Window & Pinning**, **Attachments & Media**, and **Privacy & Obscuring**; the link-preview settings move out of "Composer & Copying" into their own **Link Previews** section; and the two-item "Misc" group is folded into **Composer & Editing**. No setting changed behavior or was renamed — this is purely a regrouping so each preference is easier to find.

## 0.469.0 — Scheduled tidy for duplicate & orphaned tabs
New **Auto-tidy Stashpad tabs** setting (Settings → Maintenance) runs the existing "Close duplicate & orphaned Stashpad tabs" command automatically on an **hourly**, **daily**, or **weekly** schedule (off by default). It catches up on the next launch if a run came due while Obsidian was closed, and waits out the remainder if a tidy already ran within the interval. Scheduled runs are quiet — a brief notice appears only when a tab is actually closed.

## 0.468.0 — Reorder no longer jumps to top
Dragging a note to reorder it no longer scrolls the list back to the top.

## 0.467.0 — Cleaner preview rail badge
The note-preview rail badge is now icon-only, dropping the redundant "NOTE" caps label.

## 0.466.0 — Page Preview on Mod+hover
**Mod+hover** over a note row shows an Obsidian Page Preview of the note's source file.

## 0.465.0 — Loose files always import from the drop subfolder
Loose files placed in the import drop subfolder are now imported regardless of the "auto-import" setting.

## 0.464.0 — Split a mixed note into tasks + prose
A note that mixes checkbox lines with prose can now be split into one task per checkbox line plus a single note holding the remaining prose.

## 0.463.0 — Floating quick capture
A new floating **quick-capture** window lets you jot a note while reading, without leaving your current view.

## 0.462.0 — Jump to a date in the due-date calendar
The due-date calendar gains a day picker so you can jump straight to a specific date.

## 0.461.0 — Nickname a pin
Pins can be given a nickname (`pinAlias`) so a pin with a vague title still reads clearly in the sidebar.

## 0.460.0 — Crop images in the preview modal
The file-preview modal can now crop images, non-destructively.

## 0.459.2 — Reaction settings polish
Reaction settings show always-visible (greyed) reset buttons and update results live as you search.

## 0.459.1 — Manage reaction Favorites & Presets from Settings
Reaction **Favorites** and **Presets** can now be managed from Settings → Note Actions & Menus.

## 0.459.0 — Drafts count, preview toolbar, emoji picker
- Accurate composer drafts count with a consistent draft notice, and a responsive preview toolbar.
- Emoji picker: presets stay visible in Edit mode, favorites are packed, and the "All" list is capped for a tidier picker.
