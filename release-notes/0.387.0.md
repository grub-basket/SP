# 0.387.0

Covers 0.380.0–0.387.0 — a batch of bug fixes and two small keyboard/clipboard features.

## 0.380.0 — Preview button layout on mobile
- Fixes the per-row **Preview** button spilling below the note body on mobile. The non-compact mobile note is a named-grid-area layout, and the Preview button (added in 0.374.0) had no assigned slot, so it fell into an implicit row under the body. It now has its own top-row column (`meta · toggle · react · quick · preview · more`).
- The Preview button is sized to match its neighbours (22px box / 15px icon, `flex-shrink:0`) so it reads at the same visual weight. Desktop was unaffected.

## 0.381.0 — List-pin menu labels reflect state
- The "Pin to top of list" / "Pin to bottom of list" context-menu items now flip to **"Unpin from top/bottom of list"** (with a pin-off icon) when the note is already pinned to that edge, matching the sidebar Pin/Unpin item. Previously they kept the "Pin to…" label with only a checkmark, which read as still-unpinned.

## 0.382.0 — Modification time only changes on a real edit
- Saving a note whose body is unchanged no longer rewrites the file or bumps its modification time. The Save chokepoint now returns early when the (trailing-whitespace-stripped) body matches what is already on disk, so a no-op Save — or one that differed only in a trailing newline — is a true no-op.

## 0.383.0 — Debug modal copy button
- The composer-debug modal no longer selects all of its text on open. The select-all was swallowing the first tap on the **Copy** button on mobile (the tap collapsed the selection instead of activating the button), making copy appear to require a manual selection first.
- Copy now uses the async clipboard API (no text selection needed) and only falls back to `execCommand` if that rejects; success is reported only once the write actually resolves.

## 0.384.0 — Preview keyboard shortcuts
- **Shift+Space** previews the selected/cursor note; **Mod+Shift+Space** previews the current list's home (focused) note. Both are full commands — bindable in Stashpad's hotkeys and exposed in the command palette.
- Enables the **Space** key to be used in a chord at all: its `KeyboardEvent.key` is a literal space, which a chord's `+`-split would drop, so `Shift+Space` could not previously be matched or recorded. Space now normalizes to a stable token in both the key matcher and the hotkey recorder.

## 0.385.0 — Copy link(s) from a note
- New **"Copy link(s) from note"** command — the counterpart to "Copy code from codeblock", but for hyperlinks. Copies the first link in the cursor row's note; when several exist it opens a picker whose first entry is the first link, plus a "copy all links (one per line)" option. Extracts markdown links, angle-bracket autolinks, and bare `http(s)`/`mailto` URLs in document order (internal `[[wikilinks]]` are excluded). Bindable (default `}`, the sibling of the codeblock command's `{`) and in the palette.

## 0.386.0 — Preview modal dismisses on action
- Invoking an action from inside the note-preview modal's ⋮ menu (Edit — which routes to the composer, edit modal, or a tab — as well as Move, Reply, and others) now dismisses the preview modal first, so the action's surface is not opened hidden behind it. This lets Edit-in-composer and any action that needs the underlying list (moving a note, selecting others) work from the preview.

## 0.387.0 — Space no longer swallowed by the composer
- A chorded Space (**Shift+Space**, **Mod+Shift+Space**) is no longer captured by the list-focus "Space focuses the composer" handler, so the new preview shortcuts fire as intended. A bare Space still focuses the composer unchanged.
