# 0.471.0

## Composer — slash commands anywhere, and a `>` destination trigger
- **Slash commands fire mid-line.** Typing `/` no longer has to be at the start of a line to open the Stashpad command menu — it now triggers at any word boundary (start of line or after a space), the same rule the `#` and `@` triggers use. Mid-word slashes are still ignored, so URLs (`http://`), `and/or`, `24/7`, and dates like `9/22` never open the menu.
- **Type `>` to route a note to a folder.** Start a token with `>` in the composer to pick an existing Stashpad folder for the next send — e.g. `>Filing Cab` offers *Filing Cabinet*. It only ever lists folders you already have (it cannot create a new one), multi-word folder names work, and picking one strips the `>query` and sets the destination just like the destination menu. A Markdown blockquote (`> ` with a trailing space) and a bare `>` never open it, and a `>word` that matches no folder is left as ordinary text.

## 0.470.2 — Mobile: composer no longer shows above an open sidebar drawer
On a phone, opening a sidebar drawer while the composer was focused could leave the composer's text cursor painting above the drawer, with the keyboard still up (which also made the drawer stop short of the screen bottom). The composer is now reliably released when a drawer, modal, or menu opens over it, so the caret and keyboard go away and the drawer covers the full height.
