# 0.279.1 — Cleaner attachment links + small fixes

## Attachments
- **Pasted / imported attachment links are cleaner.** Links now use the file's
  plain basename, and the source note is deselected once the new note is created,
  so you're not left with a stray selection after an attachment lands.
- **The attachment name-prefix now defaults OFF.** New attachments keep their
  original filename by default instead of getting a prefix; turn the prefix back
  on in settings if you prefer it.

## Fixes
- Added a clear settings heading for the copy-with-timestamp option.
- Guarded the composer caret on mobile so it no longer jumps unexpectedly.
