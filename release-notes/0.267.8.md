# 0.267.8

Obscuring — the blur that hides a note's text on screen — grew a global switch,
per-folder defaults, and a tappable control on every hidden note.

Obscuring has always been **visual only**, and still is. The text is unchanged in
the file, and it still appears in search, in Obsidian's editor, in sync, and to
every other plugin. It stops someone glancing at your screen and nothing more.
Real privacy is the per-folder encryption feature, which this is deliberately
never called.

## Cover everything, in one action

Two new commands, so the switch is reachable from the command palette or a
hotkey rather than four taps into settings:

- **Cover (obscure) every note everywhere** — covers every note in every folder.
- **Uncover every note** — turns it back off.

Two commands rather than one toggle, deliberately. Under the circumstances this
exists for — someone walked over, you handed your phone across — a hotkey that
toggles can *uncover* everything on a second press, and that is the one outcome
that should not be a keystroke away. Covering is idempotent: press it again and
nothing changes.

There is a matching switch in Settings.

**It overrides everything while it is on**, including a folder set to Never and a
note set not to obscure. A switch that covers most things cannot be trusted at
the moment it is needed, and that moment does not allow for checking which notes
opted out. Nothing is rewritten — the switch outranks the other settings rather
than editing them — so everything returns exactly as it was when you turn it off.

Notes you had already revealed are covered again too, rather than staying
visible through the switch.

## Per-folder defaults

A folder can start its notes covered. Set it from the folder's right-click menu
in the folder panel, or from Settings, where every folder is listed at once:

- **Follow global** — no opinion; obeys the vault-wide switch.
- **Always obscure**
- **Never obscure**

Always and Never are explicit answers that a single note can still override —
useful for a folder that is covered by default with one note you want readable,
or the reverse.

## Every hidden note has a control

The small "hidden" marker on a covered note is now a **button**. Tap or click it
to peek at the note, and again to cover it back up. It sits after the timestamp
and the drag handle, and stays readable while the note itself is blurred.

It changes only what is *shown*, never whether the note is obscured — so it
cannot make itself disappear, and it never writes to your note. Changing whether
a note is obscured at all is a separate, deliberate action in the right-click
menu, which now names the current state rather than offering a bare toggle:
*Obscure this note* / *Stop obscuring this note* / *Hide this note again*.

Tapping the button will not open the note, and a double tap on it simply toggles
twice rather than drilling in.

## Fixes

- Obscuring several notes at once now covers all of them. It previously covered
  only the ones whose metadata happened to refresh first, so a selection of five
  might show two covered.
- Obscuring a single note, with no global or folder default in play, no longer
  appears to do nothing.
- Tapping the hidden button no longer scrolls the list — only the affected note
  is repainted, rather than the whole list re-rendering.
- The focused note at the top of the list is covered along with everything else.
  It was previously left readable, which rather defeated the point.
- Undoing a change to a note's obscured state restores it exactly, including the
  case where the note had no setting of its own to begin with.

## Performance

Measured with 126 covered notes on screen at once: frame times during scrolling
are unchanged, 16.7ms either way. The cost scales with how many notes are
*visible*, not how many exist, because rows render as you reach them.

## Where the cover applies

The global cover is **per-device by default**, with a setting to sync it across
devices instead.

It is about the screen in front of you — someone is reading over your shoulder,
or you are handing your phone across — and that is not a fact about the vault.
Synced, covering your phone would also cover a desktop nobody is standing near,
and uncovering there later would uncover the phone. Set it to **All devices** if
you would rather cover everything everywhere at once.

Switching between the two carries the current state across, and a device that
has never set the switch inherits the synced value — so changing this can never
uncover something that was covered a moment ago.

## Compatibility

The debug trace now reads Obsidian's version from the plugin API rather than the
browser user agent, which is both the documented source and a community-plugin
requirement.
