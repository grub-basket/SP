# 0.528.3

Covers 0.528.2 and 0.528.3. Both change when the one-time note-id quoting sweep from 0.527.0 runs.

## 0.528.2

- **Safer timing for the note-id quoting sweep.** It used to run about 5 seconds after Obsidian started. Now it waits until Obsidian has finished indexing the vault, then waits about 2 more minutes, so a sync service (Obsidian Sync, iCloud or a network drive) has time to finish downloading notes first. This avoids sync conflict copies.
- On mobile, the sweep only runs while the app is in the foreground. If the app is in the background, it waits until it's brought back.
- If Obsidian closes or the plugin is turned off before the sweep runs, it's cancelled cleanly and runs in a later session. A sweep that's already running stops between notes and finishes next time.

## 0.528.3

- **Partial runs retry weekly.** A run where every note was quoted (or safely skipped) marks the sweep as done; after that, only Rebootstrap quotes ids. If any note fails, the run date is saved and the sweep tries again at the next startup at least 7 days later, until a run completes.
- Notes skipped as unsafe to quote (for example ids with leading zeros, like `007`) count as handled. Their paths are now listed in the action-log entry (up to 50, plus a count of the rest).
- Devices that already completed the sweep stay completed.
