# 0.456.0

A flat-view **"make this a child of…"** row button. In Flat and Everything views the tree structure isn't visible, so each note now carries a small button (a corner-down-right arrow, the structural counterpart to Reply) that opens the fuzzy note picker and re-parents the note under whatever you choose. Hidden in Nested view, where nesting is already visible and drag-to-nest is available. Re-parenting goes through the same cycle-guarded `changeParent` primitive as every other move.
