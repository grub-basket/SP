# 0.454.0

## Read-only canvas preview in the file-preview modal

Opening a `.canvas` in the file preview now shows a real, scaled overview of the canvas instead of a plain file card.

- The canvas is parsed from its JSON and drawn as a fit-to-stage, read-only overview: each node is placed where it sits on the canvas, text nodes render their markdown, file nodes show a type icon and filename, link nodes show their URL, and groups render as a labelled frame behind their members.
- Node and edge colours are preserved (the canvas colour presets and custom hex colours).
- Edges are drawn as connecting lines between nodes.
- A badge shows the node and edge counts and marks the preview read-only, with an **Open canvas** button to jump to the real, editable canvas.
- Large canvases stay responsive (markdown rendering is capped past 60 text nodes); a malformed or empty canvas falls back to the file-fact card.

This replaces the canvas identity card added in 0.453.0. `.base` files continue to render their live table view in the preview.
