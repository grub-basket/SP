# 0.540.2

This release covers every change since 0.539.0. On desktop, long notes now use the full width of the list once their text gets past the buttons at the top right of each note. On a narrow list the buttons get out of the way entirely. Hidden notes all take the same compact height.

## Updates

- **0.540.0** — **Long notes flow under the note buttons (desktop).**
  - Each note's buttons used to take a column down the whole right side of the note. A long note stayed squeezed into the space beside that column for its full length, which was worst in a narrow window.
  - The buttons now sit in the top-right corner of the note. When you expand a note, the lines below the buttons use the full width.
  - The buttons are the same size as before, and notes have the same spacing. Collapsed notes look the same as before.
  - **Narrow list (700px wide or less):** the buttons are hidden and the text gets the whole width. Point at a note, or move keyboard focus into it, and the buttons appear as a small toolbar over the note's top-right corner.
  - On a touchscreen without a mouse pointer, the buttons always stay visible (the wide layout above), since there is nothing to hover with.
  - An expanded note still scrolls inside its own window after 16 lines. The buttons now scroll with the note's first line inside that window.
  - Hidden notes: the blur and the solid cover apply to the note text only, never to the buttons. With the solid cover on, a hidden note keeps the buttons in their own column, so the cover doesn't run behind them.
  - Mobile is unchanged.
- **0.540.1** — **Hidden notes take one fixed height.**
  - A hidden note that hasn't been revealed is now always two lines tall, however long the note is. Hidden notes no longer show how long they are, and an expanded hidden note no longer shows up as a large blank block.
  - Its **Show more** button is hidden until the note is revealed, since it would do nothing.
  - Revealing a hidden note brings back its normal height.
- **0.540.2** — **Fix: compact mode.** The fixed height for hidden notes no longer applies in compact mode. Compact rows are already all the same height, and the extra height had pushed a hidden note's text up and clipped it.

## Internal

- On desktop, each note row now wraps its body and its button group in one element, `.stashpad-note-main`, and the row carries `.is-wrap-actions`. The button group floats right inside that element. The row's grid drops its right-hand column.
- The expanded-note scroll limit moves from the note text up to `.stashpad-note-main`, because a scrolling box can't wrap around buttons outside it.
- Narrow mode uses a CSS container query on the view's scroll host, inside `@media (hover: hover)`.
- The hidden-note height is CSS only. The list's virtual scrolling measures rows as they're drawn, so it needs no change.
- Merged the feature branch into main. Developer coordination notes were updated twice; they don't ship in the plugin.
