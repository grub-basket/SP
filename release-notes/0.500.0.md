# 0.500.0

Authorship, team notifications, and rich paste. Four changes since 0.496.0.

## 0.497.0 — Author rename history no longer records a per-character trail

Renaming your author name in Settings → Authorship recorded a separate rename
event for every keystroke, so the "Known Authors" list showed a junk trail like
`Renamed: J → Jo, Jo → Joh, Joh → John`. `saveSettings` runs on every keystroke
and was appending to the registry's rename history each time.

- The registry now updates the stored name **silently** on save and records a
  single rename event only on **commit** (blur / Enter), or when you rename your
  author page file in the vault.
- Existing junk trails can be wiped per-author with the new **"Clear history"**
  button (below) or by rebuilding the registry.

## 0.498.0 — Paste preserves rich formatting (HTML → Markdown)

Pasting formatted content — from a chat, a web page, a document — into the
composer or the edit box previously dropped all formatting and pasted plain
text. Stashpad's editors are plain text areas; the paste handler only read the
HTML clipboard to extract spreadsheet tables.

- Rich paste now converts the HTML clipboard to Markdown (bold, italics, links,
  headings, lists, etc.) using Obsidian's built-in converter, in both the
  composer and the edit box.
- Plain text still pastes as plain text — no needless escaping of characters
  like `*`, `_`, `#` — and spreadsheet/table pastes are unchanged.

## 0.499.0 — Identity switching and author-registry management

Editing your name in Settings **renames** you (keeps your author id, updates
your notes). New, distinct operations for becoming a *different* author — for the
case where a config folder was cloned from a coworker and now belongs to someone
else — none of which rewrite existing notes:

- **New identity…** mints a fresh author id under a name you enter.
- **Adopt existing…** takes over an author id already in the registry.

The "Known Authors" list gains per-author actions:

- **Merge…** reassigns every author / contributor / assignee link for one author
  onto another across the whole vault (each note's folder path is preserved so
  links keep resolving), removes the source from the registry, and is
  **undoable** from the Stashpad list immediately after. A confirmation shows how
  many notes will change.
- **Set as me** adopts that specific identity.
- **Clear history** wipes an author's rename history.
- **Forget** removes an author from the rebuildable registry (notes are never
  touched; Rebuild re-adds anyone still referenced).

## 0.500.0 — Team notifications on a shared network-drive vault

If a vault is shared over a network drive and each person runs their own Obsidian
config, teammates' notes written on another machine did not raise any
notification. Obsidian's file-change events do not travel between machines over a
network share, and the team-notify feature listened only to those events, so a
note created on another computer was never seen.

- Adds a periodic re-scan that does not depend on file events: it checks your
  watched (or all Stashpad) folders for notes new since the last pass and
  notifies for them, so activity from other machines is picked up even without a
  live file event. Tunable via **Settings → Notifications → "Network-drive check
  interval (seconds)"** (default 90; set 0 to turn the scan off for a purely
  local vault).
- Each machine still needs team notifications enabled, desktop notifications
  enabled, and the operating-system notification permission granted.

*Note: the poll logic (deduplication, catching notes regardless of age) is
verified, but the cross-machine behaviour on a real network share could not be
reproduced in testing — treat the network-drive notification fix as attempted
and confirm it on your own shared-drive setup.*
