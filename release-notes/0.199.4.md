# 0.199.4

- **Color picker: keyboard navigation now works in secondary windows.** With
  the picker open in a pop-out window, arrow keys / Enter / Escape did nothing
  — Obsidian's keymap scope doesn't receive key events there (verified with
  trusted input events). When the modal lives in a secondary window it now
  binds its own key handlers on that window's document; main-window behavior
  is unchanged (single, scope-based handling).
