# 0.272.5

## Fixes a repeated large sync after a rebootstrap

A full rebootstrap writes recovery links into each note's frontmatter. One of
those, the list of a note's children, was written in an order that could differ
between devices, so two synced devices kept rewriting it back and forth, each
seeing the other's copy as a change. That showed up as Obsidian doing a large
sync again and again even though it reported being fully synced, without any new
notes.

The list is now written in a fixed order, identical on every device, so it is
written once and then settles.
