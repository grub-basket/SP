# 0.207.1

- Internal: the per-folder sidecar files Stashpad writes beside a folder's
  notes (`.stashpad-order.json`, `.stashpad-sort.json`,
  `.stashpad-structure.json` and its rotated previous generation) are now
  enumerated in one canonical list that each store derives its filename from.
  No behaviour change — it exists so tools that walk, back up or convert a
  Stashpad folder have a single accurate list to work from, since these are
  dotfiles that Obsidian's vault API cannot see.
