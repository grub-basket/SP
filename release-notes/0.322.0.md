# 0.322.0

## Recent and saved searches

The search box now remembers where you've been:

- **Recent searches** appear when the search box is empty (this device), newest first — pick one to fill the box and run it again.
- **Save a search**: type a query and choose "Save this search" at the bottom. Saved searches (synced across your devices) sit at the top of the empty search with a star, and each has a ✕ to remove it. Picking one fills the box.
