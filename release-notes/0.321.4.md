# 0.321.4

Small polish for the right-click / ⋮ menu builder and the command-icon settings.

- **Reset asks first.** Resetting the ⋮-menu to its default now shows a confirmation.
- **Dividers.** An **Add divider** button drops a divider into the menu, and creating a new submenu adds a divider before it by default so it reads as its own group.
- **Command icons layout.** The custom **Other commands** list now sits at the top of the Command icons section (that's where a command you add appears), with a note that the rest are Stashpad's built-in actions.
