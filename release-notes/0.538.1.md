# 0.538.1

This release covers every change since 0.537.2. When a folder shows no notes, the page now helps you find out why. It says when files on disk aren't showing as notes, and a button copies a diagnostic report you can send to the developer before reloading.

## Updates

- **0.538.0** — **Expected notes here?** and **Copy diagnostic report** on the empty folder page.
  - The **This Stashpad is empty** page has a new section below its usual buttons, separated by a line. It says that if the folder shouldn't be empty and no filters are on, you should copy a diagnostic report before reloading and send it to the developer. Copy it first, because reloading usually makes the problem go away.
  - Filters are already handled: when filters hide notes, the highlighted "hidden by filters" card from 0.537 appears instead of this page.
  - The report is plain text. It shows at which step the notes went missing:
    - markdown files on disk
    - files Obsidian has read
    - files with a Stashpad id
    - notes Stashpad has loaded
    - notes at this level
    - notes on screen
  - It also includes:
    - the Stashpad and Obsidian versions and the platform
    - the folder and view mode
    - whether Obsidian was still reading the vault
    - any active filters
    - whether list updates were paused
    - the last 40 lines of captured errors
    - the last 60 debug-trace lines, if the debug trace is on
  - The report includes no note contents. Error lines can include file names, and the page says so.
  - New command: **Diagnostics: copy missing / empty folder report**. It copies the same report for a list that looks wrong but isn't completely empty.
- **0.538.1** — The empty page tells you when files aren't showing, and **Diagnose selection** reports more filters.
  - If the folder has more markdown files than Stashpad has notes, for example while notes are still loading from a slow drive or when the files aren't Stashpad notes, the page now reads **No notes are showing**. It says how many files aren't showing and why that might be, and offers **Copy diagnostic report** as its main button.
  - That page leaves out the first-run tips and the **Load example content** button. That button adds example notes to the folder, which is only safe when the folder really is empty.
  - **Diagnose selection (select-all mismatch)** now lists the day filter and the text in Find among its active filters.

## Internal

- New `buildEmptyFolderReport` / `copyEmptyFolderReport` on the view, and the command `stashpad-copy-empty-folder-report`. The report copies through the same clipboard helper as other copy actions and logs an `empty-folder-report` entry to the debug trace.
- The empty-page diagnostic section is shared by both empty-page versions through `renderZeroStateTrouble`.
- The check for files that aren't showing compares the folder's markdown files (the same set Stashpad's note list reads) with the number of notes Stashpad has loaded.
- Merged both branches into main. Developer changelog and coordination notes don't ship in the plugin.
