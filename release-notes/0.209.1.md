# 0.209.1

- **Brackets around empty space stay visible.** Typing internal-link brackets with
  only spaces between them — `[[   ]]` — made the brackets vanish, leaving a blank
  gap where you had typed something. An empty target is not a link to Obsidian
  either (it renders as plain text), so the brackets now stay put.

  The same false positive was fixed in two other places it could do more damage:
  an embed written as `![[   ]]` was treated as an attachment reference, which
  removed that text from the note's rendered body; and exporting a note
  containing one produced a spurious "Missing attachment" warning every time.
