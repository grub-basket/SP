# 0.208.0

The first-run experience. Stashpad used to create a folder silently the first
time you opened it and drop you into an empty list with no explanation.

- **A welcome on first run**, shown only when the vault has no Stashpad folder
  yet and you haven't already answered it. It asks before writing anything,
  explains what Stashpad is in a few lines, and offers to load a small **demo
  dataset** so you can see a populated stash instead of a blank one. The demo
  ships inside the plugin — nothing is downloaded.
- **A real empty state** at the Stashpad root, instead of a blank panel, with
  the demo and "start writing" options right there.
- **Creating a folder announces itself.** If Stashpad does create a folder for
  you, it now says so and names it, rather than doing it silently.
- **A "Help & Getting started" settings tab**, including a command list built
  from Stashpad's own command metadata — so it can't drift out of date — and
  the explanation of how folders work, which was previously buried.
- Folder-name inputs are guarded against path traversal.
