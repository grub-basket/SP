# 0.205.0

- **Stashpad no longer claims folders belonging to other plugins.** A folder
  was treated as a Stashpad folder if it held any note with `id` and `parent`
  in its frontmatter — but that's a generic outliner signature, not a Stashpad
  one. Another plugin writing those fields had all of its folders appear in
  Stashpad's folder pickers and panel, and its notes were exposed to Stashpad's
  task, reminder and integrity features (including ones that write back).
- A folder now qualifies only on a signature Stashpad actually owns: its home
  note (`id: __root__`), or the `attachments` field that every note Stashpad
  creates carries.
- If a folder of yours disappears from the pickers — only possible if its home
  note was deleted *and* its notes predate the `attachments` field — right-click
  it in the file explorer and choose "Open folder in Stashpad" to restore it.
