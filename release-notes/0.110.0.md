# 0.110.0 — Granular settings + name-first attachments

## Settings, reorganized
The settings are split from one sprawling **General** tab into focused categories, so
each heading is tightly relevant to what's under it: **Folders & storage**, **Import &
export**, **Note titles**, **Dates & time**, **List & display**, **Moving notes**,
**Deleting**, **Composer & copying**, **Windows & tabs**, and **Maintenance**. The old
**Diagnostics** tab is also split into **Diagnostics** (profiling, debug trace, log) and
a new **Notifications** tab (history limit, per-category mute, history browser). Same
settings and behavior — just easier to find. (Native settings search still matches every
individual setting.)

## Attachments: name-first filenames
New attachments are now named `photo-<id>.png` instead of `<id>-photo.png` — the
readable name comes first and the extension stays last.

- **Rebootstrap migrates existing attachments** to the new format, rewriting the
  `![[links]]` in note bodies and the `attachments` frontmatter as it goes.
- **Link safety:** the migration only runs when Obsidian's *"Automatically update
  internal links"* (Settings → Files & Links) is on. If it's off, Rebootstrap detects
  the old-style attachments but leaves them untouched and warns you to enable the
  setting first — so links are never orphaned. Detection is conservative, so unrelated
  files are never renamed.
