# 0.321.5

## Smart default icons for custom commands

When you add an Obsidian command to a menu or the item buttons without choosing an icon, Stashpad now picks a sensible one from the command's **name** instead of a generic terminal icon. It strips the same filler words it strips from note titles, then takes the first remaining word that is a real icon — so "Open due calendar" gets a calendar, "Copy tree with level markers" gets a copy icon, "Merge selection" gets a merge icon. If nothing matches, it uses a question-mark icon. You can still override any icon in Settings → Note Actions & Menus → Command icons.
