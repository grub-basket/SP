# 0.201.2

- **Edit modal → "Obsidian editor" now saves first, then opens — no prompt.**
  Previously the tab opened immediately and a "Discard unsaved edits?" prompt
  appeared afterwards, over an already-opened (stale) copy of the note. Unsaved
  edits are now written silently and Obsidian opens the up-to-date note. Same
  for the Mod+Shift+E shortcut.
- **Four-in-a-row brackets heal on note creation.** Exactly `[[[[` or `]]]]`
  (the residue of the old autocomplete double-close bug, or a hand-doubled
  close) collapses to a proper pair when a note is created. Runs of three or
  five+ are left untouched, and existing notes are never rewritten.
- **One attachment button.** The composer's paperclip absorbed the dropzone
  button's powers — drop files straight onto it, or click it for the large
  dropzone / file picker. The separate dropzone button (0.199.3) is gone.
