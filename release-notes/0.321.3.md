# 0.321.3

## Move-into-note now follows the note
"Move note into the note above/below" now selects the new parent afterwards, so you see where the note landed — even when the note is set to open its parent in a background tab.

## Build the whole right-click / ⋮ menu
The ⋮-menu is now fully customizable in Settings → Note Actions & Menus. The builder shows **every** item in the menu — the actions, the Task / Share & export / Pin submenus, obscure, delete, dividers — and you can reorder all of them, add any Obsidian command, and **create your own submenus** with a name, icon, and items.

## Command icons update live
Changing a command's icon now updates it everywhere it appears on the settings page at once, and a command you add to any menu shows up in the "Other commands" icon list immediately.

## View launcher ranks names first
Typing part of a view's name brings that view to the top, above views that only match on their description.

## Folder tabs in the launched Pinned view
The "Pinned notes" view you open from the launcher now supports the same **Folder tabs** layout as the sidebar panel (its ⋮ → Folder tabs), sharing the grouping and active tab.

## The calendar projects repeating tasks
The due calendar now shows a repeating task on **every day it will occur** across the visible period, not just its current due date. Projected occurrences appear as dimmed "Recurring" chips with their own legend toggle.
