# 0.283.2

A follow-up to 0.283.1 (the team-features release — emoji reactions, quoted
replies, duplicate-note hints, and teammate notifications; see the 0.283.1 notes
for the full list).

## Fixes

- **Reaction popover styling.** The emoji-reaction popover set its
  `position`/`left` directly in JavaScript with literal values, which the
  community-store review rejects (`no-static-styles-assignment`). Moved
  `position: fixed` onto the popover's CSS classes and folded the viewport-edge
  clamp into a single computed value. No behavior change — the picker still
  anchors to the trigger, flips in from the right edge when it would overflow,
  and stays on-screen.
