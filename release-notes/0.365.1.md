# 0.365.1

## Kanban board polish

A review of all three board modes at a real desktop viewport. Tag and Status boards were already clean; the Color board is where the work landed.

- **In-use columns first.** Columns that hold cards now render ahead of empty palette columns, so the live content leads instead of being scattered among empties.
- **Empty palette columns are compact stubs.** They collapse to a narrow rail (still valid drop targets) and widen back to full width on hover or while dragging a card over them, so a card can still land in any colour without six empty full-height columns dominating the board.
- **Quieter hex titles.** A raw hex column title (no colour alias set) is now muted monospace — the swatch already carries the colour, so the hex reads as data rather than a heading.

## Fixes

- **Empty-state hint now fires for Color.** The "all N notes are in the hidden No-color column — tap Show to reveal them" hint was keyed on column count, and Color always renders its palette columns, so it never appeared for the exact case it was written for. It now keys on visible cards.
- **Undo/redo stay honest after a Refresh.** A board change's undo used to act on a card object that a later Refresh had orphaned, leaving the board stale until the next refresh; it now syncs onto the live row for that file (or re-collects if there is none).
- **Cards are keyboard-reachable.** Each card has a button role and a tab stop; Enter or Space opens the note.
