# 0.132.0 — Task scheduling, unified aggregate/trash/archive views, mobile header & search polish

This release spans everything since 0.122.11: a mobile focused-header redesign,
locked-note search, a full task snooze/scheduling system, unified cross-folder
Trash / Archive / Tasks views with shared filter and view-mode controls, reset
controls and author-aware task filtering, and two new behavior settings for
composer focus and search navigation. Grouped by version below.

## Mobile focused header (0.123.0–0.123.7)

- **0.123.0** — On mobile, the focused-note header replaces the separate *edit*
  and *open-in-new-tab* buttons with the single context-menu (kebab) button,
  matching the note-row affordance.
- **0.123.1** — Use a horizontal kebab in the focused header and fix the clipped
  top edge on the home note header.
- **0.123.2** — Shorten the focused-header kebab button so it can no longer clip.
- **0.123.3** — Give the focused-header kebab more headroom (shorter button plus a
  slightly taller header).
- **0.123.4** — Fix the clipped home-header kebab by centering the actions cluster.
- **0.123.5** — Stop the mobile focused header from clipping its buttons
  (`overflow-y: visible`).
- **0.123.6** — Fix the compact sticky header clipping its button (`top: 0`
  instead of `-12px`).
- **0.123.7** — Final compact-header fix (`top: -4px`) and revert the earlier
  over-corrections.

## Locked-note search & hotkey change (0.124.0–0.124.1)

- **0.124.0** — Encrypted (locked) notes are now findable in search; when a title
  is hidden the search result shows the placeholder instead.
- **0.124.1** — Change the default *Toggle task* hotkey from `H` to `G`, with a
  one-time migration so existing custom bindings are preserved.

## Task snooze & scheduling (0.125.0–0.126.1)

- **0.125.0** — Task **Snooze** (reschedule) reusing the due-date picker.
- **0.125.1** — Configurable quick time-adjust presets with an increment/decrement
  flip, available in both the due-date and snooze pickers.
- **0.126.0** — **Daily review** tasks modal — a roomier surface than the side
  panel for triaging tasks.
- **0.126.1** — Tasks as a full aggregate tab (**All tasks**), sharing the same
  triage renderer as the daily-review modal.

## Unified Trash / Archive / Tasks views (0.127.0–0.130.0)

- **0.127.0** — Unified **Trash** view across all folders, plus task-triage
  filters (by assignment, folder, and status).
- **0.127.1** — Searchable author filter in task triage; snooze button made
  shorter (icon height unchanged).
- **0.128.0** — Trash view modes: *separated*, *mixed-by-date*, *encrypted-only*,
  and *unencrypted-only*.
- **0.129.0** — Unified **All archived** view — plain notes with restore, borrowing
  its structure from the trash view.
- **0.130.0** — Unify the Trash and Archive view-mode chips into one shared control
  and add a **By folder** mode to both.

## Reset controls & author-aware task filters (0.131.0–0.131.2)

- **0.131.0** — Reset controls for the aggregate view chips and the task filters;
  the author list now includes yourself.
- **0.131.1** — Tasks carry and display their author; the filter and the person
  picker now match on author as well as assignee/assigner (most tasks have an
  author but no assignee, so this is what surfaces your own tasks).
- **0.131.2** — De-duplicate the task person filter: the dropdown now selects the
  *relationship* (all / mine / others / by me / unassigned) and the search box
  selects the *person*, so the two no longer overlap.

## Behavior settings (0.132.0)

- **Focus list on open** — new setting (default off): opening or switching into a
  Stashpad view now focuses the note **list** so arrow-key navigation works
  immediately, instead of the composer stealing focus every time. Decoupled from
  the existing after-send autofocus.
- **Search opens note in context** — new setting (default on): picking a search
  result opens the **parent list** and scrolls/cursors to the note, so you land in
  context rather than on the focused-note header. (Cross-folder results keep the
  prior behavior.)

## Build, tooling & internal

- **Release validation** gates every production build — `validate-release.mjs`
  checks that `styles.css` parses, `manifest.json` is valid with all required
  fields, `manifest`/`package.json` versions match, and `main.js` is present and
  parses. Later deepened with additional `manifest.json` and `main.js` checks.
- **`.gitattributes`** — enforce LF line endings and mark binary assets so they
  aren't line-ending-normalized.
- **Tooling** — the `obs-dev` eval helper now accepts bare expressions
  (REPL-style), not just statement bodies.
- Internal development-log and TODO commits (task-scheduling notes, aggregate-view
  suggestions) are omitted from the shipped plugin — no runtime effect.
