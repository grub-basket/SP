# 0.271.7

## Readable aliases from note titles

Stashpad names its files `slug-and-id`, so Obsidian's quick switcher, link
autocomplete, and graph show that raw name rather than the note title. This
adds the title as an alias so those places show something readable.

It is never automatic. You ask for it, one of two ways:

- **Command:** "Create aliases from titles for THIS folder's notes
  (append-only)" adds aliases for the folder you are in.
- **Rebootstrap:** a full rebootstrap now backfills aliases too.

Append-only and safe: it only ever adds the title if it is missing. An aliases
list you have edited by hand is never reordered or pruned, and a note keeps
every alias it already had. The title comes from the note's first heading or
first line; a note with nothing to name gets nothing.
