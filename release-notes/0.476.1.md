# 0.476.1

Rolls up everything since 0.471.0.

## 0.476.1 — Colour shows on the focused heading
Assigning a colour to the note you're currently inside now lights up its pinned heading — a colour swatch in the grip slot plus a colour-tinted heading border, matching the dot list rows already show. It updates the instant you pick a colour.

## 0.476.0 — Code blocks, tables & callouts as rail chips
Each code block, table and callout in a note now appears as its own chip in the attachment rail — like a little attachment for that block. Tap a chip to pop the block out in a preview with a one-click **Copy** (code copies its source; tables/callouts copy their text). New setting **"Code blocks, tables & callouts in the rail"** (Settings → Behavior & Display → Attachments & Media), on by default.

## 0.475.0 — Reorder and hide the built-in row buttons
The built-in buttons on each note row (**Edit / Focus / Reply / React**) now live in the same list as your custom item buttons, so you can **reorder them or hide any you don't use** — Settings → Note Actions & Menus → Item buttons. Existing setups are migrated so nothing disappears; the ⋮ menu stays last. (The mobile row keeps its own compact layout.)

## 0.474.x — Fixes & polish
- **Skip repeating task** is now fully undo/redo, and undoing a skip restores every field it changed — the due date **and** the `missed`/`completed` flags (previously only the due date came back).
- **File-preview copy button** copies *text* now: the note slide copies the note's body, and text attachments (`.md`/`.txt`/`.csv`/code/…) copy their contents. Images still copy the picture; PDFs still copy a link.
- **Reaction/emoji picker** flips upward (or clamps to fit) when opening it near the bottom of the window would push it off-screen — e.g. in the file-preview modal's toolbar.
- **Reading width** in the file preview now applies to text-file slides too, so a plain-text preview is capped and centred instead of spanning the whole window.
- Clamped notes containing **code blocks, tables or callouts** render them properly (they were collapsed/mangled by the line-clamp before), and the **code-block copy button works** in clamped notes — a click used to land on the row footer and do nothing.
- The collapsed focused-header text is a touch larger, reading more like a heading.

## 0.473.x — Composer Escape + code-block copy
- Press **Escape twice in the composer** to exit the current mode — cancel an in-progress edit-in-composer (kept safely in Drafts) or clear a pending reply. A one-shot hint appears on the first Escape.
- Fixed the code-block copy button being unclickable inside clamped list rows.

## 0.472.0 — Similar-note fix
A note you edit in the composer no longer shows up as its own **"Similar note"** suggestion after you save it.
