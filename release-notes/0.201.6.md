# 0.201.6

- **Select text, type a symbol, and it wraps instead of replacing.** Highlight
  a word and press `[`, `(`, `"`, `'`, `` ` ``, `*`, `~` or `=` and the
  selection is surrounded rather than overwritten. The wrapped text stays
  selected, so pressing the same key again nests it — `note` → `[note]` →
  `[[note]]`, `word` → `*word*` → `**word**`. Any other key still replaces the
  selection normally.
- Works identically in the composer and the edit/split editor (both use the
  same shared input layer).
