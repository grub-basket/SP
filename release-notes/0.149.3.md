# 0.149.3

## Folder panel updates live when settings sync in

Building on 0.149.2's cross-device folder-panel sync: a pin, downrank, or hide made
on another device now shows up **without reloading**. Stashpad watches its own
settings file and, when Obsidian Sync (or another window) updates it, adopts the
change and refreshes the folder panel on the spot. Changes you make locally are
unaffected, and there's no risk of a sync loop.
