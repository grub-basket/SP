# 0.470.1

Maintenance release. The floating quick-capture window previously cleared its default bottom-right anchor by setting `right`/`bottom` to `auto` inline. Those static inline styles are now moved into a `.stashpad-floatcap.is-positioned` CSS class that the window toggles once it has been dragged or a saved position restored; the dynamic `left`/`top` coordinates stay inline. No visible behavior changes — this keeps the code within the community store's static-style guidelines.
