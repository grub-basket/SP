# 0.201.5

- **Autopairing now covers quotes.** Double and single quotes auto-close — but
  only at a word start (after a space, line start, or another opener), so
  apostrophes in "don't" and a closing quote typed after a word insert plainly.
  Type-over and Backspace pair-deletion work for quotes like the other pairs.
- Note: the 0.201.3 autopairing (brackets, parentheses, backticks, bold/
  strikethrough/highlight markers) verified working with real key input — if
  it seems dead in your vault, check the plugin is updated past 0.201.3, the
  vault was reloaded, and Settings → "Auto-pair Markdown syntax" is on.
