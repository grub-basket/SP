# 0.254.0

Two additions to the places you type.

## Slash commands in the composer and the note editor

Start a line with `/` and a list of Stashpad's commands appears. Keep typing to
narrow it, Enter to run. The `/` and whatever was typed after it are removed
when the command fires, so nothing is left behind in your note.

- **Every command is there.** The list is read from the same registry the
  Stashpad command palette uses, so anything that has a command has a slash
  command too — including ones added in future releases.
- **Search works like everywhere else** in Stashpad: all terms, any order, case
  insensitive. `/mov note` finds "Move notes".
- **Only at the start of a line.** A `/` mid-sentence is ordinary text — dates,
  file paths, and/or — and a popup interrupting every one of those would be a
  nuisance rather than a feature.
- **Escape dismisses it** and leaves the `/` sitting there as plain text.

Two commands are deliberately withheld: the command palette (you are already in
a command picker) and *Focus the list* (it exists to leave the text field, so
running it from inside one makes no sense). The bar for exclusion is "this is
incoherent from a half-typed line", not "this is destructive" — destructive
commands are undoable and belong here like anything else. Expect that short
list to grow as odd cases turn up in real use.

Turn the whole thing off with **Type "/" to run a command** in settings.

## Dates preview themselves while you are still typing

The `@` trigger used to resolve only a *complete* phrase. Typing `@yest`
offered nothing — you had to finish the word and trust it. Now common relative
phrases are matched as you type and each is shown with the date it resolves to:

```
@yest   →  📅 yesterday   → 2026-08-06
@tomo   →  📅 tomorrow    → 2026-08-08
@       →  📅 today, tomorrow, yesterday, next week
```

Anything typed in full is still parsed exactly as before and ranks first, so
phrases the list does not cover — "3rd of next month", "in 45 minutes" — behave
as they always did.

**These now work without the Natural Language Dates plugin.** Fixed-offset
phrases resolve through a small built-in fallback that formats dates using the
core Templates plugin's date format. When Natural Language Dates *is*
installed it is still asked first, so its date format and its "add dates as
link" setting continue to decide what gets inserted.

One consequence worth knowing: a bare `@` now lists dates for everyone, where
previously it fell through to note links for anyone without the Natural
Language Dates plugin. Type a single character and note matches come back.

## Also fixed

Running a command while composing could restore an **older draft** over what
had just been typed. Draft saving is deferred briefly to avoid a disk write per
keystroke, and commands that change settings prompt the composer to reconcile
itself against the last *saved* draft — so inside that window the stale copy
won. The composer is now saved before a command runs.
