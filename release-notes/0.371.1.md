# 0.371.1

## 0.370.0 — Folder drag-and-drop

- Dragging a **folder** onto the composer, the paperclip button, or the **Add files** dropzone now turns it into a note subtree: a note named after the folder, each file inside imported as an attachment and nested as a child note, and sub-folders recursing the same way. The whole import folds into a single undo (which also trashes the imported attachments), and loose files dropped alongside a folder still attach to the composer as before.
- Desktop-only, by nature: folders are read through the browser File System entry API (`webkitGetAsEntry`), collected synchronously during the drop. This is why an earlier attempt didn't work — a dropped folder leaves `dataTransfer.files` empty, so reading it needs the entry API.

## 0.371.0 — PDF preview reliability + tab focus (PDF loading superseded by 0.371.1)

- Closing a tab spun out of the file-preview viewer ("Open in a new tab") now returns focus to the tab you came from — the Stashpad list — instead of activating whichever tab sits next to it. Applies to every tab the viewer opens (PDF, image, broken-link fallback).
- First pass at fixing blank PDF previews loaded the PDF from an in-memory blob and added a fallback card. The blob-load half was **superseded by 0.371.1**'s layered approach below; the tab-focus fix carries forward unchanged.

## 0.371.1 — PDF preview: layered rendering

- PDF previews now load in three layers, so a blank pane is a last resort rather than a dead end:
  1. **Native** — the fast path, an `app://` iframe (correct filename in the viewer's title bar). Unchanged for everyone it already works for.
  2. **Obsidian's own viewer** — when the native resource comes back empty (seen on some Windows network drives, where the file is readable but the resource path serves nothing), the preview falls back to Obsidian's own PDF viewer via a markdown embed, which reads the file the same way its normal PDF tab does.
  3. **Fallback card** — if even that can't resolve the file, a card with "Open in a new tab" and "Retry" replaces the blank pane.
