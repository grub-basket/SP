# 0.243.0

A large release. The headline is a **media viewer** for a note's attachments,
with zoom, rotation, pan and Grid / Details browse modes. Alongside it: the
Stashpad-app importer became re-runnable and gained a destination picker,
titles stopped being wrecked by URLs, notes can be visually obscured, and
iPhone safe areas are handled properly across the plugin.

## Media viewer

- Clicking an image or PDF attached to a note opens a large preview instead of
  a new tab, with a rail of the note's other files so it browses rather than
  dead-ending. Non-image, non-PDF files still open in a tab, and the viewer
  offers "Open in a new tab" for everything.
- **Zoom is cursor-anchored**: the point under the pointer stays put, so
  scrolling over a corner zooms into that corner. Wheel, buttons, double-click,
  and click the percentage to toggle fit / 100%.
- **Pinch to zoom** on touch, anchored on the midpoint between the fingers so
  pinch and scroll agree about what "zoom here" means. Lifting one finger hands
  back to a pan without the image jumping.
- Rotation in 90-degree steps, re-fitting after each quarter turn. Pan by
  dragging.
- Keyboard: `+` / `-` zoom, `0` fit, `1` 100%, `R` / `Shift+R` rotate, arrows
  navigate, Escape closes.
- Fit never scales an image UP past 100%, so a small icon stays sharp instead
  of being blown up into a blurry mess.
- **Three view modes**, switchable from the toolbar: Viewer (one file large
  with a filmstrip), Grid (thumbnails, column count follows the width), and
  Details — a Windows-Explorer-style table of Name / Type / Size / Modified
  with click-to-sort columns. On a phone Details drops the Type and Modified
  columns rather than truncating all four.
- PDFs render inline. The embedded viewer owns its own scrolling and zoom, so
  the transform controls are hidden for a PDF instead of being left inert.
- Broken links and images that fail to decode show a labelled placeholder
  rather than an empty stage that reads as a rendering bug.
- New setting: **Open images in the media viewer** (on). Off restores the
  previous open-in-a-tab behaviour exactly.

## Attachments in the note list

- Every file type now has an icon, a colour and a label — a PDF is red, a
  spreadsheet green, an archive brown — replacing four grey letters. The
  colours are fixed rather than theme-derived, because a file type's colour is
  an identity; deriving it would make a PDF and a zip identical in a
  monochrome theme.
- The attachment rail picks a layout from the file mix and its own measured
  width: **thumbnails** when the files are mostly images with room to see them,
  a **compact icon strip** when a thumbnail would fall below roughly 90px (at
  which point a photo is an unidentifiable smudge, and the space is better
  spent on more files), and a **named list** when the files are mostly
  non-images, since a spreadsheet is identified by its name, not a preview.
- New setting: **Attachment layout** — Auto, Thumbnails, Compact icons, or
  File names.

## Note titles

- URLs and file paths are stripped before a title is built. A note starting
  `Check https://example.com/q3/report?x=1 for details` was titled
  `Check-Https-Example-Com-Q3-Report-X-1`; it is now `Check-Details-URL`.
- Link TEXT is kept and only the target dropped, so `[the Q3 report](url)`
  titles as `Q3-Report`. Wikilinks keep their alias, or the last path segment.
- A trailing `URL` / `File-Path` marker records that the note contains one, so
  they remain searchable. The marker's width is reserved before the title is
  truncated, so it survives on long titles.
- A line that is ONLY a link salvages its last path segment rather than
  becoming "Untitled" — otherwise every link-only note collides on one name.
- Bare relative paths need a file extension or two-plus slashes to count, so
  ordinary prose like "3/4", "and/or" and "24/7" is left alone.
- Rebootstrap re-derives titles from the current rules, so existing notes clean
  themselves up on the next run.

## Stashpad-app importer

- Pressing Import twice no longer duplicates everything. The set of
  already-imported ids is now read fresh on every parse and combined with the
  ids written during the current run — the metadata cache has not parsed those
  files yet, so a cache-only lookup still missed them.
- A re-run reuses existing section parents instead of rebuilding them, and no
  longer rebuilds its reference notes.
- **Choose the import destination**, with a confirmation step before anything
  is written. The picker offers top-level folders only and never reserved ones.
- Imported notes are tagged with what they were in Stashpad, so their
  provenance survives.
- Emoji shortcodes are converted.
- Import progress is shown, and the window is allowed to paint while it runs
  instead of freezing until it finishes.

## Obscuring and spoilers

- A note can be marked to render **blurred until tapped**. The first click
  reveals it and is consumed, so unblurring never also selects or navigates.
  Revealing is per-view and in memory, and by default the note re-blurs when
  you navigate away.
- `||spoiler||` in a note body renders blurred until tapped. `||` inside code
  blocks and inline code is left alone.
- **This is visual only, and is labelled as such everywhere it appears.** The
  text remains in the file, in search, in the editor and in sync; it hides
  content from someone glancing at your screen and nothing more. For real
  privacy, use per-folder encryption.

## Settings

- The folder-panel placement section can now SET a placement, not just undo
  one. Every folder row has a Normal / Pinned / Downranked / Hidden dropdown,
  and a new "Other folders" section lists every Stashpad with no placement set
  — previously the page could only show folders already acted on elsewhere, so
  there was no way in.
- Cross-Stashpad search scope is now one toggle per folder with a filter box,
  and each folder is individually findable in Obsidian's settings search
  instead of only the section being findable.
- Bulk recolour can apply across **every** Stashpad, not just the selected one,
  behind a toggle that is off by default. The confirmation names the folders
  it touched.
- Fixed: the search-scope section could get stuck showing "No Stashpads found"
  permanently, because the setting definitions are built once at startup —
  before the metadata cache has finished indexing — and cached.

## Commands and hotkeys

- New **Focus the list** command (`Mod+Shift+L`): move focus out of the
  composer and onto the list, landing on the last note you had selected.
- New **Obscure / reveal note** command.
- Edits made outside Stashpad — in another editor, Obsidian's own, or via sync
  — are now recorded in the action log. They were previously the only writes
  with no trace, since no command ran to log them.

## Mobile and iPhone

- Safe areas are handled through shared tokens rather than per-surface
  guesswork, so content no longer sits under the Dynamic Island or the home
  indicator. The media viewer, the composer lift and the existing sheets all
  use them.
- The task checkbox moves back to the top of a mobile note row. A previous
  three-section mobile layout had moved the row's footer beneath the body,
  dragging the checkbox to the bottom of the note with it.
- Task submenu items now dismiss the whole menu, instead of leaving the parent
  sheet covering the row just acted on.

## Fixes

- Toggling a task complete repainted the whole list and moved it; it now
  repaints in place, matching the colour and mark-as-task paths.
- Cross-folder writes re-slug the target's filename immediately, instead of
  leaving it describing a first line that had been replaced.
- Pinned folders rank first — in folder-panel order — in the folder switcher,
  the destination picker and the quick destination menu.
- The folder panel's top section is pinned notes only; folder pins keep their
  meaning through the ranking above.
