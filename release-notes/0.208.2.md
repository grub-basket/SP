# 0.208.2 — one rule for opening a Stashpad

- The ribbon icon and the "Open Stashpad in new tab" command previously used
  different folder-count rules, so with exactly one Stashpad the ribbon opened a
  picker containing a single entry while the command opened the folder. Both now
  follow one rule: no folders shows the welcome, one folder opens it directly, two
  or more show the picker. Right-clicking the ribbon still always shows the picker.
- The folder switcher ranks the folder you were last working in first.
- The ribbon icon changes from a file-tree to stacked rectangles, which reads as a
  pile of notes rather than a filesystem.
