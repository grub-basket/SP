# 0.208.2

- **One rule for every way into a Stashpad.** The ribbon icon and the "Open
  Stashpad" command each had their own idea of what to do; both now follow the
  same folder-count rule — no folders yet, you get the welcome; exactly one,
  it opens; several, you get the picker.
- **The folder switcher ranks your last-used folder first.**
- New ribbon icon, and the folder panel's folder-plus button is back (0.208.0
  removed the wrong one of two similar controls).
