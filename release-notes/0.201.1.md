# 0.201.1

- **Finishing a cross-vault cut is now guided.** After the other vault receives
  the paste, switching back to the source vault brings up a confirmation
  offering to delete the originals — nothing is removed until you confirm, the
  delete is undoable, and Cancel resolves the cut as a copy. (Implemented as a
  clipboard acknowledgement handshake — no network, no black magic.)
- The oversized-selection dialog now opens the **full export modal**, so
  encrypting the `.stash` is an option for big transfers.
- Cut notification: item previews roughly doubled (36 characters).

---

This release also includes everything from **0.201.0** (the cross-vault
cut/copy/paste feature itself — notes reconstruct in the destination vault with
nesting, attachments, and color aliases; copy mints fresh ids, cut keeps them;
crash-safe: the source is never deleted automatically; 8 MB clipboard cap), and
a README correction (the nesting section no longer denies the flat view mode —
it exists and is now mentioned).
