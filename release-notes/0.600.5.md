# 0.600.5

This release covers every change since 0.599.3:
- **Moving an encrypted folder is safe:** it is unlocked first, and Stashpad keeps reminding you to encrypt it again.
- **Merged folders keep working** when the folder they were merged into is moved or renamed.
- **Settings changes no longer get lost** in a quick burst of saves.
- **Fewer false "edited outside Stashpad" entries** in the activity log.

## Highlights

- **Moving or renaming an encrypted folder.** Move folder… and Rename… now ask first, then unlock the folder's locked notes (you may be asked for its password), turn its encryption off, and move it as a normal folder. If a note can't be unlocked, nothing moves. Locked notes that "Encrypt again" couldn't lock back the same way (archived while archive encryption is off, or in a deeper folder) stay locked and move with the folder, under the same password.
- **Reminders until it's encrypted again.** A folder unlocked to be moved gets a notice with **Encrypt again** that stays up, shows again every time Obsidian starts, is listed at the top of the Encryption settings page ("Folders waiting to be encrypted again"), and leads the folder's gear menu. **Encrypt again** brings back the folder's encryption settings and locks its notes; the reminder only goes away once they really are locked (cancelling the password keeps it).
- **Folders moved outside Stashpad** (Obsidian's file explorer, or sync) keep their unlocked state and key, so their locked notes don't get stuck behind a password prompt.
- **Merges follow a moved folder.** When a folder that something was merged into is moved or renamed, old links to the merged folder still open it, and Unmerge still works.
- **Settings changes stick.** Two timing problems in how settings are saved could put back an older value for the last thing changed in a quick series of saves (Stashpad mistook its own save for one from another device). Both are fixed.
- **Quieter activity log.** Editing a note's first line renames its file, and Obsidian then updates the link to it in the folder's Home note. That update is no longer recorded as "edited outside Stashpad" (it was, once per open tab).

## All changes

### 0.600.0
- Before Stashpad renames a note to match its first line, every note linking to it (the parent's `children` list, the children's `parentLink`, body links) is marked as a link rewrite for a few seconds (`markLinkersQuiet`), so the rewrite isn't logged as an external edit or stamped as an edit.

### 0.600.1
- Moving or renaming a folder that another folder was merged into rewrites that merge's record file (destination, container note, moved files, archive/trash folders) and then the stored redirect, keeping the two in step for Unmerge and old links.

### 0.600.2
- Encrypted folders: Move folder… and Rename… ask, unlock locked notes, switch the folder's encryption settings off, then move or rename. Name clashes and other refusals are checked before anything is unlocked.
- New "waiting to be encrypted again" record per folder, with a persistent notice, a start-up reminder, an Encryption settings section and gear-menu items; "Encrypt again" restores the old settings and locks the notes.
- Folder renames from anywhere re-key the encryption service's per-folder caches (unlocked keys, key index, key registry).

### 0.600.3
- A settings save is recognised as Stashpad's own by the sync watcher even while the write is still in progress (it was treated as another device's file and could revert newer changes).

### 0.600.4
- After writing settings, Stashpad records exactly what it wrote as saved (it recorded the live settings, so a change made during the write was skipped and later reverted).
- "Encrypt again" keeps the reminder until every note it covers is locked, waits for the key index after start-up, and keeps one notice per reminder (closed when it's cleared). The notice's button still works after the folder moves again.
- The move only unlocks notes that "Encrypt again" can lock back; other locked notes stay locked and move with the folder.
- Folders keyed through the legacy keyfile are re-keyed on rename too.

### 0.600.5
- The "Folders waiting to be encrypted again" settings list refreshes immediately after Encrypt again or Stop reminding.

- Internal changelogs, request log, board and backlog updates (not part of the plugin).
