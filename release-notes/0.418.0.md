# 0.418.0

**"Restore settings from a backup…" command.** A per-device settings-backup restore UI already existed in Settings → Maintenance (a list of snapshots with Restore buttons), but it was buried. This adds a command-palette entry that opens a focused modal:

- Per-device snapshots, newest first, with timestamps.
- A Restore button on each, which confirms and then calls the existing `restoreSettingsBackup` — that snapshots the current settings first, then prompts to reload.

More discoverable and bindable than the settings section.
