# 0.302.0

A big batch since 0.296.0 — a local crash log, cross-folder duplicate detection,
a folder-switcher quick menu, a view launcher, and a round of mobile / composer /
scheduling fixes.

## Duplicate detection & composer (0.298–0.299)

- The composer's "Similar notes" panel now also matches notes in **other Stashpad
  folders**, each labelled with its folder; clicking a cross-folder match opens
  it in a new tab (and returns you on close). Same-folder matches keep priority.
- The similar-notes panel **clears when you send** instead of briefly re-showing
  for the note you just created.
- The composer's reply chip is a two-line "Reply to" block, and its
  duplicate-hints toggle sits next to the destination (map-pin) button with a
  clearer "radar" icon.

## Finding your way around (0.301)

- **Folder switcher quick menu** — the folder buttons open a small menu of your
  current + recent/pinned folders with "Search all folders…" for the full
  picker, like the destination picker.
- **View launcher** — a searchable command (assign it a hotkey) that jumps to any
  Stashpad view (note list, master index, tasks, calendar, heatmap, timeline,
  trash, panels, detail…). Launch buttons were added to the Panels toolbar and
  the Folders panel.

## Replies & scheduling

- **Reply** (the row button or the new **R** shortcut on a cursored note) now
  always focuses the composer so you can type immediately, and the quoted
  preview renders right after you send (previously it could be missing until a
  reload). Pressing R on another note switches the reply target.
- **Due / schedule picker**: the date field is no longer clipped, the modal is
  wide enough to show all seven weekday chips on one row, and the Repeat /
  Auto-complete / Remind-every fields now give **live validity feedback** as you
  type. The day-adjust buttons sit right after the time-adjust buttons.
- **Blur schedule**: a per-weekday chip row lets you turn the schedule off on
  chosen days (e.g. weekends); the chips now toggle visibly, and a note appears
  when no folder is set to blur.

## Mobile & navigation

- **Folders in the folder panel open on a single tap** on mobile (they used to
  need two).
- **Switching folders lands at the newest notes** — via the switcher and now
  also via the folder panel (which used to keep a stale scroll position).
- Switching folders no longer jitters up and down mid-render.

## Editing & lists

- The focused-note **heading no longer collapses based on scroll position** —
  it stays a fixed size (with a manual expand toggle), which fixes short lists
  where you couldn't scroll to the last note. **Alt+E** expands/collapses the
  selected note's body.
- The edit modal's **Original / Changes panes clamp to two lines** by default
  with a per-pane "Show more", so editing a long note isn't a wall of text.
- **Copy tree** preserves the line breaks inside a note's body, so a bulleted
  list pastes as a list instead of one run-on line.

## Reliability & diagnostics (0.297)

- **Local error capture**: Stashpad now keeps a local log of its own uncaught
  errors (a file in the plugin folder — never sent anywhere), with commands to
  copy or clear it. Always on; costs nothing until something throws.
- Notifications about a **teammate's changes** are now persistent so you don't
  miss them.
- The Panels "Pinned" list no longer reorders itself by last-accessed when you
  click a pin.
