# 0.272.4

## Duplicate note ids

- The Compare button now sits next to each copy's filename, on the same line, rather than off in the action cluster.
- The merge confirmation spells out what is kept and what is discarded, filenames on their own lines, and no longer says "nothing missing" when structural frontmatter actually differs.
- The frontmatter comparison highlights the actual difference inside each value, each row sizes to its own content (a home note with hundreds of children no longer takes over), and the frontmatter section is open by default.
- Conflict copies are detected by the "(conflicted copy …)" marker rather than the word "conflict" anywhere in the name. Each id now carries a plain recommendation of which copy to keep and which to discard, since "visible" only means the copy the app happens to display, not the one to keep.
- On a narrow window or phone the row stacks and the full filename gets its own line, so it is no longer cut off.

## Obscure (blur)

- The detail side panel now blurs with the note, like the list does. Tap to reveal.
- Revealing a note by tapping is now two steps: the first tap shows the text, the second shows the images and attachments, so a glance does not expose everything at once. A note with no images reveals in one tap.

## Reveal in large text

The zoom and close buttons moved to the bottom middle, easier to reach on a phone and out of the way of the text.

## File preview: copy

The file preview now has a Copy control: for an image it copies the picture to the clipboard, for anything else it copies the attachment link. It is a button in the toolbar and, for non-PDF files, in the right-click menu.

## Filter to one day

A new calendar button in the filter bar filters the list to a single day: notes created that day, notes that link to that date, or tasks due that day. Reachable in the combined filters panel on mobile too.
