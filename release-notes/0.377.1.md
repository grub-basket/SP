# 0.377.1

The note preview modal gains action buttons and a set of view controls.

## 0.376.0–0.376.2 — Row buttons in the preview modal

- The note preview modal now carries the note's own row action buttons — react, quick menu, your custom item buttons, and the full context (⋮) menu — so you can act on the note without leaving the preview. Expand/collapse and the preview button itself are left out (they'd be redundant in the modal); edit / open / reply stay reachable through the ⋮ menu.
- Those buttons sit at the end of the modal's bottom toolbar, in one line with the existing controls, and match their styling. The caption is now just the centred note title + slide count.

## 0.377.0–0.377.1 — Preview view controls

- New buttons on the modal's bottom toolbar:
  - **Toggle reading width** — constrain the note text to a comfortable line length (remembered), on the note slide.
  - **Copy a link to this note.**
  - **Open the parent note in a new tab** (when the note has a parent).
  - **Save a copy** of the current file, **Show in the system file manager** (desktop), and **Show in Obsidian's file explorer** — for the note's `.md` or any attachment.
  - **Immersive mode** — hide the caption and thumbnail rail for distraction-free reading; toggle back from the toolbar.
- The note-level buttons (actions, copy-link, open-parent) stay put on every slide of a preview — they don't vanish when you move from the note to one of its attachments. Reading width is the one note-only control.
