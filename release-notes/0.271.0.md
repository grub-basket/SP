# 0.271.0

## Time filter: any number of any unit, sliding or fixed

The time filter used to offer four fixed choices: day, week, month, year. It now
takes a number and a unit, so "last 3 days", "last 6 weeks" or "last 2 hours" are
all expressible, alongside a choice of how the window behaves:

- **Sliding** (the default): "the last 14 days" keeps meaning the last 14 days as
  time passes.
- **Fixed start**: freezes the current cutoff to a specific moment, so the window
  stops moving and older notes drop away as usual while the start stays put.

Calendar boundaries remain a separate option: with it on, "1 week" means since the
start of this week rather than a rolling seven days.

On a phone, all of this lives in the combined filters panel, reached from the
filter button, with one-tap presets (24h, 7 days, 30 days, a year, All) for the
common cases.

Existing filters carry over unchanged: whatever you had set resolves to exactly
the same cutoff it did before.

Pinned notes still follow the "pinned notes versus filters" setting from the
previous release, including the option to keep them visible past the time cutoff.
