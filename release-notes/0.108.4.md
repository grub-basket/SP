# 0.108.4 — Mobile tap fixes, fork provenance, diagnostics

## Mobile: tap the note you meant
Fixes a long-standing mobile annoyance where, with the keyboard up and the composer
lifted, tapping the note just above the composer would open a *different* note. The
cause was the list reflowing as the keyboard dismissed — rows slid out from under
your finger mid-gesture. Now a double-tap opens the note you actually aimed at, in
one fluid motion, and a tap that only dismisses the keyboard no longer opens anything
by accident.

## Note forking
- Forks now record where they came from: a `forked-from` link back to the original,
  with every member of a fork family kept in sync.
- Forking (and cloning, and inserting templates) produces a clean standalone note —
  version/sheet metadata is no longer copied across, so a duplicate can't inherit a
  stray "final" marker or ordering.
- Deleting a note prunes it from its fork family automatically.
- Clearer labels distinguish **Fork as a version** (a draft within a tabbed group)
  from **Fork into a separate note…** (a re-homed standalone copy).

## Diagnostics
- New **Debug trace** toggle (Settings → Diagnostics) for capturing low-level
  diagnostic lines while reproducing an issue, with Copy/Clear buttons. Local only —
  no network, no file writes, and off by default.
