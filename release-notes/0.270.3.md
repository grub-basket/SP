# 0.270.3

## The quick destination menu shows every pinned folder

The quick destination menu (tap the destination button while composing) lists
your folders so a note can be sent elsewhere in one tap. Pinned folders lead the
list, but the whole list was capped at five, so a sixth pinned folder was
silently left off.

Every pinned folder is now offered, however many you have. The cap governs only
how many recent-but-unpinned folders fill the list out: with five or more pins
the menu is just your pins, and with fewer, recent folders top it up. The folder
you are already composing in is left off, since a plain send already goes there.
