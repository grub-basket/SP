# 0.313.2

A focused rework of the time filter in the note view.

## Time filter

- **New number box.** The "last N …" control is now a tidy box: a **reset**,
  the value (which **auto-sizes** to what you type, in a monospace font so the
  width is steady), and inline **+/- steppers**. A **✓** appears only when you
  type a new number — the steppers apply at once, and clicking away or pressing
  Enter also applies. The reset sits after the unit dropdown and **clears the day
  filter too**, so it's a single "show everything again".
- **Mode moved to Settings.** The calendar/rolling and sliding/frozen toggles
  left the filter bar (they read as clutter there) and became two settings with
  proper explanations:
  - **Time window mode** — *Rolling* (the last N days/weeks, counted back from
    now, sliding forward as time passes) vs *Calendar* (this day / week / month /
    year, starting at the beginning of the period).
  - **Freeze the time window** — pins the cutoff at the moment you set it, so the
    window stops sliding (a fixed "since <date>" instead of a moving "last N").
  Both the desktop bar and the mobile time popover read the same settings.
- **Clearer day-filter icon** — a calendar-with-magnifier, so "filter to one
  day" no longer looks like the old mode calendar.
- Fixes: the value is fully visible and vertically centered, and the number box
  and unit dropdown no longer have the top/bottom of their focus outlines shaved.
