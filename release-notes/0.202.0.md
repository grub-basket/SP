# 0.202.0

Stashpad's typing surfaces are plain text areas, so behaviors Obsidian's editor
provides have to be written by hand. This release works through a parity
checklist rather than fixing them one at a time — and puts them all in one
shared layer, so the composer, the edit/split editor and the detail panel
behave identically.

- **Lists continue when you press Enter.** `- milk` → Enter → `- ` ready for
  the next item. Ordered lists renumber (`1.` → `2.`), tasks continue
  **unchecked** (`- [x] done` → `- [ ] `), and blockquotes carry the `>`.
  Pressing Enter on an empty item **exits the list** instead of nesting
  forever. This never interferes with sending a note — each surface declares
  whether Enter makes a newline or submits.
- **Tab and Shift+Tab indent list items** — but only when the caret is on a
  list line or the selection spans several lines. Everywhere else Tab still
  moves focus, so the field never becomes a keyboard trap.
- **No more mid-word auto-closing.** Typing `(` in the middle of a word now
  inserts just `(`; pairs are only completed when what follows is a space, the
  end of the line, or a closing character.
- **Double-click no longer swallows the trailing space.** Selecting a word and
  wrapping or replacing it keeps the gap after it intact.
- **Obsidian's own editor settings are honored** — "Auto pair brackets",
  "Auto pair Markdown", "Smart indent lists" and your tab/indent size — so
  these are configured once and both editors agree. Stashpad's own "Auto-pair
  Markdown syntax" setting remains the master on/off switch.

---

This release also includes **0.201.6**: selecting text and typing `[`, `(`,
`"`, `'`, `` ` ``, `*`, `~` or `=` now **wraps** the selection instead of
replacing it, and the wrapped text stays selected so pressing the key again
nests it (`note` → `[note]` → `[[note]]`, `word` → `*word*` → `**word**`).
