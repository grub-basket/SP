# 0.533.0

This release covers every change since 0.532.9. Stashpad links (`obsidian://stashpad?…`) can now point at the Showcase and every other Stashpad tab, not just a note, a folder or a saved view. Send a reviewer a link to the Showcase page you want feedback on, and it opens on the same page.

## Links to Showcase and other tabs

- **0.533.0** — A new `tab=` link parameter opens one of Stashpad's tabs:
  - `tab=showcase&folder=<folder>` opens the Showcase for the top of a Stashpad. Add `&note=<id>` for a specific level.
  - `tab=board` opens the kanban board, for one folder with `&folder=<folder>` or for all notes without it.
  - `tab=tasks`, `timeline`, `calendar`, `heatmap`, `watch`, `index`, `encrypted` and `archived` open those overview tabs.
  - `tab=trash`, `tab=log` and `tab=notifications` open those tabs.
- **0.533.0** — Ways to copy these links:
  - **Copy Stashpad link** is in every Stashpad tab's ⋯ menu and in the menu you get by right-clicking the tab (the note list included).
  - The Showcase toolbar has a link button that copies a link to the page you're on.
  - New command: **Copy Stashpad link to this tab (Showcase, board, tasks, …)**.
  - In the **Open Stashpad link** dialog, "Link to where you are" offers the link for the tab in front, whether it's the Showcase, the board, the task list or another tab.
- **0.533.0** — Opening a tab link works the same way as opening a note link. If that tab is already open, it comes to the front instead of opening a second copy. A notification says what opened, or that it was already open. **Recent links** records every copy and every open. A link to a folder or note that isn't in the vault shows an error instead of failing silently. Showcase and board links follow the same nesting rules as folder links.
- **0.533.0** — Links keep to a fixed list of tabs, so a link pasted into a note can only open one of the tabs listed above.
- **0.533.0** — If Stashpad finds a tab link on the clipboard at launch, its message names the tab (for example "Opened **Activity heatmap**"). It no longer shows an empty name for tabs that aren't tied to a folder.
- **0.533.0** — Links don't carry a tab's display settings: the board's grouping, and the Showcase's layout and "hide resolved" option.
- Existing note, folder and saved-view links behave exactly as before.
