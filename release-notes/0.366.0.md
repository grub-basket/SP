# 0.366.0

## Fixes & improvements

- **The note menu now stays in sync across devices.** The built-in submenus (Move, Pin, Advanced, React / Reply, Appearance) only ever had missing *submenus* filled in on startup, never missing *items* — so a device that first set them up on an older version could show a different, shorter menu than another synced device, and the menu could appear to "grow" after you visited settings. Startup now also tops up any missing built-in items on a submenu you haven't renamed, appended after your own items (your ordering and any items you added are kept). A submenu you've renamed is left completely alone.
- **"Copy tree" is back in the command list.** The command that copies a selection plus everything nested under it had no palette/hotkey entry (an old rename had taken over its command), so it was only reachable via its keyboard shortcut. It's now searchable as **"Copy tree (selection + everything nested)."**
- **Cleaner parent-task progress badge.** The little done/total count on a parent note's checkbox is now a solid circle that fully covers the box (no more checkbox peeking around it), with a crisper green when everything's complete.
- **Cancel the in-list "nest under / reply to" picker on mobile.** The picker relied on the Esc key to cancel, which isn't available on a phone keyboard — it now shows a banner with a **Cancel** button while it's active.
