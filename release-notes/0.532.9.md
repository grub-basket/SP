# 0.532.9

This release covers every change since 0.531.3. It finishes the Showcase follow-ups:
- pins on PDF pages;
- PDF text you can select, copy and search;
- a Find bar for the whole page;
- votes that survive file renames;
- safer escaping of note properties.

## Showcase — PDFs

- **0.532.2** — PDFs in the Showcase are now drawn page by page by Obsidian's own PDF engine, each page with a small "2 / 3" label.
  - **Pins work on PDF pages.** Choose the PDF in the feedback box, click **Pin a spot**, then click the page. The comment shows "on file.pdf · p. 2"; clicking that scrolls to and highlights the page.
  - Exports with feedback draw the pin on the right page.
- **0.532.2** — PDFs are read straight from the vault, which also avoids the blank-PDF problem some network-drive and Windows setups had with the built-in viewer.
- **0.532.2** — PDFs over 60 pages or 60 MB, or files the PDF engine can't open, fall back to the previous viewer (without pins).
- **0.532.5** — **PDF text can be selected and copied**, the same as in Obsidian's own PDF viewer.
  - Dragging or double-clicking to select doesn't open the preview; a single click still does.
  - Captions and comment text can be selected and copied too.
- **0.532.3** — Only pages near the screen keep their drawn image, which keeps memory in check with long or many PDFs (especially on phones). Pages redraw when you scroll back.
- **0.532.4** — A page that scrolls away stops drawing.
- **0.532.8** — A page sitting at the edge no longer redraws on small scrolls.
- **0.532.3** — A PDF that fails partway through drawing falls back to the viewer cleanly, and doesn't offer pins it can't take.

## Showcase — Find

- **0.532.5** — A new **Find** bar: the 🔍 button in the Showcase bar, or Cmd/Ctrl+F while the Showcase is focused.
  - It searches captions, comments and the text inside PDFs, highlighting every match (the current one in orange) with an "n of N" count.
  - Move between matches with ↑ ↓ or Enter / Shift+Enter; Escape closes it.
- **0.532.6** — Find:
  - matches phrases across lines and across pieces of PDF text;
  - works in popped-out windows;
  - jumps to pages you haven't scrolled to yet and then highlights the exact words;
  - never loses what you're typing while PDF text is still loading.
- **0.532.7** — Find:
  - also searches PDFs further down the page that haven't been opened yet;
  - doesn't stall while many pages load;
  - keeps highlights separate between Showcase tabs in different windows.
- **0.532.8** — Searching ignores case correctly for letters like Turkish **İ** ("istanbul" finds "İstanbul"), and highlights stay on the right characters.
- **0.532.9** — Greek final **ς** matches **σ** ("οδος" finds "ΟΔΟΣ").
- Scanned PDFs and pictures of text have no text to find.

## Showcase — reactions

- **0.532.1** — Renaming an option's image or PDF, or moving its folder, keeps the 👍 👎 ✅ ❌ votes on it. Renames in quick succession and swaps land on the right file (0.532.3, 0.532.4).
- **0.532.4** — A comment pointing at a renamed file stays pointed at it, even when files are swapped by name.
- **0.532.5** — Undoing a vote still works after its file was renamed.

## Note properties

- **0.532.0** — Stashpad writes some note properties itself: new notes, clones, and the record left by a failed import. Values in them are now fully escaped. A failed-import record whose error message contained a Windows path (backslashes) or a line break used to break that note's properties entirely.
