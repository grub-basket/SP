# 0.270.2

## Pinned notes versus filters, as a three-way choice

0.270.1 added a single switch for whether pinned notes ignore filters. One
switch could not express what people actually wanted: "keep my pinned reference
note visible as the time window slides past it" and "ignore every filter,
including the one I just set to narrow things down" are different requests, and
the switch conflated them.

It is now a choice of three, under List display and in the filter controls:

- **Always show pinned notes.** A pinned note is never hidden by any filter.
  This is the default.
- **Only ignore the time filter.** A pinned note stays put as the time window
  slides, but tag, colour, author, hide-completed, attachments-only and
  imported-only still hide it. Useful when a pin means "this is permanent", not
  "this is exempt".
- **Treat pinned notes normally.** No special handling at all.

Applies to both kinds of pin, in a list and in the sidebar. Whichever way the
0.270.1 switch was set carries over: on becomes "always show", off becomes
"treat normally".

The control appears in the filter bar as a button that cycles the three states,
dimmed when set to the middle one so the setting reads at a glance, and in the
combined filters panel on mobile.
