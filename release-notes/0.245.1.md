# 0.245.1

The media viewer now decides what to open by looking at the **note**, not at
the file you clicked — plus a text preview and a fix for a settings heading the
community-store validator rejects.

## The viewer opens for the whole note, not one file at a time

Previously each attachment was judged on its own extension, so clicking a `.zip`
sitting beside a photo opened the zip in a tab and stranded you away from the
row of files you were reaching for. The viewer shows a rail of *everything*
attached to a note, so the decision now considers that:

1. A file type on the **exclusion list** never opens the viewer.
2. With **Open every file type** on, everything else opens it.
3. Otherwise the viewer opens when the clicked file can be previewed **or any
   other attachment on the same note can be**.

Rule 3 is the one that matters day to day: a zip, a `.docx` or a broken link
still opens the viewer whenever it shares a note with an image, PDF or text
file, so a mis-aimed tap never costs you the rail.

**Settings changed shape.** The old *"File types that open in the media viewer"*
include-list is replaced by:

- **File types to keep out of the media viewer** — an exclusion list. Blank
  means nothing is excluded. Dots optional, case-insensitive, and commas,
  semicolons or spaces all separate.
- **Open every file type in the media viewer** — off by default, since for a
  `.docx` the real application is usually the better answer.

If you had customised the old list, set the new one — the old value is not
carried over, deliberately: reading an include-list as an exclude-list would
have done precisely the wrong thing to every type in it.

## Text files preview in the viewer

Markdown, text, CSV, JSON, logs, config and source files now render their
contents as a proper slide — it participates in the rail, in previous/next, and
in Grid and Details view like any other file.

- A strip above the text names the type, size and modified date.
- The preview is capped at **2000 characters** (800 on a phone, where 2000 is a
  wall of text rather than a preview) with **Show all** / **Show less** and a
  character count.
- Expanded text **scrolls inside its own box** — the modal never grows, so the
  toolbar and the rail stay exactly where they were while you read.
- Zoom and rotation hide themselves for text, as they already do for PDFs.

## Missing attachments open the viewer too

A broken link used to ignore the click entirely. It now opens the viewer and
says what is wrong — which also gets you to the note's other attachments,
rather than leaving you where you started.

## Fixed: a settings heading the store validator rejects

Two settings headings included the plugin's own name, which the community-plugin
validator reports as an error — Obsidian already shows the plugin name above its
settings tab. *"Cross-Stashpad Search Scope"* is now **Cross-folder search
scope**, and *"What Stashpad is"* is now **What this plugin is**.

## Also fixed

- The media viewer's toolbar buttons were invisible: an icon inside a flex
  container collapsed to zero width while keeping its height, so every button
  rendered as an empty square.
