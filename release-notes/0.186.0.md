# 0.186.0

## Editing

- **`@` in the editor — dates and note links in one place.** Type `@` in the
  composer or the edit / split editor to get a unified suggestion popup:
  - **Natural-language dates** (via the [Natural Language Dates](https://github.com/argenos/nldates-obsidian)
    plugin, if installed) — `@today`, `@tomorrow`, `@next friday`, `@in 3 days`
    resolve to a real date, formatted per your NLD settings. A bare `@` offers
    today / tomorrow / next week.
  - **Note links** — `@meeting` inserts `[[Meeting]]`, an alternative to `[[` for
    people who prefer `@`.

  Dates rank first, so pressing Enter on `@today` inserts the date. If NLD isn't
  installed, `@` simply acts as a note-link shortcut. (NLD's own `@` popup only
  works in Obsidian's markdown editor, not Stashpad's text fields, so this calls
  NLD's `parseDate` API directly.)
