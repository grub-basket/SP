# 0.275.2

Filtering additions across the aggregate views.

## Task timeline: filter by tag

The timeline gains a tag filter, drawn from each task's `tags:` frontmatter and
inline `#tags` (the "task" marker tag is excluded). Use it to check on a class of
work — "events", "sagas", product outages, or any tag you group tasks under. The
filter only appears when your tasks actually carry tags.

## All notes: Broken links

A new **Broken links** filter in the All-notes index shows notes that contain a
`[[wikilink]]` pointing at a note or file that doesn't exist. It's the companion
to **Orphans**: an orphan is a note whose *parent* is missing; a broken link is a
note that *points at* something missing. Matching rows also carry an icon.

## All notes: Stale

A new **Stale** filter shows notes untouched for more than about six months —
a quick way to find what's gone cold and might want archiving or a refresh. Sort
by "Recent first" to bring the oldest to the bottom.
