# 0.201.0

- **Cut, copy, and paste notes BETWEEN vaults.** Copy or cut in one vault, open
  another vault's Stashpad, paste — the notes reconstruct there for real:
  nesting preserved, attachments carried and deduped, color aliases merged.
  Under the hood the selection rides the OS clipboard as a hidden `.stash`
  payload next to the normal plain text (pasting into other apps is unchanged).
  Copy mints fresh ids; cut keeps them.
- **Crash-safe by design:** a cross-vault paste never deletes anything in the
  source vault by itself. See 0.201.1 for the guided cleanup.
- Selections too large for the clipboard (8 MB+) keep the plain-text copy and
  offer the export path instead.
