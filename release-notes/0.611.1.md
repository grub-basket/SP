# 0.611.1

This release covers every change since 0.608.0:
- **Short screens get a layout of their own.** When the keyboard is up, or on a small or foldable phone, Stashpad hides its bars in layers and brings them back when there is room.
- **Deletes keep working on Obsidian 1.15.1**, where the system trash can refuse a file.
- **Foldable iPhones:** the folder switcher no longer flashes the sidebars when tapped.
- **Escape out of the in-list picker** no longer jumps the list to the cursor row.

## Highlights

- **Short-screen layout.** Each Stashpad view measures how much of itself you can actually see: the keyboard, a small phone and a foldable's outer screen all just mean fewer pixels. As that height shrinks, bars are hidden in layers:
  - under 600px: the breadcrumb;
  - under 460px: also the bottom toolbar, the draft tabs and note timestamps, and a jump-to-level button appears in the view's title bar;
  - under 340px: also tighter spacing.

  The composer's own row and the formatting toolbar always stay. A fold button in the title bar (phones and tablets) shows every bar or hides every layer; the automatic choice takes over again the next time the keyboard opens or closes. Settings → List display → **Short-screen layout**: Auto (phones and tablets, the default), Always (any device) or Off.
- **Deletes on Obsidian 1.15.1.** Obsidian 1.15.1 can now refuse to move a file to the system trash (network shares, unusual drives) and leave it where it is. Stashpad assumed the file was gone, so a deleted note could come back and a move between folders could leave a second copy behind. Every delete now checks the result and, when the system trash refuses, moves the file to the vault's `.trash` folder instead (still recoverable), with a one-time notice.
- **Foldable iPhone: folder switcher taps.** On the inner screen of a foldable iPhone, tapping the composer's folder switcher could flash the sidebars. The button now opts out of Obsidian's sidebar swipe.
- **Escape out of the in-list picker** (with keyboard focus outside the view) no longer pulls the list to the cursor row when that row was scrolled out of sight.

## All changes

### 0.609.0
- The composer's folder button (`.stashpad-composer-nav-folder`) carries `data-ignore-swipe`, so Obsidian's workspace swipe tracker ignores taps that start on it. Fixes a sidebar flash on a foldable iPhone's inner screen, where the button sits near the screen edge.
- New `src/layout-probe.ts` (mobile only): with Settings → Diagnostics → Debug trace on, it records phone/tablet layout flips, orientation changes and viewport sizes into the in-memory trace, to diagnose layout problems on foldables. Off unless the debug trace is on.

### 0.609.1
- Escape while the in-list picker is open and focus is outside the view: removed three `scrollTop` writes that went to a list element `render()` had already replaced, and `revealCursorRow()` now runs only if the cursor row was on screen before the cancel.

### 0.610.0
- New `src/trash.ts` with `trashVaultFile(app, file)`: calls `FileManager.trashFile`, and when Obsidian 1.15.1 resolves `false` (the system trash refused the file) moves it to the vault's `.trash` with `vault.trash(file, false)` and shows a once-per-session notice.
- All 48 direct `trashFile` calls in 9 files now go through `trashVaultFile`.
- New build gate `scripts/check-trash-file.mjs` (also `pnpm run lint:trash`): fails on any direct `.trashFile(` outside `src/trash.ts`.
- `obsidian` typings pinned to 1.14.4.

### 0.611.0
- Short-screen layout: each view measures its visible height (its box clipped to the visual viewport) and adds cumulative `sp-sq1` / `sp-sq2` / `sp-sq3` classes on the view root below 600 / 460 / 340px; CSS hides the breadcrumb, then the bottom toolbar and draft-tabs strip.
- New setting `shortScreenLayout` ("auto" | "always" | "off"), shown as **Short-screen layout** under List display.
- Fold / unfold button in the view header on mobile: shows every bar or hides every layer until the height crosses a threshold or the setting changes; hidden while the setting is Off.
- Re-measured on visual-viewport and window resizes, view resizes, focus changes inside the view (with re-checks while the keyboard animates) and after each render, at most once per frame; all of it is torn down when the view closes. Desktop with Auto installs no listeners.

### 0.611.1
- The two smaller layers also hide note timestamps.
- The formatting toolbar stays at every layer (0.611.0 hid it at the smallest one).
- A jump-to-level (routes) button appears in the view header whenever the view's own one is hidden: from the middle layer on mobile (it lives on the bottom toolbar), from the first layer on desktop with Always (it lives in the breadcrumb).

### Internal
- Branch changelogs, the parallel-work board, request log and session notes for 0.608.0 to 0.611.1; a parked to-do entry; a doc fix removing a local path from the short-screen changelog. No effect on the plugin.
