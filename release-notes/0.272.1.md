# 0.272.1

## "More commands" in the quick menu

The quick-action star menu now ends with "More commands…", which opens the full
menu, so nothing is ever out of reach from the short menu. It is on by default
and can be turned off in the quick-actions settings.

## Star button stays put on mobile

On a long note, once the show-more toggle appeared, the star button could drop to
the bottom of the note instead of staying with the other buttons at the top. It
now stays in the top row where it belongs.
