# 0.279.27

Covers everything since 0.279.1 (versions 0.279.2 through 0.279.27).

## Tasks & the pinned heading

- **Pressing the complete hotkey on the focused (pinned-heading) note now works on the first press.** Marking a plain note complete has to both turn it into a task and check it; the checkbox used to appear only on the second press. Fixed across several passes: the checkbox is repainted reliably on the heading, the just-completed state is recognized immediately instead of waiting for the metadata cache, and drilling into a note now puts the cursor on that note (so the first keypress acts on it, not a child).
- **The completed checkbox is no longer invisible.** The checked icon used an id that a newer icon set had renamed, so it drew nothing while the empty box drew fine. It now uses the current icon and falls back to a drawn glyph, so it can't silently disappear again — on the heading, the list rows, the task panel, and the detail view.
- **The pinned heading no longer reads as permanently "selected."** It gets the cursor ring like any row instead of a filled highlight, while still being the target for hotkeys and copy.

## Copying

- **Indent-safe copy with `[L1]` / `[L2]` level markers.** When copying a subtree, each line can carry a depth marker relative to what you copied (the top of the selection is always `[L1]`), so nesting survives pasting into apps that strip leading whitespace. The real indentation is kept too, so the markers can be stripped back out later with a regex.
- Available as a setting ("Indent-safe copy") and as a dedicated, hotkey-bindable command, "Copy tree with level markers (indent-safe)".
- **Copy tree from a select-all now levels correctly.** Selecting a note and all its descendants collapses to a single subtree with that note as the root, instead of treating a child as the top level.

## Privacy / obscure

- **Scheduled obscuring — blur folders only during set hours.** A folder set to obscure by default can now blur only inside a daily time window; outside it (evenings at home, say) it stays clear. Overnight windows are supported.
- **Home timezone for the schedule.** Anchor the hours to a chosen zone so the window stays in home time as you travel; "Use current" locks in the device's zone, and recent zones show as chips so an accidental change is one click to undo.
- **Stronger blur on the pinned heading** — the large title text no longer stayed readable through the blur.
- **The author / contributor name in the footer is now obscured** along with the note (the "by" / "edited" labels and timestamp stay readable).
- **Shift- or Cmd-click a blurred note to add it to a selection** without a wasted first click to reveal it.
- A settings note now spells out what obscuring does not cover (it's visual glance-protection, not encryption).

## Heatmap

- **The activity heatmap now reflects every note, not just logged actions.** It folds in each note's own created / modified dates across all folders, so notes whose activity was never explicitly logged still light up their days — and it doubles as a "where did I last leave off" record. The "All notes" view sorted "Recent first" is the flat-list counterpart.

## Navigation, tabs & keys

- **Tab titles lead with the note title, then the folder** (e.g. "My Note — Work"), so multiple open tabs are easy to tell apart instead of all starting with the folder name. The trailing note id was dropped.
- **Navigation history is capped** so it can't grow without bound over a long session.
- **A modifier + arrow key (e.g. Option+Arrow) now reaches its assigned command** instead of being swallowed as a one-row cursor move — so bindings like jump-to-top / jump-to-bottom work.
- **Mod+Shift+F is reserved while a Stashpad tab is focused**, so it no longer opens the global search over the view.

## Editing & attachments

- **The multi-note edit queue** is hardened against notes deleted mid-run, and its notice uses a dedicated "Empty queue" button.
- **Author names in the footer are plain text by default** (a setting makes them clickable links) — so a stray tap near the author no longer opens the author file, e.g. the second tap of a double-tap to enter a just-unblurred note.

## Fixes

- Fixed a rare tab-title rendering glitch where the em-dash and separator could show as stray characters.

## Correction to the 0.279.1 notes

The auto-generated 0.279.1 notes were thin and partly inaccurate; for the record, 0.279.1 actually included:

- Pasted / uploaded attachments link by their basename instead of the full vault path.
- The filename-before-link prefix defaults off, so a paste inserts a clean link without the leading filename.
- Sending a new note from the composer clears any active multi-selection.
- On mobile, the composer's text cursor no longer paints over the side panels or Stashpad's own modals.
- The "Timestamps when copying" settings section got its own heading and intro.
