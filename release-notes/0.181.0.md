# 0.181.0

A large batch since the last release — tasks, attachments, folders, a big mobile
editor pass, plus a pile of fixes and polish.

## Tasks

- **Type a checkbox to make a task.** Start a note with `[]` or `[ ]` and it's
  created as an open task; `[x]` (or `[X]`) creates it already completed. The
  prefix is stripped from the body so the title stays clean.
- **Open all tasks with a shortcut.** New bindable **"Open all tasks"** command
  (default **Shift+T**) jumps to the aggregate "All tasks" view.
- **Due-reminder notifications are tappable.** Tap anywhere on a task-due reminder
  to open the task; a corner **Snooze** button opens the scheduler instead
  (reschedule / reassign) without opening the task. The card is keyboard-focusable.

## Attachments

- **"Open in Stashpad" now works on attachments.** Right-click a non-markdown file
  (image, PDF, …) and pick **Open in Stashpad** to jump to the note that embeds it
  — with a picker when several notes embed the same file.

## Folders

- **New setting: "Folders always open in a new tab."** (Behavior → Windows & Tabs,
  off by default.) When on, opening a folder always opens a fresh tab at the home
  note instead of reusing an open one, and the folder switcher drops its
  "Reveal <folder> tab" entry.

## Editing

- **Composer full-screen button.** A maximize button in the composer opens your
  draft in the full in-app editor; Save creates the note(s) and clears the composer.
- **Edit starts with the cursor at the end** of the note (Split still starts in the
  middle for choosing a split point).
- **Mobile editor overhaul.** The edit/split modal is now a full-height sheet with a
  **pinned action bar** (Save/Cancel always reachable above the keyboard). On a
  phone the Original / Changes / Your-edit sections are a compact **tabbed** layout
  (one at a time) instead of three stacked boxes, the editor is height-capped and
  scrolls, and the controls are tightened so nothing overflows the screen.

## Focused header & long notes

- The collapsed **focused-note header** is now a fixed-height **scroll window** —
  read more of the note in place without expanding (Show more still fully expands).
- **Expanded list notes are scroll-capped** so a very long note doesn't take over
  the list — scroll within it to read the rest.

## Deep links

- The **Open Stashpad link** dialog shows a green "Link automatically pasted"
  confirmation when it auto-fills a link from your clipboard.
- **Cross-vault links hand off to Obsidian.** A pasted link that targets another
  vault (or can't be resolved locally) is passed to Obsidian to open the right
  vault, instead of failing; multi-link pastes route each carefully.

## Fixes

- **Fixed a command-palette (Mod+P) slowdown** introduced with the attachment
  feature — the palette is fast again.
- **No more title flash** when changing a note's color or task status.
- The focused-header expand/collapse toggle works on desktop and actually expands
  the note.
- Breadcrumb right-click menu lists **"Open in new tab"** first.
