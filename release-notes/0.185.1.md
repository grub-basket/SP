# 0.185.1

## Fixes

- **Editor autocomplete suggestions no longer hide behind the modal.** In the
  in-app edit / split editor, the `[[` / `#` / `@` suggestion popup was rendering
  behind the modal and appeared to do nothing. It now layers above the modal, so
  note-link, tag, and `@` completion work as intended. (Pasting/dropping files was
  never affected.)
