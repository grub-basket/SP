# 0.278.1

## Timestamps when copying — now a held-modifier gesture

The "Prefix timestamps when copying" toggle is replaced by a modifier gesture. Copies no longer include each note's timestamp by default; hold a configured modifier while copying to add them.

- Configure it in **Settings → Timestamps when copying** with modifier checkboxes (Shift / Alt / Ctrl / Cmd). No modifier checked means the feature is off — the modifier set itself is the on/off switch, so there is no separate toggle.
- Applies to **Copy** and **Copy tree** (the copies that carry timestamps) and their menu items.
- **Keyboard shortcut:** hold the modifier(s) together with your Copy / Copy tree shortcut. The matcher treats the shortcut plus the extra modifier(s) as a distinct chord, checked before the plain shortcut, so a bare-key binding such as `C` still distinguishes `Shift+C`. A modifier that is already part of the Copy shortcut forms no new chord and is treated as a no-op, so plain Copy is never silently forced to always include timestamps.
- **Context menu:** the "Copy", "Copy tree", and "Copy text" items read the modifier off the click, so holding it while choosing the item includes timestamps. The item label hints the gesture, for example `Copy (hold Shift for timestamps)`.
- **Command palette:** cannot detect modifiers, so palette copies never include timestamps.
- A live status line under the checkboxes reports whether the chosen combination will actually fire given your current Copy shortcut — off, a warning when the modifier collides with the Copy shortcut, a note when no Copy shortcut is bound, or the hold-to-copy instructions — and always notes the command-palette caveat.
- Existing settings migrate automatically: a vault that had timestamps on gains the Shift modifier (so timestamps remain reachable by holding Shift while copying); off maps to off.
- `humanCombo` now title-cases modifier names so they render consistently in labels and hints.

## Pasted and dropped outlines keep a fixed timestamp prefix

Cross-folder paste of a copied subtree, and the drop-subtree-into-composer command, write permanent outline text where provenance matters and have no natural modifier surface. These keep a fixed timestamp prefix regardless of the copy gesture, restoring the earlier default-on behavior for those artifacts.
