# 0.321.2

## Move a note into the note above or below (one action)

Two new commands (bindable in Settings → Hotkeys):

- **Move note into the note above**
- **Move note into the note below**

They nest the note under the note **literally above or below it in what you see** — the one-action version of "Nest under… (in-list)", pick the neighbour, Enter. As with the in-list picker, if "navigate into the parent after moving in" is on, the view follows the note into its new parent; otherwise the parent opens in a background tab. They act on the note under the cursor (or a selection), and won't create a cycle.

## Build your own submenus in the right-click / ⋮ menu

The ⋮-menu builder (Settings → Note Actions & Menus) now lets you **add any Obsidian command** to the menu and **create your own submenus** — give a submenu a name and icon and fill it with actions or commands. Submenus and commands sit in the reorderable top block alongside the built-in actions.

## Icon settings: "Other commands"

The custom-command icon group is now called **Other commands** and updates instantly: adding a command anywhere (star menu, item buttons, ⋮ menu) shows it here right away so you can set its icon, and "Add command…" registers one ahead of time. Rows show whether a command is in use, unused, or not installed, and any icon can be reset.

## View launcher

The launcher's search now ranks **view names above their descriptions**, so typing part of a view's name brings it to the top. (The launcher is a normal command, so you can bind it to a hotkey.)
