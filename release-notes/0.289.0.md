# 0.289.0

Reaction/duplicate UI cleanup, reply upgrades, and two bug fixes.

## Reactions (0.287.0)

- The "add reaction" affordance is now a **stable button in each note row's action
  cluster** (next to the edit / open / more buttons), with a smiley-plus icon —
  on desktop rows, mobile rows, and the focused header. It opens the emoji picker.
- Removed the old under-the-timestamp hover "＋": an empty reaction cluster no
  longer appears on hover, so a row no longer expands/shrinks as the cursor or a
  finger passes over it. Existing reaction chips still show in the meta column
  when a note has reactions.

## Duplicate-hints mobile toggle (0.287.1)

- Moved the mobile "similar notes" toggle to sit immediately left of the
  folder/destination picker in the composer.
- Its on/off state now persists per device (it survives a reload) and no longer
  syncs across devices.
- Clear on/off styling: a filled accent chip when on, muted when off.

## Note color swatch fix (0.287.3)

- Fixed a colored note's drag-grip swatch rendering as a large rectangle (it had
  been painting the grip's whole enlarged hit area). The swatch is a small square
  again while the drag target stays large. (The `background` shorthand was
  resetting `background-clip`; switched to the longhand with an explicit clip.)

## Reply upgrades (0.289.0)

- The reply quote block is now **two lines** — a "Reply to" label, with the quoted
  preview beneath it.
- The quote reads from a **cached preview** stored on the reply note, so a reply
  to a note in another folder still shows a preview without loading the source
  (and is never empty).
- Frontmatter now stores a real internal link to the replied-to note
  (`replyTo: "[[<path>|<Title>]]"`) — it resolves by path (so it stays valid when
  the source is renamed), displays the title, and is clickable/previewable from
  the file itself. Older bare-id reply links still resolve.
- Clicking a reply's quote is location-aware: a source in the **same list**
  scrolls into view and flashes; a source in **another folder/level** opens in a
  new tab (closing that tab returns you to where you were).

## Bug fixes

- **Body checkboxes (0.288.0):** checking a `- [ ]` checkbox inside a note's
  rendered body now actually toggles and saves. Previously the box had no click
  handler — it jumped and reverted without persisting. The click now maps to the
  correct source line (skipping fenced code blocks), rewrites it, and records a
  single undo step.
- **Diagnostics (0.288.0):** the "clear debug trace" command now also clears the
  performance profile, and is renamed "Diagnostics: clear debug trace +
  performance profile."
