# 0.270.4

## Less flicker when moving between a note and its list

On a phone, going up a level and then into a note could flicker: the list jumped
through a much taller scroll extent before settling.

After a navigation, the view re-checks its scroll position a few times over the
next moment, to stay put while note bodies and attachments finish loading. It was
doing that work every time regardless of whether anything had actually moved, so
a list that had already settled kept being nudged, and with the keyboard up it
was measuring against a squeezed screen that then sprang back.

It now re-scrolls only when the list's size has genuinely changed since the last
check, and it waits for the on-screen keyboard to finish moving before the final
adjustment. A settled list is left alone.

Also fixed: entering a short note and then returning to a long parent list no
longer occasionally lands you at the very bottom of the parent.
