# 0.536.1

This release covers every change since 0.535.0. If you use **Obsidian Sync**, Stashpad's "a newer build is installed" notice now waits until Sync has finished before it appears. Clicking **Reload app** while Sync is still busy waits for Sync too, so a reload can't land on a build that's only partly downloaded.

## Updates

- **0.536.0** — The **A newer Stashpad build is installed… Reload app** notice waits for Obsidian Sync.
  - A Stashpad update arrives as three files (`main.js`, `manifest.json`, `styles.css`). Sync can deliver them at different moments, so reloading mid-sync could load a half-arrived build.
  - While Sync is moving files (or is still starting up after launch), the notice is held. It appears once Sync has been quiet for about 5 seconds, so a short pause between batches doesn't release it early.
  - If Sync is paused, showing an error, or not connected, the notice still appears after the same short wait. Sync won't finish on its own in those states, so waiting longer would only hide it.
  - It never waits more than 10 minutes. After that the notice appears even if Sync still looks busy.
  - With Sync turned off, nothing changes: the notice appears just as it did before.
- **0.536.1** — **Reload app** also checks Sync when you click it.
  - The notice stays on screen until you act on it, and Sync can start again in the meantime (for example, when another device sends more files).
  - If Sync is busy when you click, a notice says **Obsidian Sync is still syncing. Stashpad will reload as soon as it finishes.** Stashpad reloads once Sync has been quiet for about 5 seconds.
  - The waiting notice has **Reload now** to skip the wait and **Cancel** to call the reload off. Closing the notice also cancels, so Stashpad never reloads without something on screen saying it will.
  - If Sync still hasn't finished after 10 minutes, Stashpad stops waiting and doesn't reload by itself. It shows a **Reload anyway** button instead.
  - Clicking **Reload app** a second time while it's already waiting doesn't stack up extra notices.
  - The separate **Reload without saving** item in Stashpad's menu still reloads immediately.

## Internal

- The Sync check reads Obsidian Sync's status through a small helper, `obsidianSyncStatus`. If that status can't be read, Stashpad treats Sync as off, so the notice can only ever show sooner, never get stuck hidden.
- The wait logic lives in `checkForSyncedBuild`, `shouldDeferBuildNoticeForSync` and the new `reloadAppForUpdateWhenSynced`. Any pending timers are cleared when the plugin unloads.
- Developer coordination notes recording the 0.535.0 release. They don't ship in the plugin.
