# 0.541.0

This release covers every change since 0.540.3. Stashpad folders now cope with being moved or renamed, including renames made on another computer, such as a coworker on a shared network drive. Before, a tab whose folder had been renamed elsewhere quietly created a new, empty folder under the old name.

## Updates

- **0.541.0** — Moved and renamed folders.
  - **Each Stashpad has an identity.** Its Home note gets a `stashpadFolderId` property the first time the folder is opened with this version. The Home note moves with the folder, so the identity does too, and Obsidian already indexes it, so finding a folder by its ID is instant even on a slow drive. No extra file is added to the folder.
  - **Tabs follow a rename made elsewhere.** A rename made on another computer usually arrives as "new folder appeared, old folder deleted" rather than as a rename. When an open tab's folder disappears that way, Stashpad looks for the folder with the same ID. If there's exactly one, the tab switches to it and a notice says where it went.
  - **No more silent empty folders.** If a tab points at a folder you've used before and that folder is gone, Stashpad no longer recreates it. It shows **This folder was moved, renamed or deleted**, with:
    - the most likely new location, either by folder ID or because it contains notes you recently used in the old folder
    - **Pick a folder…** to point the tab somewhere yourself
    - **Create it here again**, if an empty folder really is what you want
    - **Copy diagnostic report**
  - That page keeps checking. When the renamed folder appears, for example once a network drive or sync catches up, the tab follows it.
  - **Notes can't be written into a missing folder.** Writing would recreate the folder under its old name, so Stashpad asks you to re-link it first.
  - **Copied folders get their own identity.** A copy of a folder starts out with the same ID. When the copy is opened, Stashpad gives it a new one, so the two never get mixed up. If two folders could both be the right one, Stashpad offers both and never picks for you.
  - **Renaming a folder now keeps all of its per-folder settings:** hide completed, hide notes without children, attachments only, include attachments, folder icon, note template, colour names, obscured notes, filter chips, and the remembered cursor and selection. Some of these used to be lost on a rename.
  - New Stashpads made on purpose, from the folder picker or the welcome screen, work exactly as before.

## Internal

- New `src/folder-identity.ts`: `scanHomes`, `findMovedFolder` (looks for the folder by ID first, then by remembered note IDs) and `RelinkFolderModal`.
- New plugin helpers: `ensureFolderId` (only runs once Obsidian has finished reading the vault, and retries for a Home note created moments earlier), `followMovedFolder`, `remapLocalFolderState`, `isKnownStashpadFolder`, `rememberedNoteIds`, `guessMovedFolder`.
- `bootstrapFolder` checks for a missing folder before creating anything.
- A Stashpad tab now reacts when its folder is deleted, and re-checks for the missing folder whenever a Home note changes.
- `stashpadFolderId` is a reserved property, so note templates and clones never copy it.
- Remembered cursor and selection only count as evidence for a folder when those notes exist in the current vault. That memory is shared by every vault on a device, so a "Stashpad" folder in another vault can't make a new one here look moved.
- Debug-trace entries: `folder:missing`, `folder:guess`, `folder:follow`, `folder:id`.
- Developer changelog notes for the branch. They don't ship in the plugin.
