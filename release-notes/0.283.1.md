# 0.283.1

This release brings Stashpad's first set of **team / multiplayer** features —
emoji reactions, quoted replies, teammate-note notifications, and in-composer
duplicate detection — alongside desktop text selection and a batch of fixes.

## Team features

### Emoji reactions (0.280.0, 0.280.1)
- React to any note with an emoji. Reactions are stored per-author in
  frontmatter (list format, `["👍:<authorId>", …]`) so a note carries who
  reacted, and clones/templates never inherit someone else's reactions
  (`reactions` is a reserved frontmatter field).
- Pick from a quick set or type any emoji (shortcode input, e.g. `:avocado:`).
- Reactions render as a **compact cluster in the meta column, below the
  timestamp** — no full-width empty row. The most popular reactions lead; when
  there are more than three, a "+N" chip opens the rest.
- Toggling your own reaction off removes just your authorship; undo/redo is
  supported. New command **"React to note (emoji)"** and a "React…" context-menu
  item.

### Quoted replies (0.281.0)
- Reply to a note (Telegram-style): the next composer send becomes a new note
  linked back to the one you replied to (`replyTo` frontmatter, a reserved
  field). A chip above the composer shows what you're replying to, with a ✕ to
  cancel; it's one-shot and clears on send.
- A reply renders an **"in reply to …" quote block** above its body that jumps
  to the source note on click (and reads "a note that isn't in this folder" when
  the source lives elsewhere). New command **"Reply to note"** and a "Reply"
  context-menu item.

### Duplicate-note hints in the composer (0.282.0)
- As you type a note, a **"Similar notes"** panel above the composer surfaces
  existing notes in the folder with a matching title, so you can spot a possible
  duplicate before creating one. Matching uses Stashpad's token search over
  titles (in-memory, so it runs live per keystroke), ranked exact → prefix →
  contains, shortest first; click a hit to open it.
- New setting **"Similar-note hints in the composer"** (on by default). On
  desktop the search is always live; on mobile it's behind a composer toggle so
  the on-screen keyboard isn't crowded.

### Notifications for teammates' notes (0.283.0)
- When a teammate creates a note in a Stashpad folder — it arrives via sync as a
  new file — Stashpad notifies you, in-app and (optionally) as an **OS desktop
  notification** so activity reaches you with Obsidian in the background.
- Fires only for notes authored by someone else, created in the last 30 minutes
  (so a bulk sync of old notes doesn't flood you), and armed a few seconds after
  launch to skip the startup sync storm. Clicking the notification opens the
  note.
- New **Team activity** settings (Notifications tab): a master switch, a desktop
  toggle (asks OS permission once, falls back to the in-app toast if denied), a
  **watch list** (when set, only those folders notify — livestream one place a
  teammate is working), a **mute-folders** list, and **per-person** toggles.
  A new "Team activity" notification category also honours the existing
  per-category mute and appears in notification history.

## Other changes

- **Select note text on desktop (0.279.30, 0.279.31).** Note bodies are now
  text-selectable on desktop; rows drag from the grip in that mode. A new
  setting chooses text-selection vs whole-row drag, and the grip's grab target
  is enlarged (without moving the 14px icon) for an easier drag.
- **Activity heatmap (0.279.28).** Toggling a category chip now keeps the
  selected day instead of clearing it.
- **Performance instrumentation (0.279.29).** Added measurement points (behind
  the performance-profiling flag) around note writes, edit-modal saves, and
  aggregate-view renders to diagnose reported save/edit slowness.

## Fixes rolled up in 0.283.1

With all the team features integrated together, testing surfaced and fixed
several issues:

- **Crammed note rows / dead drag-grip.** An empty reaction cluster was still
  reserving ~30px in the meta column (the always-present add-button), pushing
  the timestamp and note-start apart and sitting over the grip's hit area. An
  empty cluster now collapses entirely (the add-button returns on row hover), so
  rows are compact again and the grip is grabbable.
- **Grab-from-anywhere grip target** now actually enlarges — the padding was
  being folded into the icon by the default `box-sizing`; forced `content-box`.
- **"Open Stashpad settings: <section>"** commands now deep-link to the
  requested settings sub-page (and reliably on the first, cold open) instead of
  only opening the Stashpad settings page list.
- **Notification-history** description now reflects the configured history limit
  instead of a hardcoded number.
- **Tab title** is centered again for Stashpad tabs (the longer
  note-title-first tab name had read as left-aligned).
- **Duplicate-hints mobile toggle** uses a distinct icon so it no longer
  collides with the composer's adjacent search control.
