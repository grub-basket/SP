# 0.256.0

## Adoption notifications can take you to what was adopted

When Stashpad adopts a note — filling in the frontmatter that makes it a
Stashpad note — it puts that note somewhere you weren't looking. That is the
point of adoption, and it also meant the notification told you something had
happened and then left you to go find it.

Those notifications now carry a button:

- **One note adopted** → **Open note** takes you straight to it.
- **Several adopted** → **Open home** takes you to the note they were all
  adopted under. Adoption files notes at the top level, so that is the folder's
  home note.
- **Several adopted across different folders** → the button names where it is
  going, like **Open Beta home**, and targets the folder that received the most
  of them. There is no single parent in that case, so the label says which
  folder you will land in rather than picking one quietly.

No button appears when there is nowhere sensible to go. *Adopt active note into
Stashpad* can be run on any note you have open, including one outside every
Stashpad folder, and a button that opens a Stashpad view onto a folder that
isn't one would be worse than no button.

This applies to all three places adoption happens: a dropped or synced note
being adopted automatically, the *Fix orphans* command, and the explicit *Adopt
active note into Stashpad* command. All three also now appear in the
notification history with the files they touched, which they did not before.

Opening a note from these buttons behaves exactly like every other "reveal in
Stashpad" in the plugin — deep links, *Open in Stashpad*, pinned items — so
there is nothing new to learn.
