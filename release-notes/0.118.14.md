# 0.118.14 — Folder icons, long-note collapsing, rebootstrap progress, and fork polish

A big batch since 0.117.0: per-folder icons, a reworked Show-more/less for long
notes, a progress bar for Rebootstrap, several legibility/UX fixes, and
refinements to the sheet-versions forking feature.

## Per-folder tab icons (0.118.0, 0.118.6)
- Give any Stashpad folder its own **Lucide icon**, shown on its tab, the folder
  switcher, and its folder-panel row (instead of the default).
- Set it in **Settings → Folders & Storage → "Folder tab icon"**: pick a folder,
  type an icon id (browse at lucide.dev), with a live preview. Blank = default.
  The setting is searchable.

## Long notes: Show more / less (0.118.1, 0.118.5, 0.118.7–0.118.13)
- The 2-line clamp + "Show more / less" toggle is more reliable: the overflow
  detection now measures against the actual clamped height, so the toggle
  appears on genuinely long notes (and not on short ones).
- **Code blocks wrap** inside note bodies instead of bleeding off the right
  edge — and, by wrapping, they can be collapsed like any long note.
- The toggle reflects and controls the row's **auto-expanded** state (when
  "expand the cursor row automatically" is on): an auto-expanded row shows the
  collapse affordance, and clicking it actually collapses.
- Fixed the toggle disappearing after entering a note and coming back, and
  stopped a double-click on the toggle from accidentally opening the note.

## Rebootstrap: progress + clearer result (0.118.4, 0.118.9)
- "Rebootstrap existing Stashpad folders" now shows a **persistent progress
  notice with a bar** that advances per folder, then is replaced in place by a
  **success notice** summarizing what changed — or stating plainly that
  everything was already in sync. The summary is now legible in every theme
  (it previously could render dark-on-dark and look blank).

## Legibility / UX fixes
- **Encryption "no recovery" warning** (0.118.6): was hard to read (orange on
  solid red); now a subtle red tint with normal text in both light and dark.
- **Confirm dialogs** (0.118.2): the right-hand button's focus ring is no longer
  clipped.

## Folder switcher (0.118.3)
- Optional setting to **include your pinned notes in the folder switcher**, so
  you can jump straight to a pinned note from the same picker. Off by default.

## Sheet versions — forking (0.107.8, 0.107.9, 0.118.14)
- A row **Fork** button to branch a note into a new version of its group.
- A fork inherits the source note's `created` timestamp and records when it was
  forked, plus links back to the note it came from and its sibling versions.
- Streamlined to forking only: the earlier clone-flavored extras (a "cloned-at"
  timestamp and a blank-version "+" button) were removed; ordinary Stashpad
  clone commands are unchanged.
