# 0.457.0

Task rows now show their **parent note** for context. In the All-tasks view and the Daily Review, a task whose title is ambiguous on its own (e.g. "call back", "review") now shows the note it belongs under (↰ parent title) in its meta line — unless the task sits at the folder home, where there's no parent to add. Resolved from the `parentLink` recovery wikilink, so there's no extra per-row vault scan.
