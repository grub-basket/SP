# 0.321.1

## Move a note to its visible neighbor

Two new commands (bindable in Settings → Hotkeys):

- **Move up past the note above it (visible order)**
- **Move down past the note below it (visible order)**

Unlike "Move note up/down" — which step one slot through the full list of siblings — these move the note next to the one **literally above or below it in what you're actually looking at**. So when a filter hides some notes, or you've sorted the list, the note lands where you see its neighbour rather than swapping with something hidden. They act on the note under the cursor (or a single selected note), keep the note under the cursor, and switch the folder to manual ordering the same way the existing move commands do. Moving one note at a time; a note nested under a different note isn't a swap target.

## Custom-command icons

The Command icons settings (Settings → Note Actions & Menus) gain a **Custom commands** group. Any Obsidian command you add to the star menu, the item buttons, or the ⋮ menu now shows up here automatically so you can give it an icon, and **"Add command…"** lets you register a command's icon before you wire it anywhere. Each row shows whether the command is in use, not yet used, or not installed, and its icon can be reset to the default. The command pickers no longer offer commands you've already added.
