# 0.306.0

Tasks & reminders got a big pass: one unified scheduler, an "auto-fail if
overdue" option, and a few fixes — plus locked (encrypted) pinned notes now
show up in the Pinned list.

## Scheduling & reminders

- **One unified due/schedule picker.** Snooze (from the list, the task panels,
  and the review) now opens the **same full picker** as Set-due / Assign —
  date + time, quick +/- adjusts, presets, assignees, tags, and repeat &
  reminders — pre-filled from the note, so a plain reschedule keeps your
  existing assignees and recurrence. No more two slightly different pickers.
- **Auto-fail if overdue.** A new option (in the scheduler) for deadlines that
  shouldn't sit open forever: once the task is past due and still open, it's
  marked **done and tagged `failed`** (with `outcome: failed`). It's the mirror
  image of "Auto-complete after", which resolves a miss silently.
- **"Run due-task checks now"** command — fires the reminder / auto-complete /
  auto-fail sweep on demand instead of waiting for the periodic check.
- **Snooze always opens a new tab** — the reminder toast's Snooze no longer
  navigates (hijacks) whatever tab you were on; it opens the task in a fresh
  tab, then the scheduler.

## Scheduler layout & polish

- The **action row (Clear / Cancel / Set) moved to the very bottom** of the
  picker, beneath every input section — the date **presets (Today / Tomorrow /
  Next week)** stay grouped up top with the date controls.
- The **date field's top edge is no longer clipped** (its focus / selection
  outline was being shaved by the modal's scroll-clip).
- **Facelift** for the Repeat & reminders and Auto-fail sections — bold section
  headings and readable text that match the Assign / Tags sections, instead of
  tiny muted fine print. The "Auto-fail if overdue" toggle is its own top-level
  option, not buried inside the experimental repeat section.

## Encrypted notes

- **Locked pinned notes now appear in the Pinned list**, under a "Locked"
  heading with a lock icon and the folder they live in. Clicking one opens the
  unlock flow. This reads only the small plaintext placeholder that already sits
  next to a locked note — never the encrypted contents — and it honors
  hide-titles: a bundle locked with titles hidden isn't advertised here.

## Lists

- **Switching folders lands reliably at the newest notes** and no longer comes
  up a few rows short on large (windowed) folders.
