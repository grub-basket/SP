# 0.419.0

Two mobile composer fixes.

- **Collapsible formatting toolbar on mobile.** The composer formatting toolbar ate vertical space on a phone, so it is now collapsed by default on mobile. A chevron toggle tucked just beneath the composer expand button shows or hides it, and the choice persists (`composerToolbarCollapsedMobile`). Desktop is unaffected — the collapse class only takes effect under `.is-mobile` — and the edit modal keeps the toolbar as before.
- **Compact find-in-list bar on mobile.** Obsidian's default text-input chrome (min-height, border, radius) had turned the find bar into a tall capsule that shoved the list content up. That chrome is stripped on mobile and the padding tightened, taking the bar from roughly 90px to ~52px. The input uses a 16px font so iOS doesn't zoom the viewport on focus.
