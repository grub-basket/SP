# 0.369.0

## Clearer "Merge this copy?" confirmation

The confirmation shown when you merge one duplicate into another is easier to read, especially with long filenames.

- Both filenames are now **monospace** and each sits on its own full-width row under a bold action label ("Keep this copy:", "Discard this copy — it moves to the trash:"), wrapping cleanly instead of running into the sentence or off the edge.
- The explanation of what gets merged, and the "Undo restores both" reassurance, stay in the normal font with the names inline.
