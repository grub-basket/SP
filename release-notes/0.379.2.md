# 0.379.2

## Sync your Stashpad settings through a vault folder (opt-in)

New in **Settings → Folders & Storage → "Store settings in a vault folder (syncs everywhere)"**: move Stashpad's large, list-type settings out of the plugin's `data.json` into a normal vault folder (default `Stashpad Config/`), so that **any** file sync — Obsidian Sync, Git, Syncthing, iCloud — carries them, not just Obsidian's plugin-settings sync. It also shrinks `data.json`, so saves rewrite less.

- **What moves:** snippets, saved views & searches, menus & toolbar, note templates, per-folder appearance (folder icons, obscure, colour aliases, custom palette), and search scope. **What stays in `data.json`:** core preferences, hotkeys, encryption state, per-device items, and anything with special cross-device handling — so nothing sensitive rides on the folder being present.
- **Opt-in and reversible.** Enabling makes a one-time `data.json` backup first; turning it off moves everything back into `data.json`. A `DO NOT DELETE` sentinel in the folder guards every write, so config can never scatter into the wrong place.
- **Change the folder** any time — Stashpad copies your config across and keeps the **old folder as a synced mirror** (a redundant backup it keeps up to date). You can **Add mirror** to keep extra synced copies, or **Stop mirroring** to drop them; a mirror you add is populated to match immediately, and turning one back on re-syncs it.
- If the folder is enabled but not present on a device yet (still syncing), Stashpad shows the defaults and says so, rather than silently — and never overwrites the folder that's on its way.

This is a bounded, safe first version; core preferences and hotkeys deliberately stay in `data.json` for now.
