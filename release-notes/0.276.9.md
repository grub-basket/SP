# 0.276.9

Bulk actions, an edit queue, a merge-with command, and performance.

## All notes: select and act

The All-notes index gains a **Select** mode: turn it on and each note gets a
checkbox. A bar shows how many you've picked and acts on them all at once —
**Open, Complete, Reopen, Copy links** (as `[[wikilinks]]`), or **Delete** (with
a confirmation that notes go to trash and child notes aren't moved).

## Merge with…

A new **"Merge with…"** command: select one or more notes, run it, and search for
the note to merge them into. The oldest-created note is kept, bodies are joined in
creation order, all children are inherited, and the whole thing is undoable — so
you can consolidate a single note into another by searching for it (the plain
Merge needs two or more selected).

## Edit several notes in a row

Selecting multiple notes and choosing **Edit in Stashpad** now opens them one at a
time: save or dismiss each and the next appears, with a progress notice and a
"Stop rest" control to bail.

## Encryption

Each folder's menu gains a **per-folder encryption on/off** toggle — mark a folder
as one whose notes should be encrypted (the "Encrypt everything applicable" sweep
then locks its plaintext).

## Performance

- **Bulk delete and merge feel instant**: the affected rows collapse immediately
  while the work happens in the background, instead of waiting for it to finish.
- The **activity heatmap** no longer re-reads and re-parses the whole action log
  on every render — it caches the parse until the log actually changes. On an
  active vault with the heatmap open this was a real, and now removed, cost.
