# 0.508.0

Three changes since 0.505.0, focused on catching duplicate notes and tidying the composer toolbar.

## Duplicate detection for drafts

### 0.506.0 — Manual duplicate check + AI-contributor button moved
- New composer toolbar button, **Check for duplicate notes** (magnifying-glass icon): loads the current draft into search so you can quickly see whether the note already exists. There's also a command-palette entry, "Check for duplicate notes (search with current draft)". The button is composer-only and can be hidden or reordered like the other toolbar buttons.
- The **AI-contributor (🤖) button** now sits at the **end of the formatting toolbar** instead of in the button rail. If the formatting toolbar is hidden, it falls back to its previous spot so it never disappears.

### 0.507.0 — Per-draft duplicate badge in the Drafts manager
- Each draft in the Composer Drafts manager now shows how many existing notes in that draft's folder already match it: a **"N matches"** badge (click it to open a menu of the matching notes, each in a new tab), or **"no duplicates"** when none are found.
- Matching compares the draft's first line against each note's first line, normalized so a checkbox or markdown-prefixed line (`- [ ] Buy milk`) still matches a plain note titled "Buy milk". The per-folder scan is capped for responsiveness in very large folders.

### 0.508.0 — Drafts reminder count now matches the manager
- The "N unsent drafts" reminder and the Drafts manager now read from a single shared list, so the reminder's number can no longer disagree with what the manager actually lists. Previously the reminder skipped edit-in-progress drafts while the manager showed them, so the two counts could differ.
