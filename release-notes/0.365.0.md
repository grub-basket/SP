# 0.365.0

## Duplicate-id modal overhaul

The **Duplicate note ids** modal (Find duplicate note ids) is rebuilt for scanning and deciding, on desktop and mobile. Presentation and copy only — the sorting, verdicts, merge/discard flows, scroll memory, and rescan behave exactly as before, and the modal's accessibility rules still hold (emphasis by weight, semantic text colours on a neutral surface, never a red fill under a red label).

- **Summary at a glance.** Three stat chips — duplicate ids, hidden copies, folders — and one lead line replace the three-paragraph introduction. The full explanation is folded into a **"How to decide what to keep"** block so it never blocks the list.
- **Rows you can scan.** Each copy leads with a status chip (**Shown in list** / **Hidden copy**) plus an independent **Conflict copy** chip — so a shown copy that is itself the conflict copy stays legible. The filename is the prominent line (the only thing that tells copies apart), the folder sits demoted beneath it, and the verdict sits with the name.
- **Consistent actions.** Open / Compare / Merge into… / Discard as an icon+label cluster — on one line on desktop, wrapping with 44px tap targets on mobile.
- **Compare view.** The two copies appear as labelled cards, the colour legend sits up front, then the frontmatter diff and the body diff; the footer (**← Back to list** / **Open hidden copy**) stays reachable on mobile.
- **Clearer discard prompt.** The file being discarded is named on its own line.
- **Mobile.** Rows stack to a single column with the filename unclamped, the compare view uses one column, and the modal joins the softened 14px corner rule.
