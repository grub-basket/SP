# 0.193.0

## Tasks

- **"- [x]" now creates a task.** A leading `-` (or `*`/`+`) in front of a checkbox is
  accepted everywhere `[x]` already was. Copying a task out of Stashpad produces
  `- [x] …`, so pasting it back used to make a plain note that merely *looked* like a
  checkbox. It now becomes a real task again.
- **Pasting a checklist creates separate tasks.** When every line of what you submit is
  a checkbox, Stashpad makes one task per line instead of a single note full of
  checkbox text — even if "split on newlines" is off. New setting, **on by default**:
  *"Split a pasted checklist into separate tasks."*

## Importing

- **Colours by name.** The importer understands `[color: red]`, `[color: Amber]` and
  friends — Stashpad's nine palette colours plus common synonyms (yellow, gold, teal,
  cyan, violet). The `| alias: name` half is optional, so text you write by hand (or
  paste from elsewhere, which carries no colours at all) can set a colour with just a
  name. Unknown names are matched against that folder's own colour aliases.
- **Pop the importer out into a tab.** The import modal now has **"Open in a tab"** —
  the same idea as the edit/split editor — so a long outline gets a full-size window.
  Whatever you've typed and any options you've set come across with it.

## Fixes

- Removed a lint-suppression directive that the community-plugin review rejects.
