# 0.207.0

- **Line numbers in the editor.** The edit/split editor now has a line-number
  gutter down its left side. It stays aligned when a long line soft-wraps —
  the number keeps its place beside the line's first row rather than drifting
  a row further out with every wrap — and it scrolls in lockstep with the text.
- **Line count in the editor stats**, alongside the word and character counts:
  `12 lines · 340 words · 1,802 chars`. Lines are counted as the logical lines
  you typed, matching the gutter, not as wrapped rows.
- Both are on by default and can be turned off with **"Line numbers in the
  editor"** in settings. Desktop only — on a phone the gutter costs width the
  editor needs more.
