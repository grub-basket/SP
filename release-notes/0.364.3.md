# 0.364.3

Everything since 0.322.1, grouped by version. Highlights: a **kanban board** (columns by color, tag, or status), a global **quick capture** box, a **formatting toolbar** with user **snippets**, **per-note version history**, folder-based **cross-vault transfer**, a big mobile-composer reliability pass, and a reorganized note menu.

## 0.364.3

- Quick capture's split toggle gets a **"Split"** label beside its icon, and the icon switches to `list-end` — the same one the composer's split toggle uses — for consistency. Attach sits immediately to its right.

## 0.364.2

- **Quick capture gains the formatting toolbar** (composer/edit-modal parity): the same snippet + bold/highlight/code/link/etc. buttons above the textarea, gated on the toolbar setting. Scrolls horizontally on mobile.
- **Split toggle** in the quick-capture action row: each line/paragraph (per the split mode) files as its own note, using the same splitter the composer uses.
- The **"File into" destination row moves to the bottom**, just above the Attach / Cancel / Save buttons.
- **Softer mobile modal corners**: Obsidian gives mobile modals a very round 30px radius; Stashpad's own modals (quick-capture and edit/split) are dialed back to 14px, scoped so Obsidian's core surfaces and themes are untouched.

## 0.364.1

- **Kanban group-by picker.** The board now pivots on any of Stashpad's first-class dimensions:
  - **Color** — columns are the palette plus colors in use; drop sets the color.
  - **Tag** — columns are tags in use; a card appears in each of its tag columns, and dragging **moves** it (removes the source column's tag, adds the target's).
  - **Status** — **To do / Done** from the `completed` field; drop checks or unchecks the task.
- The **"None" column** (cards lacking the property) is **hidden by default**, with a one-tap `Show "No tag" (N)` reveal and an empty-state hint so the color board never opens looking empty. Group-by and the show/hide choice persist.

## 0.364.0

- **Kanban board** — a new view type. Pivot a folder's notes into columns by color (plus a "No color" column); every note is a card; drag a card into a column to recolor it (undoable). Click a card to jump to it. Opened from the view launcher ("Kanban board") or the "Open kanban board" command; scoped to the active folder or the whole vault.
- Columns come from the color palette ∪ colors in use, so empty palette columns are still drop targets. Named colors (aliases) show as column titles.
- New `activeStashpadFolder()` helper (the most-recent list view's folder).

## 0.363.12

- **Settings writes are trailing-coalesced.** A burst of saves used to trigger one disk read + write each; while a write is queued but not started, further saves now join it, so a burst collapses to ~2 disk writes instead of N — with no dropped save and the collision-merge guard intact.
- **Save-path diagnostics**: the trace records `settings:save` (dedups to `(xN)` = burst size), `settings:write {coalesced:N}`, and `settings:write-quiet`. The composer-debug command now includes the full perf trace and the latest `stall {ms, after}` line, so one copy carries everything needed to diagnose a freeze. It also says when the debug trace is off.

## 0.363.11

- **Pop-out button placement fixed**: the edit chip's pop-out and ✕ now sit flush together at the right edge (two auto-margined buttons had been splitting the free space).
- **Straighten curly quotes on send**: iOS Smart Punctuation's `“ ” ‘ ’` become straight `"` and `'` on send, behind a new **"Straighten curly quotes on send"** setting (on by default).

## 0.363.10

- **iOS smart-punctuation curly quotes now auto-pair on mobile.** Smart Punctuation converts a typed straight quote to a curly one before it reaches the pair logic; the curly openers (`“`→`”`, `‘`→`’`) are now recognized and closed correctly.

## 0.363.9

- **Edit modal really fits mobile width.** The overflow source was the edit tab panel expanding to its widest child; `min-width:0` down the flex chain lets the toolbar scroll internally and the textarea wrap to width.
- Pop-out button moved toward the right edge (superseded by the flush placement in 0.363.11).

## 0.363.8

- **Pop a composer edit out into the edit modal.** When editing a note in the composer, the "Editing" chip gains a pop-out button that opens the full edit modal on that note, **carrying the in-progress text**. The Original tab still shows the saved body, and the composer's edit draft is dropped so no stray "Resume editing" entry lingers.

## 0.363.7

- **Root-cause fix for mobile autopair doubling.** iOS soft keyboards ignore `preventDefault()` on `keydown`, so an auto-paired opener landed twice (`(`→`((`, `"`→`""`). Pairing now runs off `beforeinput` on mobile, which iOS honors. Desktop is unchanged; the pairing logic is shared.

## 0.363.6

- The on-send autopair cleanup now also trims a doubled opening quote (`"""after"` → `"after"`), leaving valid quoted spans, apostrophes, and wikilinks untouched. (Superseded as the primary fix by 0.363.7; kept as a backstop.)

## 0.363.5

- Edit-modal formatting toolbar given `min-width:0`/`max-width:100%` so it scrolls instead of widening its container (completed by the flex-chain fix in 0.363.9).

## 0.363.4

- **Mobile autocomplete waits for the keyboard to rise.** With the keyboard down, tapping the `[[`/`#` toolbar button used to reveal the popup straight into the rising keyboard; the reveal now waits until the viewport settles, with a hard cap so it can never stay hidden.

## 0.363.3

- **iOS placeholder "N" fix**: the native textarea placeholder painted as a stuck "N" after inserting and deleting an internal link. The visible ghost text is now a custom overlay (the native placeholder is painted transparent and drives visibility via `:placeholder-shown`), so iOS paints it correctly.
- **Reliable mobile keyboard detection**: keyboard state is read by comparing the visual viewport height to its own historical max, since `innerHeight` tracks the keyboard in Obsidian's mobile webview.
- **Coalesced settings broadcast**: a burst of saves recomputes the render signature and notifies views once per microtask instead of once per call.
