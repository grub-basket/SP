# 0.208.5

- **Fixed for real: deep-link auto-paste in secondary windows.** With several
  vaults open, the "Open Stashpad link" modal auto-pasted in two vaults'
  pop-out windows but never a third — after an earlier fix that was supposed to
  address exactly this.

  The earlier fix used the modal's own window's clipboard, which only helps
  when that window happens to be the one the OS considers focused; otherwise
  the read is rejected. That's why the symptom followed some windows and not
  others, and survived being "fixed". Both the auto-prefill and the Paste
  button now read through Electron's clipboard, which has no focus or
  permission dependency, falling back to the browser API on mobile.
