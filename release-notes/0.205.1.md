# 0.205.1

- **Stashpad now leaves another outliner plugin's folders alone, explicitly.**
  0.205.0 stopped claiming them by tightening what counts as a Stashpad note;
  this adds the durable half of the agreement: a folder holding another
  plugin's own manifest file is skipped outright. That stays correct no matter
  which frontmatter fields either plugin adds later.
- Nothing is written or migrated — it only affects which folders Stashpad
  lists. Remove the other plugin's manifest and the folder reappears.
