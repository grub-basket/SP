# 0.275.1

New views and controls, plus a log fix.

## Due calendar: Month / Week / Day

The due calendar gains a Month / Week / Day switcher, like other calendar apps.
**Week** shows seven day-lanes, each with that day's full list of notes; **Day**
is a single-day agenda. The arrows step by whichever period you're viewing.

## Task timeline: complete tasks and filter by span

- A checkbox on each row **marks the task complete (or not) right from the
  timeline**, and a calendar button lets you **set a specific completion date** —
  it fills in the completion date and marks the task done in one step, for when
  you want the bar to end on the real day rather than "now".
- A **"Longest first"** sort surfaces the tasks and projects that have stretched
  on the longest.
- A **"Custom…"** window lets you type an exact number of days to look back,
  instead of only the 30/90/all presets.

## Log: no more false "edited elsewhere"

An edit made through Stashpad's own editor was being recorded in the action log
as an edit from *outside* Stashpad. In-app edits are now recorded correctly (a
genuine edit from another app or sync is still flagged as external).

## Select mode starts empty (mobile)

Entering select mode no longer auto-selects the note you last tapped or focused —
it starts with nothing selected, so you build the selection deliberately by
tapping, and never act on a note you didn't mean to pick.

## Timeline row polish

The set-completion-date button now sits next to each checkbox instead of after
the note title (it was truncating the text and rendering as an invisible icon).
The title fills the rest of the column, ellipsizing only where it meets the
timeline.
