## Saved views

Save a folder + its filters as a named view and jump back to it from the launcher.

- Set up a Stashpad the way you like it — a folder, a time filter, a tag or color filter — then run **"Save current view (folder + filters)…"** and give it a name.
- Saved views appear in the **view launcher** (the Launch View button / command) with a bookmark icon; pick one to open it in a new tab with everything applied. Each has a ✕ to remove it. Saved views sync across your devices.
