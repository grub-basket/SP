# 0.275.3

A new split method, a tab-focus fix, and a small heatmap default.

## Split on a custom symbol

The split dialog gains a **Custom** method: type any symbol or string to split
on. By default it's **nondestructive** — the delimiter stays at the end of each
piece, so splitting a paragraph on `.` turns each sentence into its own note with
the periods intact. Tick **Remove it on split** to strip the delimiter instead.
Each resulting note is trimmed of surrounding whitespace, and a live preview
shows exactly what you'll get.

## Closing a tab returns you where you opened it

When you open a note from one of the overview tabs (All notes, Due calendar, Task
timeline) or from a link, closing that note's tab now returns focus to the tab
you opened it from — not whatever tab happens to be on the right.

## Activity heatmap opens on today

The activity heatmap now selects today when it opens, so the detail panel shows
the day's activity right away instead of being blank until you click a square.
