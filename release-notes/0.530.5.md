# 0.530.5

This release covers every change since 0.528.3. It adds **Showcase**: any level can open as a single page for reviewing visual work with other people. Each note shows its images and PDFs at full size, gets quick reactions, and has a feedback column made of ordinary notes. The page can be exported as one web page file.

It also fixes the version number. 0.528.3 was published after 0.529.0 and showed a lower number; this release is above both.

## Showcase — a level as one page

- **0.530.0** — **Opening it.** The **View** menu (where Nested / Flat / Everything live) has a new **Showcase** row. It opens the current level in a new tab. Also available as the command "Open showcase (page view with feedback) for this level" and from the launcher.
- **0.530.0** — **The page.** Each note in the level is a numbered section, in the level's own order: manual order, sort mode and list pins carry over. The note's text appears above its files.
- **0.530.0** — **Files at full size:**
  - Images fill the width, capped at 85% of the window height. Click one to open the usual file preview, with all of that section's files as slides.
  - PDFs show every page inline. Each one loads only when it scrolls near the screen.
  - Video and audio get players.
  - Any other file gets a card with an Open button.
- **0.530.0** — **Options.** A note with several files presents them as **Option A, B, C…**, so a set of proposals can be compared. A toggle in the top bar switches between **Stack** and **Side by side**.
- **0.530.0** — **Reactions:**
  - Every section has 👍 👎 ✅ ❌ plus the full emoji picker. These are the note's normal reactions, so they also show in the list.
  - When a note has two or more files, each option gets its own 👍 👎 ✅ ❌, stored on the note as `attachmentReactions`.
  - Hovering a reaction shows who reacted. Reactions can be undone.
- **0.530.0** — **👎 and ❌** are now part of the default quick reactions everywhere, so a proposal can be rejected as quickly as approved. Customised reaction presets are unchanged.
- **0.530.0** — **Feedback is just notes.** The right-hand column lists the section's child notes as comments: author and role, time, the text, and replies indented under it. To post, type in the box at the bottom.
  - Each new comment is an ordinary child note and an open task, so **Resolve** is the usual complete checkbox. Undo works.
  - A comment can be about the **whole section** or **one file** ("on Option B · cover.png"). Click that label to scroll to the file.
  - With an image selected, **Pin a spot** and click the image to drop a numbered pin. The pin's number matches the comment's number, and clicking a pin highlights its comment.
  - The top bar counts open feedback (click it to jump to the next section with open items) and has **Hide resolved**.
- **0.530.0** — **In the normal list,** a comment about one file shows a **"Feedback on <file>"** chip. Clicking it opens that file in the preview.
- **0.530.0** — Live updates. Edits, new comments, reactions and resolves redraw only the part of the page that changed, so a new comment doesn't reload the PDF above it. A half-typed comment survives a redraw.
- **0.530.0** — Blurred ("obscured") notes stay blurred in Showcase until revealed, and only in that tab.
- **0.530.0** — The Showcase tab comes back after restarting Obsidian, even when the matching Stashpad tab hasn't loaded yet.
- **0.530.0** — Four new Stashpad-managed note properties: `attachmentReactions`, `feedbackOn`, `feedbackPin` and `feedback` (a marker). Clone and templates don't copy the first three.

## Showcase export

- **0.530.1** — **Export** in the Showcase top bar saves the page as **one web page file** that opens in any browser, with no Obsidian needed. It can be emailed or put on a shared drive. The file goes to the Stashpad's `_exports` folder (or the export folder set in Settings).
  - Images are embedded in the file.
  - **PDF pages are turned into images** using Obsidian's own PDF engine, so they show anywhere, including mail previews and print.
  - An optional switch adds **feedback and reactions**: reaction counts with names, numbered comments with author, role, date and target, replies, resolved state, and pins on the images.
- **0.530.3** — Exports are safe to share:
  - Scripts, embedded frames, forms and remote images from note text are removed.
  - The page carries a content policy that only allows its own built-in script.
  - A file that can't be read is listed instead of stopping the export.
  - Very large exports list the biggest files by name instead of embedding them (about 150 MB total on desktop, 25 MB on mobile; 40 MB per file).
  - Blurred notes and comments are left out unless revealed in the tab.

## Fixes from review

- **0.530.2** — Posting a comment is a single file write. It no longer shows up in the activity log as an edit from another device. It doesn't get the folder's note template appended. Undoing it no longer puts its text into the list's composer.
- **0.530.2** — A comment can no longer be posted twice on a slow network drive. The box is locked ("Posting…") until the note exists.
- **0.530.2** — Hidden notes stay hidden in the feedback column too. "Cover everything", the obscure schedule and folder defaults apply to Showcase immediately.
- **0.530.2** — Per-option reactions are stored as a plain list, so Obsidian's Properties panel no longer marks them as an unsupported type.
- **0.530.2** — Feedback about a file in a folder whose name contains `#`, `^` or `|` now finds its file.
- **0.530.2** — A level with many notes shows the first 30 sections, then **Show more**.
- **0.530.2** — Adding or reordering a page no longer reloads every page below it.
- **0.530.2** — PDFs over 60 MB open in Obsidian's own viewer instead of loading into memory.
- **0.530.2** — The reaction picker's 10 quick reactions fit on one row.
- **0.530.3** — Removed a 30-second background refresh. It couldn't pick up a coworker's change any sooner than Obsidian itself does, and it moved keyboard focus.
- **0.530.3** — Export: one export runs at a time; two exports in the same second get distinct names; long or emoji titles make valid file names; very tall PDF pages still render; the progress notice names the section, file and page.
- **0.530.4** — Creating a note now escapes backslashes in its author, reply, quote and attachment properties. A quoted reply ending in `\` used to break the new note's properties.
- **0.530.5** — A just-posted comment no longer stays labelled "Unknown" when Obsidian reads the new note late, which is common on network drives.
- **0.530.5** — `feedback` is no longer a reserved property, so imports, merges and templates keep a `feedback` property of your own.
- **0.530.5** — Reaction buttons and pins keep keyboard focus when something else on the page changes. Navigating with the breadcrumb resets "Show more". Changing obscure settings no longer reloads every section.
