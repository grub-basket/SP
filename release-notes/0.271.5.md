# 0.271.5

## Rail refinements

**The layout switch is instant and local.** Flipping a rail's layout now changes
just that view and takes effect immediately, rather than re-rendering every open
note. It is a quick "show me this differently right now"; the saved default is
unchanged.

**Attachment names appear instantly.** Hovering an attachment shows its full name
right away instead of after the usual tooltip delay.
