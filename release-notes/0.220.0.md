The detail panel no longer goes stale when you close a tab, and keeps a copy of what you were last looking at.

## 0.220.0

- **The detail panel notices when a Stashpad tab closes.** It previously kept showing that tab's last selection indefinitely — the panel had nothing listening for tabs opening or closing, and the closed tab's view stayed alive behind the scenes with its last selection intact.
- **It keeps a copy of what was last previewed.** Instead of emptying when there is no Stashpad list open, the panel keeps showing the note you were last looking at, labelled "Last viewed" so it is never mistaken for a live selection. Open a Stashpad list again and it resumes following your selection.
- If the retained note is deleted, the panel clears properly rather than pointing at a file that no longer exists.
