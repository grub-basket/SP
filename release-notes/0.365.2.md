# 0.365.2

## Fix

- **Kanban "Group by: Status" keeps To do before Done.** 0.365.1's in-use-columns-first ordering applied to every group-by mode, so when "To do" had no cards it moved behind "Done". That ordering is now Color-only: Status keeps its fixed To do → Done order, and Tag columns stay alphabetical. The narrow empty-column rail is also Color-only, so an empty "To do" keeps full width.
