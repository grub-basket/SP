# 0.373.0

## 0.372.0 — "Move in list" in the Move menu

- The Move ▸ context submenu now leads with **Move in list** — the in-list picker (arrow keys + Enter to reposition or nest a note within the current list), previously only reachable by its hotkey. Existing menus get it added at the front automatically; a renamed Move submenu is left untouched.

## 0.373.0 — Inline-format keyboard shortcuts

- **`Mod+B`, `Mod+I`, `Mod+E`** now apply **Bold**, *Italic* and `Code` to the selection in the composer (or drop an empty pair at the caret). The edit/split editor also gets `Mod+B` and `Mod+I` (its `Mod+E` continues to toggle the edit/split surface).
- Deliberately a small, universal set — the rest of the formatting toolbar stays click-only, so there are no unmemorable chords or collisions. The shortcuts fire only on the note-editing fields, never on search or folder-name inputs.
