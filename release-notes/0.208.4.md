# 0.208.4 — clean titles

- Breadcrumbs, the focused header, crumb tooltips and the tab title no longer show
  raw Markdown syntax. A note beginning `**Atomic Habits** — James Clear` displayed
  its asterisks, because titles come from the note's first heading or first body
  line verbatim.
- Emphasis, inline code, strikethrough, highlight, links, images, wikilinks
  (showing the alias when present), leading block markers and backslash escapes are
  all handled. Stripping is deliberately conservative, so `snake_case_name`,
  `a_b_c`, `2 * 3 = 6` and a trailing `5 stars ***` are left alone.
- Notes are unchanged on disk — this affects display only.
