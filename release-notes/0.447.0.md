# 0.447.0

A batched release spanning development versions 0.420–0.447. Highlights: a new
**Export to HTML / PDF** feature, the **view-in-context** (flat neighbourhood + reply
thread) view, and a large batch of quality-of-life fixes.

## Export to HTML / PDF (new)

- Export selected notes, a subtree, or a reply thread to a single **HTML** document,
  or to **PDF** on desktop (via the OS/Chromium print pipeline — selectable text, real
  pagination).
- Export dialog: choose the output **format** (HTML / PDF), the **scope** (selected
  notes only, selected + subtree, or the reply thread), whether to **split each
  top-level item onto its own page**, and (desktop) a **system save-location** dialog.
- Attachments are copied to a sibling `<name>_assets/` folder next to the document.
  Images are **both embedded inline and linked** as separate items; non-image files are
  copied to the folder and linked.
- The export stylesheet is a self-contained "theme" — groundwork for future publishing.
- Reachable from the note context menu under **Share & export ▸ Export to HTML / PDF**.
- PDF is desktop-only; on mobile the dialog offers HTML (which opens and prints
  anywhere).

## View in context (new)

- A narrowed, on-demand context view for a note: a **Flat** mode (the note's tree
  neighbourhood — ancestors, siblings, children) and a **Thread** mode (the reply
  conversation, walking the `replyTo` chain up and the replies down).
- Threads are **vault-wide and cross-folder** — a reply that lives in another folder is
  pulled in (read-only) so no part of the conversation is missed.
- Context tab with a Flat/Thread segmented toggle.

## Folder switcher

- The quick folder switcher now honours the **"Folders always open in a new tab"**
  setting — picking a folder opens a new tab when that setting is on (previously it
  always switched the current tab in place). A Mod/Ctrl-click inverts the behaviour.

## Search

- Desktop **search-scope toggle** on the ribbon, matching mobile.
- Search hotkeys are locked to their command, independent of the scope toggle.
- A searched-for note now **expands (un-clamps)** when it is revealed.
- Search-in-parent honours the open-in-context / new-tab settings.

## Composer, editor & toolbar

- Composer buttons: attachments moved to the left of the destination picker.
- **Quote** toolbar button, plus a left bar rendered on blockquotes.
- Mobile: the composer is hidden while finding in the list (find no longer raises the UI
  too much).
- Mobile toolbar toggle — swaps position above the expand button, with state-matching
  chevrons.
- Mobile select mode now exits after a nest/move action consumes the selection.

## Preview modal

- **"Open in the default app"** button in the file-preview modal.
- **"Reveal in large text"** button on the note slide of the preview modal.

## Notes list & navigation

- The attachment rail is always visible for collapsed notes and headings.
- New setting: **"Expand headings by default."**
- **"Building calendar…"** loading indicator (the due calendar could appear blank for a
  few seconds).
- Mobile: the route (jump-to-level) button moved to the left of the breadcrumb.
- **"Move in list"** surfaced as a default star-menu action and near the top of the
  context menu ▸ Move.
- Due-calendar legend: "Links" renamed to "Date links."

## Settings & menus

- Snippet icon added in settings; **Edit** added to the default star menu (quick wins).

## Fixes & hardening

- Guard the split modal against a double-press duplicating its output.

## Under the hood

- Notification-log migration: many more surfaces routed through the unified
  notification system (main, view, modals, locked-menu, re-encrypt paths).
