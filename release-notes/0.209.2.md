# 0.209.2

## Selection diagnostics

- **New command: "Diagnose selection (select-all mismatch)".** For when Select All
  appears to miss notes. Run it straight after the bad selection — it changes
  nothing, so it is safe on the state you are trying to explain — and it reports
  where the count actually drops, from the files on disk through the tree, the
  visible list, the selection, and finally the notes an action would touch.

  It also shows the current view mode and any active filter, because two things
  make a smaller selection correct rather than broken: Select All covers one level
  at a time in nested view, and filters apply before the selection is made.

  The result appears as a notice with a "Copy full report" button, and is recorded
  in the debug trace so it can be copied out of Settings → Diagnostics alongside
  everything else.

## Also in this release (0.209.1)

- **Brackets around empty space stay visible.** `[[   ]]` used to make the brackets
  disappear, leaving a blank gap. An empty target is not a link to Obsidian either,
  so they now stay as typed. The same problem was fixed in two related places: an
  embed written as `![[   ]]` was treated as an attachment reference and removed
  that text from the rendered note, and exporting a note containing one produced a
  spurious "Missing attachment" warning.
