# 0.208.3

- **Opening a Stashpad no longer conjures a stray empty folder.** Opening your
  only Stashpad — say "My Notes" — could also create an empty `Stashpad/`
  folder beside it, Home note and all.

  The cause is long-standing rather than new: Obsidian hands a view its state
  *after* the view opens, so for one moment the view didn't yet know which
  folder it was for and set up the default one. It only became visible now
  because 0.208.0 made folder creation announce itself — so it fired a notice
  naming a folder you never asked for, right after promising nothing gets
  created without asking. Set-up is now deferred until the view knows which
  folder it's actually showing.
