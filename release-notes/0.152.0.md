# 0.152.0 — Row actions menu, deep links, and undoable encryption

## Per-row actions menu + copy link
Every note row now has a `⋯` actions menu that consolidates its row-level
actions in one place, including a **Copy link** action for grabbing a direct
link to the note. On desktop the copy-link button is also available inline on
the row.

## Deep links open in their own tab
Opening a link to a specific note now opens it in its own tab instead of
hijacking the tab you're currently in, so following a link never loses your
place.

## Locked (encrypted) rows reach parity with normal notes
Encrypted note rows now share the **full** note context menu rather than a
stripped-down one. Actions that only make sense on plaintext (edit, copy text,
and the like) prompt to **unlock first**; the actions that work regardless —
copy link, delete — are available directly. Locked rows also gained their own
copy-link and delete entries in the earlier row-menu work.

## Encryption actions are now undoable
Locking, unlocking, and deleting encrypted notes can now be undone (Cmd/Ctrl+Z),
matching the undo-everywhere behavior of the rest of Stashpad:
- **Lock** and **Unlock** are undoable.
- Deleting a locked note (encrypted delete) is undoable.
- Encrypted-note delete now also trashes the note's `.stashmeta` sidecar, so no
  orphaned metadata is left behind.

## Fixes
- Deleting a note no longer wrongly insists that an encrypted trash be
  configured on folders that don't use per-folder encryption.
