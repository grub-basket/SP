# 0.192.0

## Importing

- **Import pasted text, in the plugin.** A new command — **"Import pasted text (paste
  → nested notes)…"** — turns pasted text into nested notes directly. Paste, tweak the
  options, see a live preview of the tree you'll get, then import. This replaces the
  round-trip through the standalone Stashpad Importer web app (paste there, download a
  `.stash`, import it here).

  - One note per line; **indentation** or a **`- ` list marker** nests a note under the
    one above (over-indenting is normalised, so inconsistent pasted text still nests
    sensibly).
  - **Code blocks** stay whole, attached to the line above them.
  - **Paragraph mode** for prose: consecutive lines become one note, a blank line
    starts the next.
  - Level-1 notes land under **whatever you currently have focused**, so you can
    import straight into a subtree.
  - The whole import is a **single undo**.

- **Copy and paste round-trips.** The importer understands `[x]` checkboxes and
  `[color: #ffe243 | alias: boogers]` tags — exactly what Stashpad's own copy produces
  — so text copied out of Stashpad can be pasted back in (into another folder, or
  another vault) with its **tasks, colours and nesting intact**. Colour names come
  across as that folder's colour aliases.
