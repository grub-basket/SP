# 0.368.1

## Fix

- **Cross-vault paste now nests under where you're focused.** If you were focused inside a nested note and pasted content copied from another vault, it was placed at the vault's home instead of under the note you were in. It now nests under your current focus (the copied subtree's own structure is preserved), matching how the clipboard/zip paste path already behaved. At the top level it still lands at home.
