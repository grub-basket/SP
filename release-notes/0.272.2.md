# 0.272.2

## Attached files stay as links, not inline previews

Embedding a file with `![[photo.png]]` used to render the image inline in the
note. That turned out too heavy. A file embed now shows as a plain link
(`[[photo.png]]`), still visible in the text, and the file collects in the
attachment rail as before. Embedding another note inline still works and is
unchanged.

## Rail layout switch

The layout switch on the attachment rail now toggles between the filename list
and the compact icon strip. The large thumbnail grid is still available as the
default and in settings.
