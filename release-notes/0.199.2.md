# 0.199.2

- **Fixed the four-brackets bug.** Accepting a link suggestion while the caret
  sat inside an existing `[[link]]` left the old tail behind: `[[Fixed]]o]]`.
  The replacement now extends over the remainder of the old target and its
  closing brackets.
- **`[[@` works.** Typing `@` inside a wikilink hands over to the
  natural-language-date trigger, and the resolved date inserts as `[[date]]`.
- **`@today` inherits Natural Language Dates' "add dates as link" setting** —
  the composer inserts the same thing NLD's own editor suggestion would.
- **New setting (on by default): auto-pair wikilink brackets.** Typing the
  second `[` auto-inserts `]]` with the caret between; typing `]` over an
  existing closing bracket steps over it instead of doubling up. Applies to the
  composer and the edit/split textareas.
