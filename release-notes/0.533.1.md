# 0.533.1

This release covers every change since 0.533.0. It fixes the one issue the community plugin review flagged, and nothing changes for users.

## Showcase export

- **0.533.1** — **Export page** in the Showcase adds a small built-in script to the exported web page so that PDFs display when the file is opened in a browser. Stashpad used to add that script by creating a script element while it assembled the page. The plugin review rejects any plugin that creates script elements at runtime, even when the element is only written into an exported file and never runs inside Obsidian. The script is now written into the page's HTML text directly. Exported pages are byte-for-byte the same as before, and the page's Content-Security-Policy still allows exactly this one script and nothing else.
