# 0.366.1

## Fixes

- **The note menu now shows the full default again, on every device.** If your menu ordering was saved before the submenus (React / Reply, Move, Pin, Appearance, Advanced) were introduced, the whole menu could render without them — even though you never customized it. A one-time refresh restores the current default menu in that case. A menu you've genuinely customized (one that still uses any of the current submenus) is left untouched.
- **In-list "nest under" now moves the note you selected.** If you started the picker, created a new note mid-way (say, to make a parent that didn't exist yet), then chose a target, it moved the *new* note instead of the one you'd selected. It now moves the note you set out to move.
