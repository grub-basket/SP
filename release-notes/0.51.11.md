# 0.51.11 — Multiplayer authorship

First public release. Stashpad is a chat-style nested-notes view for
Obsidian: rapid capture, outliner navigation, in-place editing. Local-only,
no external services.

## Multiplayer authorship (the headline feature)
- Per-user identity in settings: name, role, department.
- `_authors/` reserved folder with auto-generated stub file per identity;
  bidirectional sync between the settings name and the stub.
- Author stamped on every new note; contributor list tracks who else has
  edited it (debounced until edits settle).
- Footer row on each note shows author / contributors / last-edit, with
  per-folder "you've worked in" links.
- Log gains an Author column so multi-user activity is auditable.

## Other 0.51.x changes
- Keybind/command parity audit (0.50.0): every Stashpad command is now
  bindable from the command palette.
- Clone-the-current-tab command (0.51.11).
- Split delete-confirm setting + frontmatter-attachment fallback (0.51.12,
  0.51.13).

## Install
Compatible with Obsidian 1.7+. Install via BRAT from this repo, or copy
`main.js`, `manifest.json`, and `styles.css` into a folder under your vault's
`.obsidian/plugins/`.
