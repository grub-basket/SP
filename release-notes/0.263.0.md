# 0.263.0

## Merge one duplicate copy into another

The duplicate-id modal could only *discard* a copy, which answers "which do I
keep" only when one copy is strictly worse. When both hold something — the
usual case for a sync conflict — the honest action is to combine them, and that
meant opening both and copy-pasting by hand.

Each row now has **Merge into…**:

- With one other copy there is nothing to choose, so it goes straight to a
  confirmation.
- With three or more copies it offers a **menu of the others by name**, with the
  one Stashpad displays marked as such. Names rather than "the copy above",
  because the rows are re-ordered — conflict copies sort last — so a positional
  choice would mean something different depending on the sort.

What merging does is spelled out in the confirmation rather than left to the
word:

- the other copy's text is **appended** under a labelled separator, and only
  when the two bodies actually differ;
- fields are filled in **only where the target has none** — the note you are
  merging *into* always wins, so merging can never overwrite something you
  meant to keep;
- then the copy you merged from goes to the trash.

**One undo restores both sides** — the merged note's original text and the
discarded file.

## Fixed: the folder switcher was hard to read

The folder name sat directly on the accent colour, which reads badly whatever
the accent happens to be — and on the switcher in the composer row it was worse,
because that one never got the contrast fix the toolbar button received.

Both are now outlined instead of filled: the name is ordinary text on the
ordinary background, and the accent marks the active folder through the border
and the icon. Measured on a green accent, that takes the label from a muddy
dark-on-green to **14.7:1** in light mode and **10.6:1** in dark.

## Also

Duplicate-id rows label themselves **Visible:** / **Hidden:** with the file path
on the same line, and the comparison result is colour-coded — green when a copy
has nothing you would lose, red when it holds something you should read first.
