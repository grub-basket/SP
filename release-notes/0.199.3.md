# 0.199.3
- **File dropzone button in the composer.** Drop files straight onto the small
  button to import them and land their links in the composer — or click it for
  a large dropzone modal whose zone is also a click-to-browse file picker. No
  more aiming a drag at the narrow composer.
- **Fixed deep-link auto-paste in secondary windows.** The "Open Stashpad link"
  modal read the clipboard through the main window, which silently fails when a
  pop-out window has focus; it now uses its own window's clipboard, so the
  auto-paste (and the Paste button) work everywhere.

---

This release also rolls up everything since 0.198.0:

## 0.199.2

- **Fixed the four-brackets bug.** Accepting a link suggestion while the caret
  sat inside an existing `[[link]]` left the old tail behind: `[[Fixed]]o]]`.
  The replacement now extends over the remainder of the old target and its
  closing brackets.
- **`[[@` works.** Typing `@` inside a wikilink hands over to the
  natural-language-date trigger, and the resolved date inserts as `[[date]]`.
- **`@today` inherits Natural Language Dates' "add dates as link" setting** —
  the composer inserts the same thing NLD's own editor suggestion would.
- **New setting (on by default): auto-pair wikilink brackets.** Typing the
  second `[` auto-inserts `]]` with the caret between; typing `]` over an
  existing closing bracket steps over it instead of doubling up. Applies to the
  composer and the edit/split textareas.

## 0.199.1

- **Multi-select commands act in list order, not click order.** Selecting notes
  bottom-up or cherry-picking, then copying, pasted them in the order you
  clicked. Selections are now ranked by their position in the displayed list,
  so a copy comes out in the order you see on screen. (Merge already sorted by
  creation time and is unaffected.)

## 0.199.0

- **New Behavior setting: "New tabs open in the background"** (off by default).
  When on, everything Stashpad opens in a new tab — folders, notes, attachments,
  a reminder's task, the aggregate/tasks/trash views — opens WITHOUT stealing
  focus: you stay where you are and switch when ready. Opening a note's editor
  still focuses it (you asked for it to type in it).
- **Clicking a task-reminder notification now always opens the task in a fresh,
  focused tab.** Previously it could reuse an existing folder tab and navigate
  it to the task — which read as "my tab got overwritten".
- **Folders panel:** the per-row "open in new tab" button is hidden when the
  "Folders always open in a new tab" setting is on (the row click already does
  that, so the button was redundant).
- **Folders panel:** the trash button and menu item now say "Open trash" —
  encryption is an implementation detail of the trash store, and there is no
  separate plain-text trash view to disambiguate from.
- The resend-reminders command is renamed **"Re-show pending notifications
  (resend / redisplay reminders for incomplete due tasks)"** so searching the
  palette for "re-show", "display", or "notifications" finds it.

## 0.198.1

- **Due-date picker: removed the empty gap before the date.** Obsidian's own
  stylesheet reserves a picker-indicator gutter inside `input[type="date"]`
  (`padding-left: var(--size-4-6)`, ~24px) with a selector too specific for a
  plugin class to override. Stashpad hides that indicator (the calendar icon on
  the left opens the picker), so the gutter was pure dead space before the
  year. The padding on the date/time inputs is now applied with `!important`
  (scoped to those two inputs only), so the value sits flush like the time
  field.
