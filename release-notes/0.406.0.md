# 0.406.0

Covers 0.393.0–0.406.0 — a large batch of drafts, search, preview, and scroll work.

## Composer drafts (0.393.0–0.397.0, 0.400.0)
- Drafts are no longer pushed into the composer text — the composer always opens empty. Already-sent text and stale chips no longer resurface. Drafts are still saved and reached via the Drafts manager.
- A **Drafts** button at the end of the composer's formatting toolbar toggles a per-folder reminder chip (right-click opens the manager); it's hideable/reorderable like any other toolbar button.
- A short **launch reminder** notice (with an "Open drafts" button) appears if unsent drafts exist — with a setting to turn it off.
- Draft dedup also discards a draft that duplicates (or is a leading portion of) an existing note in the folder, using a fast capped scan.

## Search
- **Search-in-parent** now honors the "open in context / parent list" and "open in a new tab" settings (was always focusing into the note).
- **Search-scope button** beside the composer search button cycles the search between **all → in-list → in-parent**; the search button and the search hotkey run the chosen scope, and it persists. A "Cycle search scope" command is available too.
- **Find-in-list**: a live result count in the find bar; on mobile the formatting toolbar hides while finding to show more results; Escape closes find from anywhere.

## Preview viewer & replies
- The note-preview viewer opens the same viewer from every entry point; clicking an attachment lands on that attachment (the note is one slide back).
- Editing a note in the composer now dismisses the preview modal from every entry point.
- A **Switch PDF render** button on PDF slides cycles Auto → Native → Obsidian (Native allows text selection; Obsidian renders where the native path is blank).
- Reply picks (the "N replies" chip and a reply's quote) now reveal and cursor-select the target note in the list.

## Scroll & other fixes
- List no longer jumps back to the bottom after a scroll up; reply-quote jumps land the note at the top.
- Edit-modal spellcheck (red typo underline) restored; the composer autocomplete popover dismisses on send and on a space after a tag.
- No more redundant expand/collapse toggle after clicking it.
- `Preview home note` now defaults to **Alt+Shift+Space** (Option+Shift+Space on macOS), clear of the previous Mod+Shift+Space system conflict.
