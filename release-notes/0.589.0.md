# 0.589.0

This release covers every change since 0.580.0:
- **The Focus view's search can create tasks.**
- **Stopwatch comes first** in the Focus timer.
- **Hold Send to send a note straight to another place.**
- **PDF export on mobile.**
- **Obscured notes blur again on their own.**
- **Deleted drafts stay deleted** on every device.

## Highlights

- **Create tasks from the Focus search.** In the Focus view's "Add tasks" search:
  - Type a title and click **Create "…"** at the bottom, or press Shift+Enter, to make a new task and put it on today's list.
  - When no note has that title, a "Create new" row also leads the results.
  - "New tasks go to" picks the folder, and the choice is remembered.
  - The search box clears so you can keep adding.
- **Better Focus search.**
  - An empty search lists your open tasks.
  - Typing searches every note: title matches first, then notes that only mention the words in their text, with the matching line shown.
  - Each result shows whether it's a Task, a Note or Done (done ones are struck through). It also shows its folder and parent note, when it was created, its due date and the time tracked, so tasks with the same name are easy to tell apart.
- **Focus timer: Stopwatch first.** The Stopwatch / Pomodoro switch is bigger, with Stopwatch listed first. New installs start with the stopwatch; a choice you already made is kept.
- **Done tasks stay done.** Adding a task you've already finished to today's list keeps it finished. It shows in today's Done section instead of reopening.
- **One at a time → Choose task.** In "One at a time" mode, "Choose task" lets you pick which of today's tasks to work on. A running timer switches to it and saves the time so far to the old task.
- **Real titles in Focus.** The Focus list and search show each note's first line instead of its file name, which drops small words and can start with a date.
- **Hold Send → pick a place → sent.** Press and hold the composer's Send button, pick a destination, and the note is sent straight there. Before, the pick only set the destination and you had to tap Send again.
- **PDF export on mobile.** On Obsidian Mobile 1.15 or later, the export dialog offers PDF. Stashpad hands the note to Obsidian's own "Export to PDF".
- **Exports no longer repeat the first line.** HTML, PDF and PNG exports show a note's first line once, as its heading.
- **Obscured notes blur again.** A note you tap to reveal blurs itself again after 15 seconds unused. Change the time, or turn it off, with "Blur revealed notes again after". The obscure command's "hide again" now sticks.
- **Deleted drafts stay deleted.** Deleting a draft records the deletion, so another device's older copy of your settings can't bring it back.
- **More of the toolbar and row buttons can be changed in Settings.**
  - The 🤖 "AI-assisted" button can be hidden or moved under Toolbar buttons. Hiding it also stops new notes being tagged as AI-assisted.
  - Preview, the Star menu and Make child are regular entries under Item buttons, so you can hide or reorder them.
  - The breadcrumb's right-click menu keeps just four actions that make sense for a path level.

### 0.582.0
- Holding the composer's Send button, then picking a destination, sends the note there. Before, the pick only set the destination.

### 0.583.0
- Focus "Add tasks" search:
  - An empty search lists open tasks.
  - Typing searches every note: titles (first line) ranked first, then body matches with the matching line. Note bodies load in the background.
  - A `Create new: "…"` row, and Shift+Enter to force-create. New tasks go to the folder chosen under "New tasks go to" and land on today's list.
- One at a time: "Choose task" menu (a running timer switches tasks; a paused timer stops; otherwise the task becomes "Up first"). "Up next" no longer repeats the "Up first" task.
- Focus titles come from each note's first line, not its file name.

  - A heading further down no longer becomes the title.
  - An exact title ranks first.

  - Typing during a create isn't wiped.
  - The folder default is always one the list shows.
