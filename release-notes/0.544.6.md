# 0.544.6

This release covers every change since 0.543.0. You can now type a due date in plain words. The Show more / Show less button no longer appears on notes that already fit. A note you've drilled into has one expand button instead of two. The "Insert text at multiple points" panel now sits on top of the formatting toolbar instead of floating.

## New

- **0.544.0** — Type the due date in words.
  - The **Set due date** window has a new text box at the top. Type something like `next fri 3pm`, `in 2 weeks`, `tomorrow at noon` or `end of month`.
  - It understands the same phrases as typing `@` in the composer, so a date means the same thing in both places.
  - As you type, the date and time fields below fill in, and a line under the box shows the result, for example "→ Fri, Oct 9, 2026 · 3:00 PM". A phrase without a time keeps the time that was already set.
  - Half-typed words get a suggestion. Typing `next fr` shows "Tab → next friday", and Tab completes it.
  - Text it can't read shows a hint in red instead of guessing.
  - Press Enter to save, same as the Set button. If you empty the box, the fields go back to what they were, unless you changed them by hand after typing.
  - On desktop the window opens with the cursor in this box. On mobile it still starts on the date field, so the keyboard doesn't cover the window.

## Fixes

- **0.544.1** — The Show more / Show less button no longer appears on notes that already fit.
  - An expanded note always got a collapse button, even a one-line note with nothing to collapse. With **Expand note bodies by default** turned on, that meant every note in the list. The setting is per vault, which is why it only happened in some vaults.
  - Expanded notes are now measured the same way as collapsed ones. They only get the button if collapsing would actually hide something.
  - Stashpad remembers whether each note was too long to fit. Those remembered results were measured before 0.540.0 let note text flow under the row buttons, so some notes that now fit were still marked as too long. They are measured again once.
- **0.544.2** — A note you've drilled into has one expand / collapse button instead of two.
  - Expanding the note at the top of the list used to add a second button (**Show more**) next to **Expand / Collapse the header**. That gave three steps: one line, then a short scrollable window, then the full note.
  - Now there is only the header button. Expanded shows the whole note at normal text size, and collapsed is one line. Notes in the list below are unchanged.
- **0.544.3** — The **Insert text at multiple points** panel now sits on top of the formatting toolbar.
  - It used to float under the text box, where it could end up off the bottom of a tall edit window or under the phone keyboard.
  - It's now a strip directly above the toolbar, styled like the composer's "Similar notes" strip. This applies in the composer and in the edit window.
- **0.544.4** — Expanded notes that contain a code block, table or callout get their **Show less** button back on desktop. The first version of the 0.544.1 fix measured those notes as fitting, so they had no button. They also stayed fully open after collapsing. Remembered results from that version are measured again.
- **0.544.5** — Due date box:
  - Pressing Enter in the **empty** box no longer saves. The box has the cursor when the window opens, so a stray Enter used to save whatever was already filled in. With several notes selected, that copied the first note's date and tags to all of them.
  - A time you change by hand after typing is kept when you then type a phrase without a time.
- **0.544.6** — If the composer or edit window redraws while you're marking spots for **Insert text at multiple points**, the marking session now ends cleanly instead of leaving its markers behind.

## Internal

- `DueDatePickerModal` reuses `parseNaturalDate` / `naturalDatePhrases` from `natural-date.ts`.
- `queueClampMeasure` measures expanded rows under a temporary `.is-clamped`, with the container's `.is-body-expanded` lifted for the measurement. The memo fast path and `remeasureClampsForWidth` cover expanded rows too. `OV_MEMO_VERSION` is now 3.
- `renderFocusedHeader` renders the drilled-in heading's body unclamped (`clamp: !opts.asRow`). New CSS drops the size limits on an expanded heading row.
- `MultiInsert.toggle` takes an optional `dock` element (the toolbar passes itself). If nothing is passed, the floating panel is used as before. A new `orphaned()` check ends a session whose text box or panel was removed. The docked panel is created with `createDiv`.
- Developer changelog notes for the branch. They don't ship in the plugin.
