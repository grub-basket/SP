# 0.271.4

## Embedded notes stay in the note

Embedding another note inline (`![[Some Note]]`, or a dated note like
`![[2026-08-18]]`) used to make it disappear: it was pulled into the attachment
rail and left a gap where the note should have rendered. Only real files belong
in the rail, so an embedded note now stays in the body and renders in place.

## A layout switch on the rail

When a note has several attachments, a small control at the start of the rail
switches the layout between the thumbnail grid, the filename list, and the
compact strip, handy for a note carrying a lot of files, without a trip to
settings.
