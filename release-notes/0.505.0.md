# 0.505.0

Two features since 0.500.0: composer code-block handling + a block-preview modal, and AI "bot" authors.

## Composer fenced code blocks + block preview

### 0.501.0 — Auto-complete fenced code blocks in the composer
Typing a triple-backtick fence in the composer now auto-completes the closing
fence, so code blocks stay balanced as you type.

### 0.502.0 — Keep fenced code blocks atomic when splitting notes
When a composer send is split into multiple notes, a fenced code block is no
longer cut across the split — the fence and its contents stay together in one
note.

### 0.503.0 — Block-preview modal refinements
Widen the block-preview modal, move its Copy button to the left, and add a
soft-wrap toggle.

### 0.505.0 — Resizable block preview + prominent Copy
Make the block-preview modal resizable and give it a large, centered Copy
button.

## 0.504.0 — AI bot authors (Claude, ChatGPT, …)

Add AI assistants as named authors or contributors of a note, the same way a
person is attributed.

- A bot is a regular author record flagged `bot: true` — stampable as a note's
  author or contributor, shown with a 🤖 marker in Settings → Authorship →
  Known Authors, and **excluded from team notifications** (a bot-authored note
  never notifies teammates).
- Seeded suggestions: Claude, ChatGPT, Gemini, Copilot, Grok — plus "add a
  custom bot". Enabled/created on first use.
- Three ways to attribute a note, all additive and undoable:
  - Right-click a note ▸ **Attribute to AI…** ▸ *As contributor* / *As author*.
  - A keybindable command, **Attribute to AI author / bot… as contributor**
    (no default chord — bind it in Settings → Hotkeys).
  - A **🤖 button in the composer**: toggle it on to tag every note you send as
    contributed by the chosen AI, until you toggle it off.
- **As contributor** (the default) adds the bot alongside you; **as author**
  sets the bot as author and moves any existing human author to contributors
  rather than dropping them.
