# 0.209.0

- **The link autocomplete understands aliases.** A note titled "Architecture
  Decision 7" was unreachable by typing `ADR-7`, however its frontmatter was
  set up. Obsidian's `aliases` are now indexed, with one suggestion per alias
  so you can see which name matched — the alias as the label, the real filename
  and path beneath, so two notes sharing an alias stay tellable apart. All the
  shapes real vaults use are accepted (`aliases` or the older `alias`, as a
  single value or a list).
- **You can now type `[[Target|Alias]]`.** Pressing the pipe key used to kill
  the suggestion list outright, since no filename contains one. The query now
  splits at the first pipe — target before it, alias after — and inserting
  keeps whichever alias you typed.
- **Exports: an extra fallback when resolving an attachment's path**, covering
  a file Obsidian hasn't finished indexing. Adding it surfaced a genuine defect
  in both exporters, which could treat a *folder* as an attachment to read and
  package; both now check properly first.
