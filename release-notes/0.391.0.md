# 0.391.0

Covers 0.388.0–0.391.0 — composer-draft precision and note-preview / PDF viewer improvements.

## 0.388.0 — Drafts don't resurrect what you just sent
- The composer sometimes re-captured a note you had just sent (a blur/flush race after submit) and showed it back as a lingering draft. Sends and edits are now remembered per folder, and a draft whose text matches one of them is discarded instead of resurrected. Edit-drafts are exempt (their text mirrors the note by design).
- The drafts manager's **Delete** button is now labelled **Discard** (with matching notice and help text).

## 0.389.0 — Draft matching refined
- Removed the length floor on draft matching: a draft is treated as a re-capture when it equals a recent send/edit or is a leading portion of one, at any length. A draft that extends a sent note (longer than it), or diverges, is unique and kept. Discarding only affects persistence — the composer keeps whatever you have typed.
- Fixed write churn: a matching or empty draft with nothing bound no longer rewrites settings on every keystroke or blur.

## 0.390.0 — Unified note-preview viewer
- `Shift+Space`, the row **Preview** button, and clicking an attachment now all open the same viewer — the note as the first slide, followed by its attachments — differing only in which slide opens first.
- Clicking an attachment opens **that attachment**, not the note, so it no longer lands on the note preview when you meant to open a file; the note is one slide away rather than absent (previously an attachment click opened an attachments-only viewer with no way back to the note).

## 0.391.0 — Switch how a PDF renders
- A **Switch PDF render** button on PDF slides cycles the render engine: **Auto → Native → Obsidian**.
  - *Native* uses the browser PDF chrome, which allows selecting text.
  - *Obsidian* uses Obsidian's own PDF viewer, which renders where the native resource comes back blank (e.g. some Windows network drives).
  - *Auto* keeps the existing probe-then-fall-back behaviour.
- The mode is remembered across slides for the session; a short notice names the mode picked.
