# 0.185.0

## Editing

- **The edit & split editor now has the composer's autocomplete.** Type `[[` to
  link a note or attachment, `#` for a tag, or `@` — the same popup you get in the
  main composer, now inside the in-app edit / split editor (modal and pop-out tab).
- **Paste or drop a file into the editor to attach it.** Dropping or pasting a file
  (image, PDF, anything) into the edit / split textarea copies it into the note's
  attachments and inserts an `![[wikilink]]` at your cursor — matching the composer.

## Reminders

- **Task reminders open in their own tab.** Clicking a due-task reminder now focuses
  a background tab for that folder (or opens a fresh one) instead of taking over the
  tab you're currently working in.
- **New command: "Resend reminders for incomplete due tasks."** Pops your backlog of
  past-due, still-incomplete tasks back up on demand — handy first thing in the day.
