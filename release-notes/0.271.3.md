# 0.271.3

## Attachment rail: filenames fit, and the default layout is horizontal

Two fixes to how a note's attachments are shown.

**Filenames no longer clip.** In the thumbnail layout, a non-image file showed a
type badge with its name below, but the name overflowed the card and was cut off
mid-word. The badge and name now share the card and the name is a single line,
so it reads cleanly.

**The default layout is horizontal.** The automatic layout used to switch to a
vertical list whenever a note's attachments were mostly non-images, so a note
with a couple of documents looked completely different from one with photos. It
now stays a horizontal rail by default (thumbnails when they fit, a compact icon
strip when space is tight). The vertical filename list is still available as an
explicit choice in settings.
