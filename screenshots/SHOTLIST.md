# Screenshot checklist

Drop a PNG with the exact filename into this folder and it appears on the site
automatically (no HTML edits). Until then, a labeled placeholder shows. 16:9-ish
crops look best. Dark theme recommended to match the site.

| File | Section | What to capture |
|------|---------|-----------------|
| `hero.png` | Hero | Stashpad open in Obsidian — composer at the bottom, notes stacking/nesting above. The money shot. |
| `install.png` | Install | BRAT's "Add beta plugin" dialog with the repo pasted. |
| `outliner.png` | Core idea | Drilled into a note: breadcrumb at top, nested children below. |
| `composer.png` | Composer | The composer with its button rail (split, destination, Enter, attach, send). |
| `composer-autocomplete.png` | Composer | The `[[` or `#` autocomplete popover open. |
| `split-modes.png` | Splitting | Right-click menu on the split button (each line / paragraphs / headings). |
| `split-modal.png` | Splitting | The Split modal with the "Split by:" preset row and the centered divider. |
| `command-palette.png` | Navigation | The Stashpad command palette (or the keybindings settings). |
| `search.png` | Search | Sift search results across a folder / the vault. |
| `panels.png` | Panels | The panels sidebar showing Pinned / Tasks / Shared. |
| `organizing.png` | Organizing | The right-click context menu (move, merge, clone, colors, pin…). |
| `tasks.png` | Tasks | A task note with a due date + the Tasks panel. |
| `okf-export.png` | OKF | The "Export as OKF…" dialog with .zip / .tar.gz / .stash options. |
| `okf-frontmatter.png` | OKF | A note's `okf*` frontmatter and/or a generated `index.md`. |
| `stash-export.png` | Import/export | Exporting a subtree as a `.stash` bundle. |
| `authorship.png` | Multiplayer | Author/contributor stamps on a note. |
| `encryption.png` | Encryption | Encryption settings and/or a locked note. |
| `jd.png` | JD index | A generated Johnny.Decimal index. |
| `tiny-mode.png` | Tiny mode | The floating, pinned, opacity-adjusted tiny window over another app. |
| `templates.png` | Templates | The per-folder template setting. |
| `mobile.png` | Mobile | Stashpad on a phone (portrait crop is fine — it still renders). |
| `settings.png` | Settings | The Stashpad settings tab. |
